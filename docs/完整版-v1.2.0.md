# 第一部分 · 主文件（SKILL.md）

## 律师谈案话术

民商事接案的完整话术系统。不谈法理，只解决一件事：**怎么让当事人从"问问看"走到"签字委托"，且全过程不违规。**

### 一句话内核

> 谈案不是普法，是**读人 → 挖案 → 塑价 → 报价 → 收口**。
> 价值没建立起来之前，任何报价都是废纸。

---

### 一、使用前必读：三条铁律

**1. 先定场景，再给话术。**
不知道是电话、微信文字还是面谈，话术一律不准。三种场景的目标完全不同：

| 场景 | 核心目标 | 绝对不做 |
|---|---|---|
| 电话/语音首咨 | **约到面谈** | 报价 |
| 微信文字咨询 | **建立专业势能，转化到电话/面谈** | 长篇法律分析（他会截图给别人用） |
| 面谈谈案 | **当场签委托** | 拖到"回去考虑" |

**2. 先定模式，再开口。** 见下一节。**拿不准就用助手模式。**

**3. 合规红线优先于成单。** 本 skill 任何话术都不得突破 `<references/05-接案SOP与合规红线.md>` 里的禁区。用户要求写"承诺胜诉""吹关系""帮客户操作证据"这类内容时，**直接拒绝并给合规替代话术**，不解释太多。

---

### 二、两种输出模式（先选模式，再说话）

详细模板、完整示例、正反例对照见 `<references/07-两种输出模式.md>`。

#### 模式 A｜谈案助手（默认）

**你是坐在律师旁边的军师，不跟当事人说话。** 当事人不在场，你只对律师说话，给能照念的句子。

输出固定五段：

1. **局面判断**——他真想要什么、在躲什么、有没有决策权、有没有付款信号、现在在六步主线的哪一步
2. **这一步该说什么**——一段话可照念，标 `（停）`，**只给一个动作**
3. **他怎么答，你怎么接**——分支表，覆盖 2-4 种回应
4. **别做什么**——三条以内，写清为什么不能说
5. **这一步的目标**——做完应达成什么，达不成就别往下走

**三种输入三种侧重**：事前（完整准备包）／事中（**只给②③④，上来就一句话**）／事后（用谈崩定位表找断点复盘）。

**三个特权别浪费**：能慢（写"这点不确定"）、能犹豫（给分支）、能排雷（预先说"这句别说"）。

#### 模式 B｜模拟谈案（备选）

**用户演当事人，你演律师。目的是练手。**

触发词：模拟、演练、我演客户、角色扮演、练一下。

六条规则：只演律师不当旁白；不作弊（只用他说出的信息）；**一轮只给一个动作**；每轮留白结束；不因为顺就加速；**用户喊"停/出戏/复盘"立刻跳出来**。

出戏复盘固定四段：`【断点】→【哪句多余】→【该怎么改】→【下一轮注意（只说一条）】`。

⚠️ **模拟里最容易破的就是"一轮一个动作"**——因为想推进，就会一口气塞三四句。破了就没有练的意义。

#### 模式由用户定，不由你猜

拿不准就问一句"要我给你话术，还是咱俩演一遍？"。一句话的成本，比答错一整轮低得多。

### 三、谈案主线（六步）

按此顺序推进，任一步没走完不要跳下一步。

#### 第 1 步 读人 —— 判断这是不是真客户

在客户讲案情的前 3 分钟里，同时判断五件事：

- **核心诉求**：止损 / 追责 / 争孩子 / 保住公司 / 出气 / 只想有人听他讲
- **隐性恐惧**：怕输、怕花钱打水漂、怕对方报复、怕家丑外扬、怕自己不懂被坑
- **信任缺口**：他为什么不信任律师（被坑过 / 觉得贵 / 觉得都是骗子 / 觉得案子简单不用律师）
- **决策权**：他自己拍板，还是"回去跟老公/合伙人/领导商量"
- **付款信号**：问分期、问能不能先做后付、问"你们最便宜多少"、主动说"我什么时候有空过来"

**动作**：心里打完标签。标签决定后面用哪套话术。
- 高意向 + 有决策权 → 走"快速塑价 + 直接报价 + 收口"
- 低意向 / 白嫖型 → 走"设门槛 + 低成本试探"，不投入太多
- 无决策权 → **不报价**，先要决策人到场

#### 第 2 步 挖案 —— 边挖事实，边挖付款意愿

不要连珠炮发问。每问 1-2 个问题，必须**回给客户一个有用的判断**，否则他觉得自己在填表。

三组必问（民商事通用）：
1. **事实组**：时间、主体、金额、证据有没有、对方现在什么态度
2. **程序组**：有没有时效问题、有没有保全必要、管辖在哪、有没有在走的程序
3. **意愿组**：你最想达到什么结果？能接受什么结果？之前找过别人吗？

**收尾必做**：用自己的话总结一遍案情，让客户说"是的，就是这样"。
这一步不是确认事实，是**让他进入你的思路轨道**——后面所有"是吧？"才会生效。

#### 第 3 步 塑价 —— 把法律方案翻译成他能感知的损失

当事人不为"专业"付费，为**"如果不请你，我会损失什么"**付费。

三个锚点任选，不要堆：
- **敞口锚**：这笔钱拖一年，利息 + 执行难度 + 对方转移财产的概率
- **对比锚**：自己弄 vs 请你弄，差的不是知识，是取证权、保全时机、程序节奏
- **机会锚**：他现在最该干的事是挣钱/养孩子/救公司，不是天天跑法院

一句话模板：
> "你这个案子最贵的不是律师费，是**时间**。现在动手和拖半年动手，能拿回来的钱不是一个数。"

#### 第 4 步 报价 —— 价值不到，绝口不提数字

**报价三个前置条件，缺一不报**：见过材料 / 判过风险 / 客户已认可你的思路。
只满足"他问了"，不构成报价条件。

- **三档并列**：高/中/低三档服务包，让他选"哪一档"而不是"要不要"
- **高开留口**：首报略高于心理价位，但不得虚高到离谱
- **拆解类比**：把总价拆成月/天/单项工作量
- **绝不做**：电话报价、微信发数字、被"你直接说多少钱"逼出底价

#### 第 5 步 收口 —— 异议是购买信号，不是拒绝

"太贵了""我再想想""我跟家人商量下"——**这些都不是拒绝，是在要一个继续谈的理由。**

应对公式（三步，不许跳）：①先共情 ②再重构 ③给台阶。

收口必带**具体动作**：不是"你考虑一下"，而是"那我们定周四上午十点，你把合同和转账记录带来"。二选一给时间，不给开放式。

#### 第 6 步 跟进 —— 没签不等于死了

未成交当天必做三件事：发预约/资料清单短信 → 记录卡点在哪一环 → 设下一次触点（不骚扰，给新信息）。

⚠️ **两条贯穿全场的铁律**（详见 `01` 开篇）：**一轮只给一个判断、一个动作**；**信息不够，不下结论**。

---

### 四、按案件类型调用

不同案型的**切入点、发问清单、价值锚、专属异议**完全不同。接到具体案型，先读 `<references/04-分案型话术.md>` 对应章节，再动笔。

覆盖：婚姻家事 / 民间借贷与债务 / 合同纠纷 / 劳动争议 / 工伤 / 建设工程 / 公司股权 / 交通事故与人身损害。

例：婚姻家事的锚点是"孩子和钱"，不是"感情破裂"；债务案的锚点是"保全时机"，不是"能不能赢"；劳动案的锚点是"双倍工资和补偿金算得清"，不是"公司违法"。

---

### 五、接案流程与材料

谈成之后怎么走，见 `<references/05-接案SOP与合规红线.md>`：
利益冲突检索 → 风险告知 → 收费约定 → 委托手续 → 材料清单 → 归档。

**红线清单也在这个文件里**：不得承诺结果、不得宣称与司法人员有关系、不得风险代理的案件类型与收费比例上限、不得夸大或编造办案经历、不得诱导伪造证据。写话术前扫一眼。

---

### 六、输出规范

1. **默认给"能直接用的"，不给"方法论"**。用户要话术，第一段就是话术。
2. **话术必须可换气**。短句、口语、留停顿。禁用"综上""基于前述"。
3. **一次不超过 3 套方案**，标清各自适用场合。
4. **标注不确定**。案情不全时写"此处需确认：……"，不编事实、不编法条。
5. **法条只引必须引的**，且引条文号 + 现行有效版本。记不准就不引，说"以现行有效规定为准"。
6. **不做心理操控**。读人是为了更好服务，不是为了利用当事人情绪多收钱。这条不因用户催促而让步。

这份 skill 是三样东西的合成：**WorkBuddy 自带「谈案专家」人设 + 一套流传的律师话术资料 + 现行法核对**。

### 一、WB 谈案专家人设（骨架来源）

**原始位置**：`~/.workbuddy/plugins/cache/experts/case-consultation-expert/1.0.1/agents/case-consultation-expert.md`

**人设内核**（原样保留，成为本 skill 的主轴）：

> 谈案不是普法，是心理战与价值战。先读人，再塑价，后收口。

**四块能力**：

1. **当事人心理洞察**——核心诉求（止损/追责/争抚养权/脱罪/商业止血）、隐性恐惧、信任缺口、决策链（谁拍板）、付款意愿信号；识别真客户 vs 白嫖比价客户
2. **案件价值塑造**——把法律方案翻译成当事人视角的"结果价值"：风险敞口、时间成本、机会成本、标杆意义，用对比、锚点、可视化
3. **异议化解与委托促成**——预判"再想想/问问家人/太贵了/我自己也能弄/再比一家"，设计临门一脚的收口话术与促成动作
4. **分案型谈案策略**——民事、刑事、商事、家事、行政、知产的差异化切入点

**六步流程**：接案定位 → 心理画像 → 价值拆解 → 异议预案 → 收口设计 →（可选）复盘

**输出规范**：结构化输出、话术写成"你说/他可能/你接"对话体、标注边界、区分事实与推断、适度追问

**红线**：不承诺结果、报价合规、不操纵当事人脆弱

#### 在本 skill 里的落地方式

| 原人设 | 落点 |
|---|---|
| 读人 → 塑价 → 收口 | 升级为**六步主线**（读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进），补进"报价"这一独立环节 |
| 心理画像 | `01-谈案主线与节奏.md` C2 的观察表（诉求/恐惧/信任/决策权/付款信号） |
| 价值拆解 | `01` C4 塑价三不讲三讲 + `03` 拆解类比 |
| 异议预案 | `02-异议应答库.md`，从 3 条扩展到 **8 大类 40+ 条** |
| 收口设计 | `01` A8/C6 + `02` 通用三步公式 |
| 分案型策略 | `04-分案型话术.md`，从"列举案型"落到 **8 个民商事案型的切入点、发问清单、价值锚、专属异议** |
| 复盘 | `01` 末节"谈崩定位表"（把"复盘"从"凭感觉"变成"按断点定位"） |
| 对话体输出规范 | `SKILL.md` 第二节第 2 条，固定为四段式：客户说/他心里想的/你接/别说什么 |

#### 原人设缺什么，补了什么

- **缺场景区分**：原人设默认"面谈谈案"，但律师大量接案发生在电话和微信。本 skill 补了**三场景分流**，这是最大的一处结构性改动。
- **缺话术颗粒度**：原人设是"策略顾问"（告你怎么想），本 skill 是"话术库"（告你怎么说），所以每条都写成能照念的句子。
- **缺执行动作**：原人设讲"收口设计"，本 skill 落到"二选一时间 + 短信确认 + 改称呼"这类具体动作。

#### 从原资料里保留的真东西（这几条最值钱）

1. **价值不到，价格不报**——这是整套资料的地基
2. **总结确认**（把客户散乱的话复述成一二三，让他说"是的"）——一次谈话只能拿到一次"轨道进入"的机会
3. **有问必有答**（每问一个问题，回给客户一个判断）——防止咨询变成填表
4. **二选一时间法**（"今天下午还是明天上午"，不问"你什么时候有空"）
5. **改称呼**（先生 → 哥/姐）——一句话把关系从咨询拉成熟人
6. **永远不接第一次还价**
7. **拆解类比**（年费拆月、对比专职法务人力成本）
8. **请示领导 + 今天能签吗**（让价换承诺）

#### 删掉或改造的（重要）

原资料是电话销售体系出身，有一批内容**法律上过期、执业上违规、伦理上有问题**。逐条处理见 `05-接案SOP与合规红线.md` 第三节"原资料毒点对照表"。

三大类改造方向：

- **法律过期的**：诉讼时效由"两年"改为**三年**；抚养权意愿年龄由"10 岁"改为**八周岁**；人身损害城乡赔偿差异**已统一**（原话术"帮您按城镇标准操作"同时是过时和违规）；"全城没有一家做风险代理"与事实不符。
- **执业违规的**：宣称与交警/法院有关系、承诺把对方列入失信名单、暗示能影响伤残鉴定等级、编造办案案例与数量、教唆操作病历与出院证明、故意把报价明细搞复杂藏利润——全部删除或替换为合规表述。
- **伦理有问题的**：纯"挑矛盾"式的煽动话术（激化夫妻对立、挑动客户对交警的敌意）保留其"揭示真实风险"的功能，删掉"制造情绪"的部分。

**一条原则**：凡是靠"我知道你不知道的内幕"取信客户的话术，一律不用。短期有效，长期是雷。

### 三、补充的现行法核对点

原资料多处引用了当年（约 2016 年前后）的口径，本 skill 已按现行法修正，但仍建议正式出具意见前复核：

## 01 谈案主线与节奏

三个场景三套节奏。**用错场景，话术再好也白搭。**

---

### 开篇：两条全场铁律（血泪换来的，别跳）

#### 铁律一：一轮只给一个判断、一个动作

电话里人一次只能接住一个东西。**一轮塞四个信息包，等于一个都没塞进去。**

反面教材（真实翻车）：

> 客户："欠了十多万吧，两三年了，很着急啊。"
> 律师："**十多万不是小钱。但我先说你那句'两三年'——这个比金额更要命。诉讼时效是三年……过了会怎样……所以你现在第一件事不是催他，是翻记录——今晚就得翻出来。还有个问题你没答我：有没有借条？**"

一句话里有：时效标准 + 后果 + 执行指令 + 追问。客户接不住，只会觉得"这人在催我"。

正确节奏：

> 律师："时间这块我心里有数了。我问个具体的：**这个钱当时是怎么给他的？转账还是现金？**"
> （停，等他答）

**判断"是不是给多了"的自检**：这句话说完，他能不能用一个短句回答？不能，就是给多了。

#### 铁律二：信息不够，不下结论

**缺口径的判断，比不给判断更伤人。** 三个后果：吓跑客户、说错了被客户回头堵、专业形象一次性崩掉。

典型翻车：客户说"两三年了"，律师接"可能上个月就过了"——但根本没问过**有没有约定还款日**。约定"随时还"的，起算点完全不同。

**下判断前的校验清单**（通用）：

- [ ] 时间点问准了吗？（不是"两三年"，是具体哪年哪月）
- [ ] 起算依据问清了吗？（约定日期 / 未约定 / 最后一次催告 / 部分还款）
- [ ] 手上有什么材料，问清了吗？
- [ ] 对方的抗辩点，能预判吗？

**缺任何一项，标准话术是**：

> "这个得看材料才能定，我现在给你个数，是不负责任的。"
> "这一点我先记下，回头核一下再回你。"

⚠️ 注意：讲风险的**必要性**不因为这条减弱——该讲的还是要讲，只是不能把"风险提示"说成"结论"。可以说"这个时间点很关键，得算准"，不能说"你已经过了"。

### 场景 A｜电话 / 语音首咨（目标是约到面谈）

电话的唯一任务：**让他愿意带着材料来律所。** 不报价、不做完整法律分析、不承诺结果。
平均时长控制在 8-15 分钟。超过 20 分钟还没约上，基本就废了。

#### A1 开场（20 秒内建立"我是律师"的身份）

> "您好，这里是××律师事务所，我姓×，您说。"

不要问"有什么可以帮您"，太客服。让他直接讲，你在听。
他讲的时候只做三件事：**不打断、记关键词、嗯一声表示在听**。

#### A2 总结确认（全场最重要的一步）

听完必须复述，用"一二三"结构：

> "×先生/女士，我先把您的情况复述一遍，您看我理解得对不对——
> 第一，……；
> 第二，……；
> 第三，您现在最想解决的是……。
> 是这样吧？"

**为什么要复述**：一是证明你在听（客户最缺这个），二是把他散乱的情绪整理成"问题"，问题才能被解决，能被解决的问题才值得付钱。三是从他嘴里拿到第一个"是"，后面所有"是吧"才有心理惯性。

**他说"对，就是这样"之后，不要立刻讲法律。** 先补一句需求确认：

> "所以您现在要的不是'这事到底谁有理'，是**怎么把这笔钱拿回来/怎么把婚离掉/怎么把赔偿要到位**，对吧？"

把他从"讲道理"拉到"要结果"。这一句决定后面能不能谈钱。

#### A3 引导到"只有法律能解决"

不要直接说"你起诉吧"。用排除法，让他自己得出结论：

> "×先生，这事无非两条路。一条是您自己去谈——您已经谈过了，什么结果您比我清楚。
> 另一条是走法律程序。走程序的好处不是'法院帮您出气'，是**把主动权换到您手上**：
> 该保全的保全，该发函的发函，该立案的立案。他拖，法律不让他拖。
> 您现在最缺的不是道理，是**一个能强制他的东西**。您说是不是？"

#### A4 发问核实（边问边给，不能只问不给）

铁律：**每问 2-3 个问题，必须回给客户一个有用的判断。** 只问不给，客户会觉得在填表。

> "我问几个问题，您别嫌烦，这些直接决定后面怎么打。
> （问：什么时候的事？）
> ——嗯，这个时间点很关键，**诉讼时效是三年，从您知道权利被侵害那天算**，您这个还有/只剩……
> （问：有没有转账记录/合同/欠条？）
> ——有就好办。没有的话也不是不能打，但要靠其他证据补，这块是律师的活。"

**"有问必有答"是原资料里最值钱的一条**：每个问题问完，明确告诉他"我为什么问这个、这个答案意味着什么"。他会立刻感到"这人懂"。

#### A5 专业展示（给路径，不给结果）

给的是**程序和机会**，不是胜率：

> "这个案子往下走大概三步：先××，再××，最后××。每一步能争取什么、会卡在哪，我大致能给您画出来。
> 但具体能走到哪一步，得看到材料才知道。**我现在给您一个准数，是不负责任的。**"

他说"你就说个大概""你经验这么多还不知道吗"——这正是你要的，接住：

> "正因为做过太多，才知道同一个案情换个证据、换个法院，结果就不一样。谁张嘴就给您一个数，您反而要小心。"

#### A6 首次邀约（不要等他问"那怎么办"）

主动抛，用**理由**而不是请求：

> "这样，×先生，电话里我只能给您个方向。合同/欠条/病历这些东西，每一份都影响判断。
> 您把材料带上，来所里坐半小时，我当面给您把路径捋清楚——**您听完觉得我行，我们再谈委托；觉得不行，您拿着这个思路自己走也可以。**"

最后半句必须说。它把"来律所"从"要被推销"变成"来白拿一次分析"，阻抗直接降一半。

#### A7 二次邀约（他还在电话里追问细节时）

> "这个我电话里真说不准，因为要看材料。您先过来，我们把材料过一遍，这个问题当场就有答案了。"

不要被拉进电话里的长篇法律分析。**分析给完了，他就不来了。**

#### A8 二选一锁时间 + 短信确认 + 改称呼

> "那您看是今天下午方便，还是明天上午？"
> （他选明天上午）"行，明天上午十点，我给您留出时间。"
> "我等下把地址和我的电话发到您手机上，您收到回我一个字就行。"
> （收到后）"好，×哥/×姐，明天见。"

三个细节，全是实战验证过的：
- **不问"你什么时候有空"**，问"今天下午还是明天上午"——封闭式二选一，他不会说"再说吧"
- **当天发短明确认**，把口头预约变成书面承诺，爽约率明显下降
- **改称呼**（先生→哥/姐），一句话把关系从"咨询律师"拉成"熟人"

### 场景 B｜微信文字咨询（目标是转化成电话/面谈）

微信的坑：**你打的每一个字都可能被转发给别的律师、发到群里、用来比价。**

#### B1 第一条回复（30 秒内，短）

> "您好，我是××律所的×律师。您先说说情况，我看到就回。"

不要回"您好，请问有什么法律问题需要咨询"，也不要一上来发名片长图。

#### B2 中间回复（只给框架，不给结论）

> "您这个事，核心就三个点：①……②……③……。这三个点每一个都有讲究，打字说不清，也容易说偏。
> 您方便的话，我把电话给您，通个话五分钟，比打两百字清楚。"

**微信里永远不写完整法律分析。** 原因很实在：写全了，他就不需要你了；写一半，他觉得你不专业。

#### B3 设门槛（对付长期白嫖）

> "简单的问一句我随时答。要是涉及看材料、出方案，这部分我们是收费咨询，××元/次，
> 后续委托的话从律师费里抵扣。您看要不要走这一步？"

**收咨询费的意义不是赚那点钱，是筛人。** 愿意付的，是客户；不愿意的，本来也不会签。

#### B4 转化（务必给具体动作）

> "您这个情况，我建议当面聊二十分钟。您把××和××带上就行。明天下午或者后天上午，您哪个方便？"

### 场景 C｜面谈谈案（目标是当场签委托）

面谈是**唯一该报价的地方**。节奏按"读人 → 挖案 → 塑价 → 报价 → 收口"走。

#### C1 开场（前 5 分钟不谈案）

先给水、先问路上、先聊两句他带来的材料怎么这么厚。
**目的**：让他从"警惕"降到"聊天"。人在防备状态下，说什么都听不进去。

一句破冰可以用：

> "您这个材料整理得挺仔细，一般人拿过来都是一团。看得出您是认真在准备这件事。"

夸具体的东西，不夸人。夸人显得油。

#### C2 读人（不输出，只观察）

边听他讲边在心里填这张表：

| 观察项 | 看什么 | 判断 |
|---|---|---|
| 诉求 | 他反复念叨的是哪件事 | 反复说的才是真诉求，第一次说的是场面话 |
| 恐惧 | 说到哪里声音变小/加快/开始抱怨 | 那里就是恐惧点 |
| 信任 | 有没有提"之前找过律师""我朋友说" | 提过被坑的，先修信任再谈钱 |
| 决策权 | "我回去跟我老公说说" | 出现即停，不报价 |
| 付款信号 | 主动问分期/问流程/问多久 | 有其一，可进入报价 |

**读人不写出来给客户看**，写出来就成了操控。

#### C3 挖案（三层递进）

1. **事实层**：时间、主体、金额、证据、对方态度
2. **程序层**：时效、管辖、保全必要、有无在途程序
3. **目标层**：他要的最好结果、能接受的最差结果、愿意为这个结果付出多少时间

第三层最容易漏，但**第三层直接决定报价档位**。愿意等两年的，可以报"全程代理"；只想速战速决的，报"阶段代理"。

#### C4 塑价（讲三件事，不讲法条）

- 不讲"根据民法典第××条"，讲"**这笔钱现在不锁住，三个月后大概率查不到财产**"
- 不讲"我有十年经验"，讲"**你这个案子最耗时间的是××，这一步没做对，后面全要返工**"
- 不讲"我们胜诉率高"，讲"**同类案子我做过，卡点在哪我清楚，所以能少走弯路**"

#### C5 报价（见 `03-报价与收费话术.md`）

#### C6 收口（见 `02-异议应答库.md`）

面谈结束前必须落地一件事：**要么签，要么定死下一次的具体时间并说明下次要带什么。**
"回去考虑考虑"是谈案失败的标准结局，不能让它出现在对话结尾。

### 谈崩定位表（复盘用）

客户没签，先定位**断在哪一步**，再改。不要笼统说"我话术不行"。

| 现象 | 断点 | 病根 | 下次怎么改 |
|---|---|---|---|
| 问完价就沉默 / 说"太贵了" | 第 3 步塑价 | 价值没建立就报价了 | 报价前先问一句"您觉得这事最坏会怎样"，让他自己说出损失 |
| 一直问"你能保证赢吗" | 第 2 步挖案 | 风险没讲透，他心里没底 | 主动把最坏结果摆出来，反而建立信任 |
| "我回去跟家人商量" | 读人 | 没识别决策权人 | 当场问"这事最后谁拍板"，把人约到 |
| 聊得很好，就是不签 | 第 5 步收口 | 全程没提过具体动作 | 结尾必须给二选一的具体时间 |
| 只问价，不聊案情 | 读人 | 白嫖/比价型客户 | 设咨询费门槛，别投入过多 |
| 说"我朋友也是律师" | 第 1 步信任 | 没有差异化 | 不谈"我更强"，谈"我和他的方案差在哪" |
| 全程你在讲 | 全程 | 说太多 | 每讲 2 分钟，必须问他一个问题 |

**复盘顺序**：先看断点 → 再看当时客户的原话 → 最后才改话术。跳过前两步改话术，改了也没用。

---


## 02 异议应答库

**先记住一件事：异议不是拒绝，是购买信号。**
真正不想签的人不会跟你说"太贵了"，他只会说"好的，谢谢，我再联系你"然后消失。

凡是他还在跟你争、跟你砍、跟你比——他就在等你说服他。

### 通用三步公式（每条话术都从这里派生）

1. **共情**：先承认他的顾虑合理（"这个顾虑很正常""换我也会这么想"）
2. **重构**：把问题换个框架（价格→价值；输赢→风险；花钱→止损）
3. **给台阶**：给一个具体、不丢面子、马上能做的下一步

**顺序不能反。** 先重构再共情，就是抬杠。

---

### 一、费用类

#### 1.1 "你们怎么收费？"（刚开口就问）

**他心里想的**：先套个价，好去比。
**你接**：

> "收费是按案件情况、标的大小、难易程度和工作量综合定的。**现在连您的事我都没听明白，就给您报个数，那是不负责任。**
> 您先说说怎么回事，我听完了，大概要花多少功夫我心里有数，那时候说收费才准。"

**别说什么**："我们不收费/先免费咨询"——一句就把自己降成客服了。

---

#### 1.2 "能不能便宜点/打个折"

**他心里想的**：律师费应该有水分，砍一砍试试。
**你接**（第一轮，先不降价，给价值）：

> "这个价我还是按您这个案子该花的功夫报的，没往上虚。
> 您这个事处理好了，省下来/拿回来的钱是律师费的多少倍，这个账您比我算得清。
> **我要是给您报个特别便宜的价，您反而该担心我把您的案子交给谁在做。**"

**你接**（第二轮，还是要降，用"申请"给台阶）：

> "这样，我给您申请一下看看能不能再让一点。不过我先说清楚——**如果领导那边同意让了，咱们今天就把委托手续办了**，
> 不然我这边不好交代。您看行不行？"

**别说什么**："那给您打个八折吧"——**永远不要接客户第一次还价**。你一让，他就会想"是不是还能再低""是不是本来就不值这个钱"。

---

#### 1.3 "太贵了"（面谈中最常见）

**他心里想的**：不是没钱，是"还不值"。
**你接**：

> "贵不贵得看跟什么比。您现在最怕的不是花这笔钱，是**花了钱还办不成事**，对吧？
> 那我们这么说：这个案子最坏的结果是什么？您损失多少？
> 我收的这个数，是让您在这个最坏结果上多一层保险。**您买的是少亏，不是多花。**"

**别说什么**："我们这已经是最低价了"——最低价等于没价值。

---

#### 1.4 "别的律师报价比你低"

**他心里想的**：你是不是在宰我。
**你接**：

> "可能。市场上多少钱的都有，还有不收费的呢。
> 但律师费这个东西，买的不是'有个人替我去法院'，是**他怎么打、什么时候打、先打哪一步**。
> 同样一个案子，先保全再起诉和先起诉再保全，结果能差出一半。
> **您要是只看价格，那就选便宜的，我不劝您。您要是看结果，那我们再往下聊。**"

**别说什么**："他们不专业"——诋毁同行本身就违规，而且显得你虚。

---

#### 1.5 "别人比你还便宜，你怎么这么贵"

**你接**（用差异，不用情绪）：

> "那两个案子不一样。您这个麻烦在××和××，光取证就得跑几趟，还未必一次拿得到。
> 您觉得都是'要钱'，其实一个是走流程，一个是得打硬仗。**这俩活儿能一个价吗？**"

**要点**：把他的案子"复杂化"必须是**真的复杂**，说得出具体麻烦在哪。说不出，就别用这招。

---

#### 1.6 "给我一份报价明细"

**他心里想的**：逐项砍价。
**你接**（两种情况选一）：

> **（案子本身简单）** "明细我能给，但说实话，这个案子拆开也就三四项，拆太细意义不大。
> **我给您一个总价，服务范围写进合同，超出的部分不另收费。** 这样对您更划算。"

> **（案子复杂，客户懂行）** "可以，我按阶段给您列：立案阶段、审理阶段、执行阶段，每个阶段做什么、花多少时间。
> **列出来您就知道钱花在哪了，也知道哪一步最值钱。**"

**别说什么**：故意把明细搞复杂、藏利润项、设价格诱饵——**这是价格欺诈，一旦投诉就是实锤**，省下的几千块不值这个风险。

**合规做法**：明码标价、项目说清、总额固定。真正的护城河是"你讲得比别人清楚"，不是"你藏得比别人深"。

---

#### 1.7 "我不想付前期费用，打赢了再给你提成"

**他心里想的**：我不信你能赢，凭什么先给钱。
**你接**：

> "我理解，您是怕钱花了事没办成。
> 但这里有个规则我得先跟您说清楚：**风险代理是有法定范围的**，您这个案子（如：婚姻家事/劳动报酬/工伤赔偿/追索抚养费）
> 按规定**不能做风险代理**，不是我不想，是做了就违规，对我们双方都没保障。
> 能做的部分，我们可以谈**分段收费 + 后段比例**，这样您的压力也小。您看这个思路行不行？"

**绝对不做**：为了签单硬承诺"全风险代理"、承诺"拿不到钱一分不收"。前者违规，后者你赔不起。

---

#### 1.8 "就帮我看个合同，为什么还收费"

**你接**：

> "合同这东西，字都认得，**难的是它后面会出什么事**。
> 一份合同里改一个字，将来可能省几十万，也可能赔几十万。
> 您找我，买的就是'知道这字改在哪'。这个功夫，是收费的。"

---

### 二、信任类

#### 2.1 "你们律所靠谱吗 / 我怎么信你"

**你接**：

> "这话该问。律师这行确实有不像话的。
> 我不跟您保证什么，就给您两个办法验证：**一是我的执业证号您可以去司法局网站查；二是这类案子我办过哪些，可以给您讲两三个，您自己去核。**
> 信不信最后还是您判断。"

**要点**：**不要自证，要给验证路径。** 自证越多越可疑。

---

#### 2.2 "你这么年轻 / 不是名校 / 不是法本"

**你接**：

> "您这个顾虑我懂，谁都希望找个有经验的。
> 但法律这行，经验不在年纪，在**这类案子你到底办过多少**。
> 我给您说个具体的：您这个情况，最容易在××上出问题，一般人不一定留意得到。**您听我说完这一段，您自己判断我够不够。**

**别说什么**："我虽然年轻但是我专业"——空口无凭。用一段具体的专业判断证明，比解释十句管用。

---

#### 2.3 "你办过我这类的案子吗"

**你接**：

> "一模一样的没有，天底下没有两个一样的案子。
> 但**同一类**办过，卡点在哪我知道。您这个案子我初步看，难点是××，这个坎过不去，后面都白搭。
> **没把握的案子我不接**，接了办不好，我比您还难受。"

---

#### 2.4 "我有个朋友也是律师 / 我朋友在法院/公安"

**你接**：

> "那挺好的，朋友能帮您看个大概。不过朋友归朋友，**他要么不收您钱（那他不会真投入时间），要么收您钱（那您不如找专做这类的）**。
> 您现在缺的不是'有人懂法'，是'有人把这事当成自己的事、按天推进'。这个只有委托关系能保证。"

---

#### 2.5 "你有关系吗？能不能找人打个招呼"

**你接**（必须挡住，且不能让他觉得你没本事）：

> "×总，这话我得跟您说实话：**关系这事，敢跟您打包票的，基本都是准备骗您的。**
> 现在办案全程留痕，谁为了一笔律师费去冒这个险？
> 真正能帮上忙的是**把证据做扎实、把程序走对**——这才是法官愿意支持您的东西。
> 我给您办，靠的是这个，不是靠谁能递话。"

**绝对不做**：暗示关系、吹"我跟××很熟"、承诺"能打招呼"。**这是执业红线，也是诈骗的高发话术。**

---

#### 2.6 "律师都是人精，我不想跟律师打交道"

**你接**：

> "您这印象不是没来由，确实有律师把当事人绕晕。
> 但我跟您讲句实在的：**我一天要说的话、要算的账，全在案子上。回家我一句废话都不想说。**
> 您要是不放心，我们把每一步做什么、什么时候做，全写进委托合同。**您按合同验我的活，不用猜。**"

---

#### 2.7 "你是不是收了钱就不管了"

**你接**：

> "这个担心很实在。所以我在合同里给您写清楚：**关键节点我主动向您汇报，进展到哪一步、下一步做什么、要您配合什么，都有记录。**
> 您随时可以问，我不怕您问，就怕您不问然后自己瞎猜。"

---

### 三、专业质疑类

#### 3.1 "你能保证赢吗 / 胜率多少"

**你接**（这是必答题，答不好全盘皆输）：

> "不能。**谁跟您说能，您就别找他了。**
> 法律不是算术题，同一个事实，一审二审能判出两个结果，这在我们行业里太常见了。
> 而且《律师执业管理办法》明确规定，律师不得对办案结果作不当承诺。**我承诺赢，本身就违规。**
> 我能给您的是：这个案子的**有利点在哪、风险点在哪、最坏会怎样**，以及我怎么把有利点做足、把风险点堵上。
> **您买的是我尽力，不是买结果。** 这话不好听，但是实话。"

**别说什么**："基本没问题""八九成把握""放心交给我"——都是雷。

---

#### 3.2 "别的律师说的跟你不一样"

**你接**：

> "他怎么说？……（听完）
> 他这个说法有他的道理，我这个说法有我的依据。**差别可能在于我们看到的材料不一样，或者对某个细节的判断不一样。**
> 您现在还没定，多问几家是对的。**但您要留意一件事：谁给您讲的'风险'更具体，谁更靠谱。** 只讲好话的那个，您得多想想。"

**如果你确实说错了**：直接认。"您说得对，这一点我刚才是说错了。"**认错反而加分**，硬撑才是掉分。

---

#### 3.3 "法律根本没用，我试过了"

**你接**：

> "您走到这一步，确实累。调解、仲裁都试过没用，换谁都泄气。
> 但您试的这些，**都是在'没有人强制他'的前提下试的**。
> 法律真正有用的地方只有一个：**它能让对方不得不坐下来。** 判决、保全、执行，这些不是讲道理，是硬约束。
> 您之前缺的不是道理，是这一环。"

---

### 四、拖延类

#### 4.1 "我再想想"

**你接**（不要问"您还想什么"，那是给他逃跑的路）：

> "行，想想是应该的，这不是小事。
> 不过我想知道，**您现在最拿不准的是哪一块？是费用，还是能不能办成，还是家里那边还没通？**
> 您说出来，我能解释的解释，解释不了的我也告诉您。**您带着一个清楚的问题回去想，比带着一团乱回去想有用。**"

**要点**：把"再想想"翻译成**具体的一个顾虑**，然后现场处理掉。

---

#### 4.2 "我回去跟家里人商量一下"

**你接**：

> "应该的。
> 不过我提醒您一句：**这种事，您回去一讲，家里人第一反应基本都是'别打官司了，太麻烦'。** 他们不是不帮您，是没看到这里面的账。
> 要不这样——您把家里人一起带来，我当面讲一遍，他们有什么疑问当场问我。**省得您回去还得替我做解释。**
> 明天晚上或者后天下午，您看哪个时间能凑上？"

**要点**：不要认"商量"这件事结束，要**把决策人拉进你的场子**。

---

#### 4.3 "我过段时间再说 / 最近忙"

**你接**（用时间成本，不用催）：

> "忙是正常的，这事也确实不该占您太多时间——**这也是为什么您该找个人替您跑。**
> 但有个事我得跟您说清楚：**这类事拖下去是有代价的。** 您这个案子，××（时效/保全时机/证据灭失/对方转移财产），
> 每过一个月，能拿回来的就少一点。**您可以忙，但时间不会等您。**
> 要不这样，您先把手上的材料给我，我先做初步的固定，您该忙忙您的。"

---

#### 4.4 "我先自己试试，不行再找你"

**你接**：

> "可以，我不拦着。但有两件事您自己试不了：
> **一是查对方财产，二是保全。** 这两样必须律师出面或者通过法院，您自己去办不了。
> 而且还有个更要紧的——**您自己去谈、去发消息，容易把对方惊动，他提前把财产转走，后面谁都救不回来。**
> 您要是想自己试试，我建议您先别动，先让我看看有没有保全的必要。"

---

### 五、结果与执行类

#### 5.1 "打赢了也拿不到钱，对方没钱"

**你接**（给"起诉仍然有价值"的四个理由，别只说一个）：

> "这话我听过太多次了。但我问您一句：**您怎么知道他现在没钱？查过吗？**
> 就算真没钱，起诉也不是白起：
> 一，**债权固定下来，一辈子有效**，他哪天有钱了您还能要，不起诉过了时效就彻底没了；
> 二，**能查他的财产**——房产、车辆、股权、银行，这些您自己查不到，法院能查；
> 三，**起诉能把他逼到谈判桌上**，很多人一收到传票就主动来谈了；
> 四，**先起诉的先受偿**，等他被别人执行完了，您连汤都喝不上。
> **您不起诉，是零。起诉了，至少还有机会。**"

#### 5.2 "执行不了怎么办"

**你接**：

> "执行不了有执行不了的做法：**限高、失信名单、查控财产、追加被执行人、追究拒执**。
> 我不敢跟您保证一定执行到钱——这个谁都不能保证。
> 但我能保证的是：**该用的手段一样不落。** 您现在最不该做的是'因为怕执行不了，所以连判决都不要'。"

---

### 六、砍价之外的价格动作

#### 6.1 "我没钱打官司"

**你接**：

> "理解。那我们把方案做成您能承受的样子：
> **一是分段收**，先做立案和保全这一段，看到进展再走下一段；
> **二是把标的分层**，能快速回款的部分先打，剩下的再看。
> 您别一次把所有钱都投进去。**但有一件事不能省：该保全的时候必须保全**，这一笔省了，后面全白干。"

**绝不做**：介绍客户去借高利贷、推荐"合作融资方"。这是行业里最容易翻车的地方。

---

### 七、关系与场合类

#### 7.1 熟人介绍 / 饭桌上问价

**你接**：

> "×总，今天这顿饭我领了。案子的事我听明白了，大概方向我心里有数了。
> **但价格这事，饭桌上说不合适**——不是跟您见外，是怕说岔了，回头朋友难做。
> 您明天（或周五）抽空来所里一趟，把××和××带上，我给您出个具体方案，那时候谈钱才谈得清楚。"

**要点**：**饭桌不报价。** 一是有旁人在，二是酒桌上的数字第二天就变味。

#### 7.2 不想接熟人的案子

**你接**（体面地推）：

> "您这个案子我不算最合适，我给您推荐我们所的×律师，他专做这块，比我在行。
> 我帮您联系，中间有什么问题您也可以随时问我。"

**不要**：勉强接，然后办不好，赔上关系。熟人案子的成本远高于收益。

---

### 八、白嫖与比价型客户

#### 8.1 微信反复问、就是不谈委托

**你接**（第一次设门槛）：

> "您这几个问题我都答了。往下要看的就不是'法律怎么规定'，是'您这案子怎么打'了——那部分我们收费。
> 咨询费××元，委托了从律师费里扣。您看要不要走这一步？"

**他还继续白嫖**（第二次，直接收口）：

> "×先生，我能帮的都说到这儿了。**要么我们约个时间正式谈，要么您先按我上面说的自己走一段**，有问题随时来问。这样对您我都好。"

**要点**：**给两次机会，第三次就不回了。** 不回不是傲慢，是让他知道你的时间有价值。

#### 8.2 "我就问一句，马上就好"

**你接**：

> "您问。"（答完，不延伸，不主动展开）
> "……就这些。再往下就涉及您具体材料了，那个得看东西才能说。"

**不要**：一句变十句。他每次说"最后一句"，你每次都答，就是无限续杯。

---


## 03 报价与收费话术

> 本文件涉及的收费规则以现行有效规定为准，签约前请核对当地律协细则与律所备案标准。

---

### 一、报价的三个前置条件（缺一不报）

| 条件 | 判断标准 | 缺了会怎样 |
|---|---|---|
| 见过材料 | 合同/欠条/病历/判决书，至少看到一样 | 报出来的价一定是错的，后面要么后悔要么吓跑人 |
| 判过风险 | 你能说出这个案子最大的坎在哪 | 报价没有依据，客户一质疑就露怯 |
| 客户认可思路 | 他说过"这样确实可以""那你说怎么办" | 价值没建立，报什么数都是贵 |

**只满足"他问了"，不构成报价条件。**

三种绝对不报的场合：
1. 电话里（不知道对方在不在听，也看不见表情）
2. 微信文字里（会被截图比价）
3. 饭桌上（有旁人在，价格第二天就变味）

---

### 二、三档报价法（主推手法）

#### 为什么是三档

给两档是"要不要"，给三档是"要哪个"。**同一句话，把决策性质从"买不买"换成"选哪个"，成交率完全不同。**

而且无论他选哪一档，都在你设定的框架内——最便宜那档也得让你不亏。

#### 怎么切三档

民商事通用切法（按"服务深度"切，不按"打折"切）：

| 档位 | 内容 | 定位 |
|---|---|---|
| A 全程代理 | 全流程 + 保全 + 执行 + 关键节点主动汇报 + 我本人主办 | 主推档，报在中间偏上 |
| B 阶段代理 | 只做一审（或只做保全+立案），后续另议 | 让价档，承接预算有限的客户 |
| C 单项服务 | 只出方案/只写文书/只陪谈一次 | 门槛档，把他变成付费客户 |

#### 话术

> "您这个事，我给您三个做法，您听哪个更适合您：
> **第一个，全程我来**。从保全、立案、开庭到执行，我全程跟，中间每个节点我主动跟您说进展。这个××万。
> **第二个，我们先把最要紧的一段做了**——保全加立案。这一段做完，对方大概率就来找您谈了，谈成了后面就省了。这个××万。
> **第三个，您自己走，我给您把方案和文书做出来**，关键时候您来找我对一次。这个××。
> 您看哪个更合适？"

**关键细节**：
- 报价顺序 **A → B → C**，从高到低。先听到的数字会成为锚点。
- 每档后面必须跟"这一档解决什么问题"，不能只报数字。
- 说完立刻问"您看哪个更合适"，**不给沉默的时间**。

---

### 三、高开留口（有边界）

#### 原则

首报可以略高于你的心理成交价，为谈判留出空间。**但高开不等于虚高。**

判断标准：**这个数字，你能说清楚它凭什么值。** 说不清就是虚高，虚高一定崩。

#### 话术

> "这个案子工作量不小：保全要跑、财产要查、对方大概率会提管辖异议拖时间，一审完了可能还有二审。
> 我按这个量报，是××万。"

#### 高开的风险控制

- **只高 10%-20%**，不要翻倍
- 高开必须配**具体的工作量说明**，否则客户会觉得你在试探他
- 高开之后，降价只能降一次，且幅度小（见下条）

---

### 四、降价的三条铁律

1. **永远不接客户第一次还价。** 你一让，他会想"还能再低""是不是本来就不值"。
2. **最多让一次，幅度不超过 10%。** 20 万降到 10 万再降到 5 万，客户会觉得砍到 5 万还吃亏，最后跑单。
3. **每次让价必须换东西。** 让价换付款方式（一次付清）、换服务范围（去掉某项）、换时间（今天签）。**白让的价，客户不感激。**

#### 让价话术（换成"申请"）

> "这个价我自己定不了，得报所里。我可以帮您争取，但**如果批下来了，咱们今天就签，行不行？**
> 不然我这边不好说话。"

**这句为什么管用**：把"降价"变成一件需要他付出承诺的事，同时也给了他不签就要承担"人情债"的压力。

---

### 五、拆解类比（对付"太贵了"最有效）

把总价拆成他能对照的日常单位。

#### 常法业务（年费拆月）

> "十万一年，拆下来一个月八千多。
> 您请一个专职法务，一个月多少钱？还得交社保、还得休假、还只管一家公司的事。
> 我们是一个团队，一个月八千多，合同、劳动、催收、合规，随时问。"

#### 诉讼业务（拆工作量）

> "这个价看着多，但您算算：调查取证跑几趟、立案排队、开庭至少两次、中间还有调解、写文书、跟对方律师拉锯。
> 摊到每个环节，其实没多少。**而且这些活您一样都替不了我。**"

#### 小额案件（拆对比物）

> "这个数，跟您这笔钱的数额比，是几十分之一。
> 您现在纠结的是这几十分之一，但丢了的是那几十分之几十。"

#### 反例（别用）

> "一分钱一分货""我们质量好"——太空。客户听过一百遍。

---

### 六、收费方式怎么选（和客户谈结构，不只谈数字）

| 方式 | 适用 | 话术要点 |
|---|---|---|
| 固定收费 | 标的小、工作量可预估 | 简单直接，别绕 |
| 按阶段收费 | 周期长、不确定性大（诉讼+执行） | "每一段做完您再付下一段，您风险小，我也能专心做" |
| 按小时 | 常法、非诉顾问 | 必须约定上限，否则客户不敢找你 |
| 风险代理 | **仅限法律允许的案件类型** | 见下节红线 |

#### 分段收费话术（推荐给预算敏感的客户）

> "咱们分两段：立案保全这段××，做完您看到东西了，再决定要不要走第二段。
> **这样您不用一次把钱压上来，我也不至于干到一半没着落。**"

---

### 七、风险代理：法定边界（这条必须记死）

**禁止实行风险代理的案件**（依《律师服务收费管理办法》，以现行有效版本为准）：

- 婚姻、继承案件
- 请求给予社会保险待遇或最低生活保障待遇的
- 请求给付赡养费、抚养费、扶养费、抚恤金、救济金、**工伤赔偿**的
- 请求支付**劳动报酬**的
- 刑事诉讼、行政诉讼、国家赔偿案件
- 群体性诉讼案件

**比例上限**：实行风险代理的，最高收费金额不得高于收费标的额的 **30%**。

#### 客户要求"全风险"时的话术

> "×先生，这个事我得跟您讲清楚：**您这类案子，规定上不允许做风险代理。**
> 不是我保守，是做了以后万一有争议，那份合同可能被认定无效，到时候您我都麻烦。
> 我们能做的是：**前期收一部分，后期按结果再收一部分**，把您的压力摊薄。您看这样行不行？"

**绝对不做**：
- 承诺"拿不到钱一分不收"
- 用"咨询费""差旅费""调查费"等名目变相做全风险
- 在禁止类案件里套风险代理的壳

**这不是道德问题，是执业风险问题。** 一旦被投诉，退费是小事，处分是大事。

---

### 八、报价单必须写清的六项

口头报完，**当天发一份书面报价单**。这既是专业形象，也是纠纷时的证据。

1. **服务范围**：具体做哪些事（保全/立案/一审/二审/执行/和解谈判）
2. **不包含事项**：诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费、异地办案费
3. **收费金额与支付节点**：什么时候付、付多少
4. **主办律师**：谁办，是否可更换（这条直接影响客户信任）
5. **成果交付**：每个阶段交付什么（书面方案/结案报告/进展汇报频率）
6. **有效期**：报价有效期（建议 7-15 天），过期重议

**第 2 项最容易被忽略也最容易起纠纷**。客户以为"全包"，结算时多出鉴定费就翻脸。事先写清，反而显得你专业。

---

### 九、报价环节自检（发出去之前过一遍）

- [ ] 是否见过材料？没见过 → 不报
- [ ] 是否在电话/微信里报？是 → 改成"约面谈"
- [ ] 每一档是否都说明了"解决什么问题"？没有 → 补上
- [ ] 是否承诺了办案结果？有 → 删掉
- [ ] 是否涉及禁止风险代理的案件类型？涉及 → 改成分段收费
- [ ] 是否说了"我是最低价/别人都不行"？说了 → 删掉（价格欺诈 + 诋毁同行）
- [ ] 书面报价单是否写明不包含事项？没写 → 补上

## 04 分案型话术

不同案型的**切入点、价值锚、专属异议**完全不同。用错锚点，说得再多也不打动他。

> 本文件法律要点为速查提示，正式出具意见前请核对现行有效法律法规与当地裁判口径。

---

### 一、婚姻家事

#### 切入点
**不谈感情，谈孩子和钱。** 客户哭诉的时候要听，但你把话题往"怎么办"上引的那一刻，他才开始把你当律师而不是树洞。

> "×姐，您说的这些我都听明白了。但我们现在得把话头转一下——
> **您最想保住的是哪一样？孩子，还是钱，还是就想赶紧把这事了了？**
> 这三样打法不一样，您得先给我一个顺序。"

#### 必问清单
1. 什么时候、在哪登记的？现在双方在哪居住、住了多久（管辖）
2. 几个孩子、多大、现在跟谁生活（**不满两周岁以母亲直接抚养为原则；已满八周岁应尊重本人真实意愿**，中间段看双方条件）
3. 有哪些财产？登记在谁名下？婚前婚后？有无按揭、有无父母出资
4. 有没有债务？谁签的字？用于什么
5. 对方什么态度？同不同意离？争不争孩子？
6. 有无家暴、出轨、转移财产的迹象？有没有报警记录、就诊记录、聊天记录
7. 对方收入、工作、名下有无公司（直接影响抚养费和执行）

#### 价值锚
- **孩子**："孩子判给谁，不是看谁更爱他，是看**谁能证明自己更适合**。工资流水、居住环境、谁在接送、谁在辅导——这些是证据，不是感受。"
- **钱**："很多人离婚时最亏的不是分得少，是**对方在提离婚前半年就把钱转走了**。您现在最该做的是查，不是谈。"
- **时间**："拖一年，您的青春、孩子的适应期、财产的贬值，都回不来。"

#### 时效与程序提醒
- 离婚本身无诉讼时效，但**再次起诉离婚**需注意判决不准离婚后分居满一年再诉的规定
- 隐藏、转移夫妻共同财产的，离婚分割时可少分或不分；离婚后发现的，可另行起诉
- **人身安全保护令**：遭遇家暴可单独申请，不必等离婚诉讼

#### 专属异议

**"我自己出轨，对方要我净身出户"**
> "法律上没有'净身出户'这一说。出轨是过错，但过错的法律后果是**可能承担损害赔偿、可能影响财产分割比例**，不是自动净身出户。
> 对方这么吓您，是在拿您不懂法压您。真到法院，该您的一分不会少。"

**"他不肯离"**
> "他不肯，不影响您离。协议不成就是起诉。**第一次判不离，隔一年再诉，基本就判离了。**
> 您现在纠结'他同不同意'没有意义，有意义的是**证据准备得够不够**，证据够，第一次就能判离。"

**"他说离婚就弄死我"**
> "这种话必须当真处理，但不能因为怕就不动。
> 三件事我们同时做：**一是报警留记录，二是申请人身安全保护令，三是把威胁的聊天记录、录音固定下来。**
> 这些既是保护，也是将来争抚养权、争财产的筹码。"

**"我要告他重婚，让他坐牢"**
> "可以，但我要先跟您说实话：**重婚的证据要求极高**，光有开房记录、有孩子，都未必够。很多人卡在这一步。
> 而且这是自诉案件，证据要您这边举证。**所以现在的关键是先取证，不是先立案。** 取不到证，立了也是白立。"

---

### 二、民间借贷与债务

#### 切入点
**不谈"能不能赢"，谈"什么时候能拿到钱"。**

> "×总，您这事我不先问对错——欠债还钱，道理在您这边。
> 我先问一个更实际的：**他现在名下有什么？您知道吗？**
> 因为这类案子，赢不是问题，**能不能执行到钱才是问题**。"

#### 必问清单
1. 钱怎么给的？转账、现金、还是代付？有没有凭证
2. 有没有借条/欠条/合同？谁写的、签没签字、有没有约定利息和还款期
3. 有没有催过？什么时候催的？有没有微信、短信、录音（**诉讼时效中断的证据**）
4. 对方现在什么态度？还认不认？有没有部分还款
5. 对方的财产状况、工作、有没有其他债权人已经起诉
6. 有没有担保人、抵押物

#### 价值锚
- **保全时机**："这类案子最值钱的动作是**保全**，不是起诉。**先下手查封，和后下手查封，结果是一个拿钱一个拿判决书。**"
- **时效**："诉讼时效三年，从还款期满或您最后一次催告起算。**您每催一次，时效重新起算——但前提是您能证明催过。**"
- **查询能力**："房产、车辆、股权、银行账户，这些您自己查不到，法院能查。"

#### 专属异议

**"他没钱，起诉有什么用"**
> "您查过吗？没查过就别说没钱。
> 而且就算没钱也要起诉：**债权固定下来一辈子有效，不起诉过了时效就彻底没了。**
> 现在排队，将来他有钱了，先起诉的先拿。"

**"借钱给他是现金，没有转账记录"**
> "不是不能打。要看三样：借条上有没有写明现金交付、您能不能说清现金来源（取现记录）、对方有没有否认借款事实。
> **对方只是拖着不还、没有明确否认，这对我们有利。** 剩下的证据我们来补。"

**"他欠了好多人的钱"**
> "那更要抢时间。**除抵押、担保优先外，普通债权基本按查封和起诉先后受偿。** 别人起诉了您没起诉，他的财产分完就没了。"

---

### 三、合同纠纷

#### 切入点
**合同是根本，先要原件。**

> "这类案子我得先看到合同原件。不是我不信任您转述，是**合同里每一个条款都跟别的条款连着**，
> 您从中间抽一条出来讲，很容易讲成对我们不利的样子。**看到全文，我才能告诉您哪条能用、哪条是坑。**"

#### 必问清单
1. 合同性质是什么？签的哪一方？有没有原件、有没有补充协议
2. 约定的核心义务是什么？谁先违约、违约在哪一步
3. 有没有约定违约金、定金、解除条件、争议解决方式
4. 履行到哪一步了？有没有付款、交货、验收记录
5. 有没有欺诈、重大误解、显失公平的情形
6. 您要的是**继续履行**，还是**解除+赔偿**？（这个必须先问清，决定整个打法）

#### 价值锚
- **方向选择**："继续履行还是解除索赔，这是两条完全不同的路，选错就废。**房价涨了要房子，房价跌了要赔偿**——得看哪个对您更值。"
- **时间**："解除权是有期限的。**放着不主张，权利会过期。**"
- **损失举证**："您亏了多少，得有证据。光说'我损失几十万'，法院不认。"

#### 专属异议

**"合同有霸王条款，是不是就没戏了"**
> "霸王条款不是自动无效，要看它是否属于**格式条款中不合理免除对方责任、加重您责任、排除您主要权利**的情形。
> 这类条款可以主张无效。**但要具体到是哪一条，得看全文。**"

**"这么简单，我自己去起诉就行了"**
> "程序您可以学，但有三件事您做不了：
> **一是判断该主张哪条请求权**——同样的钱，按违约要、按不当得要、按侵权要，举证责任和赔偿范围都不一样；
> **二是财产保全**，去晚了对方钱就没了；
> **三是损失怎么举、违约金能不能调**，这些是法官的自由裁量区，得靠经验争取。"

---

### 四、劳动争议

#### 切入点
**先算清他能拿多少。** 劳动案客户最关心"我能拿多少钱"，你算得清，他就信你。

> "×先生，我先给您把这笔账算出来，您心里有个数：
> 违法解除的赔偿金、未签合同的双倍工资、未休年假、加班费、拖欠工资——**这几项能不能叠加、各能主张多少，我一个个给您说。**"

#### 必问清单
1. 什么时候入职、有没有签合同、合同期限
2. 工资多少、怎么发（打卡/现金/谁的名义发的）、有没有工资条
3. 为什么离职？是辞退、被迫离职、还是自己辞？
4. 有没有书面解除通知？理由写的是什么
5. 社保交没交、按什么基数交
6. 有没有考勤记录、工作群记录、工牌、邮件（证明劳动关系）

#### 价值锚
- **算得清**："这些钱不是'争取一下'，是**有法定算法**的。基数、年限、倍数，都能算。"
- **举证倒置**："工资数额、考勤记录这些**由单位举证**，他举不出来，就按您说的算。"
- **不签合同是双刃剑**："没签合同对您不全是坏事——**可以主张二倍工资，最多十一个月**。但要先证明劳动关系存在。"

#### 时效提醒
**劳动仲裁时效一年**，从知道或应当知道权利被侵害之日起算。拖欠劳动报酬的，劳动关系存续期间不受一年限制，终止之日起一年内提出。

#### 专属异议

**"才几千块，值得打官司吗"**
> "值不值得看怎么算。您算的是这一笔，我算的是**连着能主张的几笔加起来**。
> 而且这类案子很多不用打到开庭，**一张仲裁申请书发过去，公司就愿意谈了**。"

**"我还想在这个行业干，怕被拉黑"**
> "这个顾虑很实际。所以我们可以先走**协商+发函**，不急着立案。
> 但协商也要有筹码，**筹码就是您手上的证据和时效**。没筹码去谈，就是求人。"

---

### 五、工伤

#### 切入点
**把程序链条一次讲清。** 工伤客户最怕"不知道要折腾多久"，你把链条画出来，他反而安心。

> "工伤这条路我给您捋一遍：**确认劳动关系 → 工伤认定 → 劳动能力鉴定 → 申请仲裁赔偿。**
> 四步，一步不能省，顺的话几个月，对方拖着就一年往上。
> **但每一步都有对应的时间限制，错过了就补不回来。** 您现在最要紧的是把认定申请递上去。"

#### 必问清单
1. 在哪、什么时候、给谁干活受的伤？有没有签劳动合同
2. 伤在哪、住院多久、有没有诊断证明和病历
3. 医药费谁出的？现在还欠多少
4. 单位是什么态度？认不认工伤
5. 有没有工牌、工服、考勤、工资记录、同事（证明劳动关系）
6. 有没有买工伤保险

#### 时效提醒（最要紧）
- **单位应在事故伤害发生之日起 30 日内申请工伤认定**
- **单位不申请的，职工或其近亲属可在 1 年内直接申请**——这一年过了，原则上不再受理
- 没有劳动合同的，要先通过仲裁确认劳动关系，这一步也耗时，**所以越早启动越好**

#### 价值锚
- **时效**："这一年是硬期限，过了一天都可能白干。"
- **程序并行**："认定程序走着，同时跟单位谈。**程序是压力，谈判是结果，两条腿走路。**"
- **鉴定**："伤残等级直接决定赔偿金额，差一级差几万。鉴定材料怎么准备，是有讲究的。"

#### 专属异议

**"没签合同，是不是就没办法了"**
> "没签合同恰恰是常事，工地上十个有九个没签。
> **没签合同也能认定，靠的是其他证据**：工牌、工资转账、微信工作群、同事证言、工地出入记录。
> 这些证据怎么取、什么时候取，是关键——**等老板警觉了，就取不到了。**"

**"包工头跑了 / 公司说是包工头的事"**
> "这是他们内部的事，跟您无关。
> **您直接找有资质的用工单位或施工单位主张**——人能跑，公司和项目跑不了。
> 至于他们内部怎么追偿，那是他们之间打官司。"

---

### 六、建设工程

#### 切入点
**抓两件事：结算依据和优先受偿权。**

> "工程款这类案子，赢不赢主要看两样：**一是有没有能算清的结算依据，二是有没有在期限内主张优先受偿权。**
> 第二样很多人不知道，过期就没了。"

#### 必问清单
1. 合同、补充协议、签证单、结算单在不在？有没有对方签字盖章
2. 工程验收了没有？有没有交付
3. 欠多少、怎么算出来的？有没有对账
4. 有没有实际施工人、转包、分包关系
5. 工程竣工或约定竣工日期是什么时候？（**优先受偿权期限**）
6. 发包方有没有其他债权人、项目有没有被查封

#### 价值锚
- **优先受偿权**："建设工程价款优先受偿权，**行使有期限**（自发包人应当给付工程价款之日起，一般十八个月内行使，以现行规定为准）。
> 这个权利比一般债权优先，很多老板不知道，白白错过。"
- **结算**："没有结算单，就得做造价鉴定，周期长费用高。**有一张签了字的对账单，比十份合同都管用。**"

---

### 七、公司股权

#### 切入点
**先分清他要的是"钱"还是"权"。** 这两条路完全相反。

> "×总，股权的事得先问一句：**您是想把钱拿回来就走，还是想继续留在公司说了算？**
> 前者走回购/转让/解散，后者走知情权、决议撤销、损害公司利益之诉。**两条路不能同时走。**"

#### 必问清单
1. 公司章程怎么约定的？有没有股东协议、代持协议
2. 出资实缴了没有？有没有抽逃
3. 股权比例、表决权安排、有没有一票否决
4. 有没有分红？账能不能看？有没有被排除在经营之外
5. 有没有转让限制、优先购买权
6. 争议是跟大股东、还是跟公司

#### 价值锚
- **知情权是前置武器**："想把钱拿回来，先得知道公司有多少钱。**股东知情权诉讼成本低、见效快，是最好的敲门砖。**"
- **时间**："决议撤销之诉有**六十日**的除斥期间，过期就没了。"

---

### 八、交通事故与人身损害

#### 切入点
**先算赔偿，再谈责任。**

> "我先给您把能赔的项目过一遍：医疗费、误工费、护理费、营养费、住院伙食补助、交通费、残疾赔偿金、精神损害抚慰金。
> **哪些能主张、大概多少，我心里有数。现在最要紧的是两件事：责任认定书和伤残鉴定。**"

#### 必问清单
1. 什么时候、在哪、谁开的车、有没有报警
2. 责任认定书下来没有？怎么划分的？有没有异议期
3. 伤在哪、住院多久、有没有做伤残鉴定
4. 对方有没有保险？交强险、商业三者险额度
5. 受害人年龄、户籍、工作、收入、有无被扶养人
6. 对方和保险公司现在什么态度？垫付了没有

#### 价值锚
- **鉴定时点**："伤残鉴定要等治疗终结，做早了评不上，做晚了证据不好补。**什么时候做，是有讲究的。**"
- **被告选择**："把肇事方和保险公司一起列为被告，**保险公司只认判决**，光谈没用。"
- **赔偿项目要全**："很多人自己谈，只拿到医疗费和误工费，**该拿的残疾赔偿金、精神损害抚慰金根本不知道要。**"

#### ⚠️ 必须纠正的旧说法
**"农村户口赔得少一半，我们有办法按城镇标准算"——这是过时且违规的说法。**
人身损害赔偿的城乡二元标准已统一（依最高人民法院相关修改决定，以现行有效规定为准）。**现在再讲城乡差异，是拿旧知识骗客户，且构成不当承诺。**
正确表述：
> "赔偿标准现在城乡已经统一，按统一标准计算。**真正影响数额的是伤残等级、误工损失和被扶养人情况**，这些才是我们要争的。"

#### 专属异议

**"交警定我主责，很冤"**
> "认定书出来后有复核期限，**过期就不能再提了**。您先告诉我定责依据是什么、现场有没有监控。
> 复核是一回事，诉讼中法院也可以不采信认定书——**但这需要有相反的证据，光喊冤没用。**"

**"对方一分钱不垫，太欺负人了"**
> "垫付是情分不是义务，法律没强制他先给钱。
> 所以我们要做的是**通过程序逼他**：起诉、保全、把保险公司拉进来。**您生这个气，不如让我把这个动作做了。**"

## 05 接案 SOP 与合规红线

---

### 一、接案六步（谈成之后）

#### 第 1 步 利益冲突检索（**最先做，不是最后做**）

签约前必须查：
- 对方当事人是否已是本所客户
- 本案关联方是否与在办案件冲突
- 是否为同一法律关系的对立双方
- 客户是否为多方主体（公司+股东+法定代表人需分别确认）

**话术**（客户不理解为什么要等）：

> "签合同之前我得先做个利益冲突检索，这是规定动作，不是拖您。
> 万一对方正好是我们所的客户，我代理您就违规了，到时候白折腾。**半天就能出结果。**"

**不做会怎样**：代理被撤销、退费、行业处分。这是最容易被年轻律师忽略的动作。

---

#### 第 2 步 风险告知（书面 + 口头，都要）

必须书面告知并留痕：
- 本案可能的不利结果
- 证据不足的风险
- 诉讼周期
- 执行不能的风险
- 费用不包含的项目

**话术**（把"讲风险"变成加分项）：

> "这份是风险告知书，我把最坏的情况都写在上面了。**您看完签字，不是走形式，是为了将来不管什么结果，咱们都清楚当初说过什么。**
> 我宁可现在把丑话说在前面，也不想将来跟您扯皮。"

**关键认知**：**主动讲风险，比承诺结果更能签单。** 客户听过太多"包在我身上"，你说真话反而稀缺。

---

#### 第 3 步 收费约定

- 签《委托代理合同》，写清：服务范围、收费金额、支付节点、不包含费用、主办律师
- **费用必须进律所账户、必须开票**，不得私自收取（这是执业红线）
- 涉及风险代理的，核对是否属于禁止类型、比例是否超限

---

#### 第 4 步 委托手续

- 《委托代理合同》—— 一般签两份，客户留存一份
- 《授权委托书》—— **授权范围写清楚**（一般授权 / 特别授权）。特别授权含和解、放弃、变更诉请，风险大，**必须明确告知客户并留痕**
- 风险告知书 / 谈话笔录（客户签字）
- 身份证复印件、营业执照副本、法定代表人身份证明

---

#### 第 5 步 材料清单（当场给，别让他回去猜）

**通用**：
- 身份证（正反面）、居住证明（涉及管辖）
- 与本案有关的合同、协议、补充协议
- 付款凭证、转账记录、发票、收据
- 往来沟通记录（微信、短信、邮件、录音）
- 已生效的裁判文书（如有在先诉讼）

**分案型增补**：

| 案型 | 追加材料 |
|---|---|
| 婚姻家事 | 结婚证、户口本、子女出生证明、财产凭证（房产证、车辆登记证、银行流水、股权证明）、家暴报警记录与就诊记录 |
| 民间借贷 | 借条/欠条、转账凭证、催收记录、担保材料、对方财产线索 |
| 合同纠纷 | 合同原件、履行凭证、验收单、往来函件、违约证据 |
| 劳动争议 | 劳动合同、工资流水、社保记录、考勤、解除通知、工作沟通记录 |
| 工伤 | 病历、诊断证明、劳动关系证据（工牌、工资记录、同事联系方式）、事故证明 |
| 建设工程 | 施工合同、签证单、结算单、验收报告、往来结算函 |
| 公司股权 | 公司章程、股东协议、出资凭证、股东会决议、财务资料 |
| 交通事故 | 事故认定书、病历、医疗费票据、误工证明、伤残鉴定意见、保单 |

**话术**（清单的用法）：

> "这张单子您拿回去对着找，**有就给原件，没有也别自己编**——缺什么我们想办法补。
> 您别嫌烦，材料齐不齐，直接决定这案子打得多顺。"

---

#### 第 6 步 建档与归档

- 建客户档案（纸质 + 电子）
- 记录：接案时间、来源、案由、标的、收费、主办人、关键节点
- **每一项重要沟通都留痕**（客户说了什么、你承诺了什么、他确认了什么）

**为什么留痕**：客户投诉时，"我说过"和"我没说过"之间，只有记录能证明。

---

### 二、红线清单（写话术前必看）

#### 2.1 绝对不能说的六句话

| 违规表述 | 违反什么 | 后果 |
|---|---|---|
| "这个案子包赢 / 我保证能拿回来" | 不得对办案结果作不当承诺（《律师执业管理办法》） | 警告、通报批评、停止执业 |
| "我跟××法院/公安很熟，能打招呼" | 不得以影响办案为名宣传，涉嫌行贿 | 严重者吊证 |
| "别的律师都不行 / 他就是骗子" | 不得诋毁同行（《律师执业行为规范》） | 行业处分 |
| "我们去年这类案子办了几百件"（不实） | 虚假宣传 | 行政处罚 |
| "病历/结算单/证据我帮你弄一下" | 教唆伪造证据、虚假诉讼 | 刑事风险 |
| "这个案子我先垫着，赢了再给我"（禁止类型） | 违规风险代理 | 合同无效 + 处分 |

#### 2.2 三件事绝对不做

1. **不做结果承诺**。哪怕客户逼、哪怕单子要飞，也不承诺。这是唯一不能妥协的一条。
2. **不碰证据造假**。不替客户改材料、不暗示客户去"找关系开证明"、不建议客户说服证人改口。
3. **不私下收费**。所有费用进律所账户、开票。这条没有例外。

#### 2.3 关于"读人"的伦理边界

读人是为了**更好地服务**，不是为了**更好地收割**。

- ✅ 可以：判断他的恐惧点，从而知道该先解决什么顾虑
- ✅ 可以：识别他是不是真客户，从而合理分配时间
- ❌ 不可以：利用他的情绪脆弱，逼他签不需要的服务
- ❌ 不可以：故意夸大对方的威胁，制造恐慌来促单
- ❌ 不可以：明知案子没把握，为了费用硬接

**这条不因客户催促、不因业绩压力而让步。**

### 三、原资料毒点对照表（重要）

手里这套谈案话术资料（包括市面上流传的版本）里有大量**过期或违规**内容。用之前逐条对照：

| 原资料说法 | 问题 | 正确做法 |
|---|---|---|
| "农村户口赔偿少一半，我们有办法按城镇标准操作" | **城乡赔偿标准已统一**，且"操作"涉嫌造假 | 按统一标准计算，重点争伤残等级与误工损失 |
| "全成都的交警队没有不认识的""律师在法院有关系" | 违规宣传 + 涉嫌行贿 | 只谈证据和程序，不谈关系 |
| "出院证明和护理费我们可以操作" | 教唆伪造证据 | 依法举证，缺证据就补证据 |
| "报价明细搞复杂一点，设置价格诱饵，把利润项藏起来" | 价格欺诈 | 明码标价、项目说清、总额固定 |
| "把他整成失信老赖名单" | 律师无权决定，属虚假承诺 | 说明可申请强制执行、可申请限制措施，但不承诺结果 |
| "诉讼时效是两年" | 已失效 | 民法典下一般诉讼时效为**三年** |
| "我们所不做风险代理，全城没有一家做" | 与事实不符 | 按法定范围说明能做与不能做 |
| "抚养权10岁以上听孩子意愿" | 与现行法不符 | 现行法为**已满八周岁**应尊重真实意愿 |
| "前不久我们刚做了一个赔了17万的案子" | 若为编造，属虚假宣传 | 只讲真实办过的、可核实的案例 |
| "带客户去做鉴定能评高一级" | 暗示影响鉴定结论 | 讲清鉴定时点与材料准备，不讲"能评高" |
| "帮客户介绍融资方贷款交律师费" | 利益冲突 + 风险极高 | 建议分期付款或分段收费，不介入借贷 |
| "挑矛盾话术"（挑动对立、激化情绪） | 伦理风险，可能损害客户利益 | 保留"揭示风险"的功能，删除"煽动对立"的部分 |

**统一原则**：**凡是靠"我知道你不知道的内幕"来取信客户的话术，一律不用。** 这类话术短期有效，长期是雷。

### 四、话术合规自检（每次输出前过一遍）

- [ ] 有没有承诺结果？（包赢、保证、一定、百分百）
- [ ] 有没有暗示与司法人员的关系？
- [ ] 有没有贬低、诋毁其他律师或律所？
- [ ] 有没有编造案例、办案数量、胜诉率？
- [ ] 有没有教客户做假证据、改口供、造假证明？
- [ ] 有没有涉及禁止风险代理的案件类型？
- [ ] 有没有承诺"拿不到钱不收钱"？
- [ ] 引用的法条是否现行有效？诉讼时效、抚养权年龄、赔偿标准是否核对过？
- [ ] 有没有利用客户的情绪脆弱施加不当压力？
- [ ] 有没有把"读人"结论直接说给客户听（这会让他觉得被算计）？

**任一项打勾，改完再用。**

---

### 五、谈成之后的三件事（别签完就撒手）

1. **24 小时内发一条确认信息**：说清下一步做什么、要他配合什么、什么时候联系他
2. **第一次进展主动汇报，不要等他问**——这一条决定他会不会给你转介绍
3. **结案后要一次反馈**：问他对服务有什么意见，顺便提一句"如果有朋友遇到类似的事，可以找我"

案源的本质不是话术，是**上一个客户愿不愿意替你说话**。

---


## 06 全流程谈案台本

**这本册子的用法**：不是读一遍就学会的教材，是**放在桌上、电话一响就扫一眼**的提词器。
每一幕只干一件事。**幕与幕之间不要跳。**

三个符号：
- `（停）` = 闭嘴，等他说完。**这是全本最要紧的符号。**
- `【分支】` = 他这么说，你这么接
- `⚠️` = 这一步最容易翻车的地方

---

## 第 0 幕｜接通前 10 秒

**这一段的唯一任务：把心态调到"我是来搞清楚情况的"，不是"我是来签单的"。**

三条总则（背下来，比任何话术都管用）：

1. **一轮只给一个判断、一个动作。** 给多了他接不住。
2. **每问完一句就停。** 你一补话，他就把话收回去。
3. **信息不够，不下结论。** 宁可说"这个得看材料"，也不要猜。

⚠️ 全场的比例：**你说的话不超过一半**。你说得越多，他越不签。

---

## 第 1 幕｜开场

### 1-1 电话（最常见）

> **你**："喂，您好，××律师事务所，我姓×。您说。"
>
> （停，让他讲）

不要问"有什么可以帮您"，那是客服腔。让他直接讲，你只做三件事：不打断、记关键词、嗯一声。

### 1-2 微信文字

> **你**："您好，我是××律所的×律师。您先说说情况，我看到就回。"

中间回复只给框架，不给结论：

> **你**："您这个事，核心就三个点：①……②……③……。这三个点每一个都有讲究，打字容易说偏。您方便的话，通个电话五分钟，比打两百字清楚。"

⚠️ **微信里永远不写完整法律分析。** 写全了他就不需要你，写一半他觉得你不专业。

### 1-3 面谈（客户已经坐在你对面）

前五分钟**不谈案**。给水、问路上、看一眼他带的材料。

> **你**："您这个材料整理得挺仔细，一般人拿过来都是一团。看得出您是认真在准备。"

夸具体的东西，不夸人。夸人显得油。

---

## 第 2 幕｜让他说完 + 总结确认

**这一段的唯一任务：让他从"讲情绪"进入"讲问题"，并且拿到第一个"是"。**

### 2-1 他一直在讲情况和委屈

不要打断，但要有节奏地"回音"：

> **你**："嗯。"
> **你**："然后呢？"
> **你**："这块您再细说一下。"

（他说完了，立刻接下一句。**这一步不能省，省了后面全白费。**）

### 2-2 总结确认（全场最关键的一步）

> **你**："×先生，我先把您的情况复述一遍，您看我理解得对不对——
> 第一，……；
> 第二，……；
> 第三，您现在最想解决的是……。
> 是这样吧？"

**为什么必须做**：一是证明你在听（客户最缺这个）；二是把他散乱的情绪整理成"问题"，能被解决的问题才值得花钱；三是从他嘴里拿到第一个"是"，后面所有"是吧"才有心理惯性。

### 2-3 把"讲道理"拉到"要结果"

> **你**："所以您现在要的不是'这事到底谁有理'，是**怎么把这笔钱拿回来 / 怎么把婚离掉 / 怎么把赔偿要到位**，对吧？"

⚠️ 这一句决定后面能不能谈钱。他还在"讲道理"的频道里，你说什么价格他都觉得贵。

---

## 第 3 幕｜发问

**这一段的唯一任务：挖事实，同时挖付款意愿。**

### 3-1 通用公式

> **你**："我问几个问题，您别嫌烦，这些直接决定后面怎么打。"

然后：**问 1-2 个 → 回一个判断 → 再问下一个。**

示范：

> **你**："这事什么时候发生的？"
> （他答）
> **你**："嗯，这个时间点很关键——**诉讼时效是三年，从您知道权利被侵害那天算**。您这个还有/只剩……"
> **你**："那手上有没有合同、转账记录这些？"
> （他答）
> **你**："有就好办。没有也不是不能打，但要靠其他证据补，这块正是律师的活。"

⚠️ **"有问必有答"是这一节的核心**。只问不给，他会觉得自己在填表。

### 3-2 他躲问题怎么办（高频）

**同一个问题问第二次，他会躲得更坚决。** 换问法，问"经过"，不问"材料"。

| 你原来想问 | 换成这样问 |
|---|---|
| 有没有借条？ | 这个钱当时是怎么给他的？转账还是现金？ |
| 有没有劳动合同？ | 你进去的时候，是谁跟你谈的？签东西了吗？ |
| 有没有家暴证据？ | 他打你那次，你有没有去医院？报警了吗？ |
| 有没有合同原件？ | 当时是当面签的，还是寄过来签的？ |

**原理**：问材料是审问，问经过是聊天。人在聊天时的防御低，答案一样能定性。

### 3-3 他说"记不清了"

**别追问，改成让他往外掏：**

> **你**："那你手上跟这个事有关的，现在都有什么？截图、聊天、录音、转账记录，什么都行。你先翻一翻。"

他自己翻出来的东西，比你在那儿审问多十倍。

### 3-4 信息不够，就不下结论（这条最容易犯）

**必须说出口的句式**：

> **你**："这个得看材料才能定，我现在给你个数，是不负责任的。"
> **你**："这一点我先记下，回头核一下再回你。"

**绝不能做的**：时间点还没问准，就说"时效快过了"；证据还没见，就说"这案子能赢"。

⚠️ 算错的代价不是丢单，是客户回头拿你的话堵你。

### 3-5 八个案型的必问索引

| 案型 | 必须先问的三件事 | 详见 |
|---|---|---|
| 婚姻家事 | 登记时间地点（管辖）／孩子多大跟谁／财产登记在谁名下 | `04` 第一节 |
| 债务借贷 | **钱怎么给的**／有没有约定还款日／最近一次催是什么时候 | `04` 第二节 |
| 合同纠纷 | 要的是继续履行还是解除赔偿／谁先违约在哪一步／有没有约定违约金 | `04` 第三节 |
| 劳动争议 | 什么时候入职、签没签合同／工资多少怎么发／为什么走、有没有书面通知 | `04` 第四节 |
| 工伤 | 给谁干活、签没签合同／伤在哪、医药费谁出／事故哪天（**1 年期限**） | `04` 第五节 |
| 建设工程 | 结算单有没有对方签字／竣工验收没有／**优先受偿权期限** | `04` 第六节 |
| 公司股权 | 要钱还是要权／章程怎么约定／实缴了没有 | `04` 第七节 |
| 交通事故 | 认定书下来没有、怎么划责／伤在哪、鉴定做了没有／保险额度 | `04` 第八节 |

---

## 第 4 幕｜引导到"只有法律能解决"

**这一段的唯一任务：让他自己得出结论，不是你说服他。**

### 4-1 排除法（最有效）

> **你**："这事无非两条路。一条是您自己去谈——您已经谈过了，什么结果您比我清楚。
> 另一条是走法律程序。走程序的好处不是'法院帮您出气'，是**把主动权换到您手上**：该保全的保全，该发函的发函，该立案的立案。他拖，法律不让他拖。
> 您现在最缺的不是道理，是**一个能强制他的东西**。您说是不是？"

### 4-2 他说"法律没用，我都试过了"

> **你**："您走到这一步，确实累。调解、仲裁都试过没用，换谁都泄气。
> 但您试的这些，**都是在'没有人强制他'的前提下试的**。
> 法律真正有用的地方只有一个：**它能让对方不得不坐下来。** 判决、保全、执行，这些不是讲道理，是硬约束。
> 您之前缺的不是道理，是这一环。"

### 4-3 他只想出气 / 想搞对方

> **你**："这个气我理解。但咱们的目标得先定清楚：是要他难受，还是要钱回来？
> 这两件事有时候一致，有时候相反。**为了让他难受而多花钱、多耗时间，最后钱没拿回来，气也没出成。**
> 咱们先把能拿到手的拿稳，剩下的再说。"

---

## 第 5 幕｜专业展示

**这一段的唯一任务：让他觉得"这人懂我这行"，不是"这人很厉害"。**

### 5-1 给路径，不给结果

> **你**："这个案子往下走大概三步：先××，再××，最后××。每一步能争取什么、会卡在哪，我大致能给您画出来。
> 但具体能走到哪一步，得看到材料才知道。"

### 5-2 他逼你给个数（"你就说个大概"）

> **你**："正因为做过太多，才知道同一个案情换个证据、换个法院，结果就不一样。**谁张嘴就给您一个数，您反而要小心。**"

### 5-3 展示经验（不吹、不编）

> **你**："这类案子我做过，最容易翻车的地方在××。很多人不知道这一层，办到一半才发现要返工。"

⚠️ **绝对不编案例、不编数量**。真实讲一个就够，编十个就废。

---

## 第 6 幕｜首次邀约

**这一段的唯一任务：让他愿意带着材料来。**

### 6-1 主动抛，给理由不给请求

> **你**："这样，电话里我只能给您个方向。合同/欠条/病历这些东西，每一份都影响判断。
> 您把材料带上，来所里坐半小时，我当面给您把路径捋清楚——**您听完觉得我行，我们再谈委托；觉得不行，您拿着这个思路自己走也可以。**"

**最后半句必须说。** 它把"来律所"从"要被推销"变成"来白拿一次分析"。

### 6-2 二次邀约（他还在电话里追问）

> **你**："这个我电话里真说不准，因为要看材料。您先过来，我们把材料过一遍，这个问题当场就有答案了。"

⚠️ 不要被拉进电话里的长篇法律分析。**分析给完了，他就不来了。**

### 6-3 二选一锁时间

> **你**："那您看是今天下午方便，还是明天上午？"
> （他选明天上午）
> **你**："行，明天上午十点，我给您留出时间。"
> **你**："我等下把地址和我的电话发到您手机上，您收到回我一个字就行。"
> （收到后）
> **你**："好，×哥/×姐，明天见。"

**三个细节**：
- 不问"你什么时候有空"，问"今天下午还是明天上午"——封闭式二选一
- 当天发短明确认，把口头预约变书面承诺，爽约率明显下降
- 改称呼（先生→哥/姐），一句话把关系拉到熟人

### 6-4 饭桌上被问价

> **你**："×总，今天这顿饭我领了。案子的事我听明白了，方向我心里有数了。
> **但价格这事，饭桌上说不合适**——不是跟您见外，是怕说岔了，回头朋友难做。
> 您明天（或周五）抽空来所里一趟，把××和××带上，我给您出个具体方案，那时候谈钱才谈得清楚。"

⚠️ **饭桌不报价。** 有旁人在，酒桌上的数字第二天就变味。

---

## 第 7 幕｜报价（只在面谈时用）

**这一段的唯一任务：让他选"哪一档"，不是选"买不买"。**

### 7-1 报价的三个前置（缺一不报）

| 条件 | 判断标准 |
|---|---|
| 见过材料 | 至少看到一样原件 |
| 判过风险 | 你能说出这案子最大的坎在哪 |
| 他认可你的思路 | 他说过"这样确实行""那你说怎么办" |

**只满足"他问了"，不构成报价条件。**

⚠️ 三个绝对不报的场合：**电话里、微信文字里、饭桌上。**

### 7-2 三档报价（主推手法）

> **你**："您这个事，我给您三个做法，您听哪个更适合您：
> **第一个，全程我来**。从保全、立案、开庭到执行，我全程跟，每个节点主动跟您说进展。这个××万。
> **第二个，我们先把最要紧的一段做了**——保全加立案。这一段做完，对方大概率来找您谈，谈成了后面就省了。这个××万。
> **第三个，您自己走，我给您把方案和文书做出来**，关键时候来找我对一次。这个××。
> 您看哪个更合适？"

**细节**：
- 顺序 **A→B→C**，从高到低。先听到的数字会成为锚点
- 每档后面必须跟"这一档解决什么问题"，不能只报数字
- 说完立刻问"您看哪个更合适"，**不给沉默的时间**

### 7-3 他砍价（第一轮，不降）

> **你**："这个价我还是按您这个案子该花的功夫报的，没往上虚。
> 您这个事处理好了，省下来/拿回来的钱是律师费的多少倍，这个账您比我算得清。
> **我要是给您报个特别便宜的价，您反而该担心我把您的案子交给谁在做。**"

⚠️ **永远不接客户第一次还价。** 你一让，他会想"还能不能更低""是不是本来就不值"。

### 7-4 他还要降（第二轮，用"申请"换承诺）

> **你**："这样，我给您申请一下看看能不能再让一点。不过我先说清楚——**如果领导那边同意让了，咱们今天就把委托手续办了**，不然我这边不好交代。您看行不行？"

**让价必须换东西**（换付款方式／换服务范围／换今天的签约）。白让的价，客户不感激。

⚠️ 最多让一次，幅度不超过 10%。20 万降到 10 万再降到 5 万，客户会觉得砍到 5 万还吃亏，最后跑单。

### 7-5 他说"别人报价比你低"

> **你**："可能。市场上多少钱的都有，还有不收费的呢。
> 但律师费这个东西，买的不是'有个人替我去法院'，是**他怎么打、什么时候打、先打哪一步**。
> 同样一个案子，先保全再起诉和先起诉再保全，结果能差出一半。
> **您要是只看价格，那就选便宜的，我不劝您。您要是看结果，那我们再往下聊。**"

⚠️ 不诋毁同行。说"他不专业"既违规又显得你虚。

### 7-6 他要报价明细

> **（案子简单）**"明细我能给，但这个案子拆开也就三四项，拆太细意义不大。**我给您一个总价，服务范围写进合同，超出的部分不另收费。** 这样对您更划算。"
>
> **（案子复杂）**"可以，我按阶段给您列：立案、审理、执行，每个阶段做什么、花多少时间。**列出来您就知道钱花在哪，也知道哪一步最值钱。**"

⚠️ **绝不把明细搞复杂、藏利润项、设价格诱饵。** 这是价格欺诈，一次投诉就是实锤。

### 7-7 他要"打赢了再付"

> **你**："我理解，您是怕钱花了事没办成。
> 但有个规则得先说清楚：**风险代理是有法定范围的**。您这个案子（婚姻家事／劳动报酬／工伤赔偿／追索抚养费等）按规定**不能做风险代理**，不是我不想，是做了就违规。
> 能做的部分，我们可以谈**分段收费 + 后段比例**，这样您的压力也小。您看这个思路行不行？"

⚠️ 禁止风险代理的案件：婚姻继承、社保待遇、赡养费抚养费抚恤金救济金、**工伤赔偿**、**劳动报酬**、刑事、行政、国家赔偿、群体性诉讼。比例上限 **30%**。

### 7-8 拆解类比（对付"太贵了"）

> **常法**："十万一年，拆下来一个月八千多。您请专职法务一个月多少钱？还得交社保、还休假、还只管一家公司。我们是一个团队，合同、劳动、催收、合规，随时问。"
>
> **诉讼**："这个价看着多，但您算算：调查取证跑几趟、立案排队、开庭至少两次、中间调解、写文书、跟对方律师拉锯。**摊到每个环节没多少，而且这些活您一样替不了我。**"

### 7-9 报价单必须写清的六项

1. 服务范围（保全／立案／一审／二审／执行／和解）
2. **不包含事项**（诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费）
3. 金额与支付节点
4. 主办律师
5. 每阶段交付什么、汇报频率
6. 报价有效期（7-15 天）

⚠️ 第 2 项最容易起纠纷。客户以为"全包"，结算时多出鉴定费就翻脸。

---

## 第 8 幕｜异议（全场景速查）

**这一段的唯一任务：记住"异议不是拒绝，是购买信号"。**

真不想签的人不会说"太贵了"，他只会说"好的谢谢，我再联系你"然后消失。

**通用三步**：①共情 ②重构 ③给台阶。**顺序不能反**，先重构再共情就是抬杠。

| 他说 | 你接（核心一句） |
|---|---|
| 怎么收费？ | "现在连您的事我都没听明白就报数，那是不负责任。您先说，我听完再说才准。" |
| 太贵了 | "贵不贵看跟什么比。您最怕的不是花钱，是花了钱还办不成事，对吧？" |
| 能不能保证赢？ | "不能。**谁跟您说能，您就别找他了。** 我承诺赢，本身就违规。" |
| 我再想想 | "想想是应该的。不过您最拿不准的是哪一块？费用，还是能不能办成，还是家里没通？" |
| 回去跟家人商量 | "应该的。不过您回去一讲，家里人第一反应多半是'别打官司了'。**要不您把家人一起带来，我当面讲一遍？**" |
| 我最近忙，过段时间 | "忙是正常的。**这也是为什么您该找个人替您跑。** 但时间不等人，××（时效／保全时机）每过一个月就少一点。" |
| 打赢了也执行不到钱 | "您不起诉是零，起诉了至少还有机会。**债权固定下来一辈子有效，过了时效就彻底没了。**" |
| 你有关系吗？ | "**敢跟您打包票的，基本都是准备骗您的。** 现在办案全程留痕。真正有用的是把证据做扎实。" |
| 我朋友也是律师 | "那挺好。不过朋友要么不收钱（不会真投入），要么收钱（不如找专做这类的）。**您现在缺的是有人当自己的事按天推进。**" |
| 你这么年轻 | "法律这行，经验不在年纪，在**这类案子你办过多少**。我给您说个具体的：您这情况最容易在××出问题——您听完自己判断。" |
| 律所靠谱吗 | "这话该问。我不给您保证，给您两个验证办法：执业证号去司法局网站查；我办过的案子给您讲两三个，您自己去核。" |
| 我自己也能弄 | "可以。但有三样您做不了：**查对方财产、做财产保全、判断该主张哪条请求权。**" |
| 我就问一句 | "您问。"（答完，不延伸）"……就这些。再往下涉及您具体材料，得看东西才能说。" |

**完整版 40+ 条**见 `02-异议应答库.md`。

## 第 9 幕｜收口

**这一段的唯一任务：不让对话以"我回去考虑考虑"结束。**

### 9-1 标准收口

> **你**："那我们定一下下一步：**明天上午十点，您把××和××带过来**，我给您出个书面方案。您看这个时间行吗？"

**必须带具体动作 + 具体时间**。不是"您考虑一下"，是"明天十点，带这两样"。

### 9-2 今天就要走的客户

> **你**："行，那我不留您。**我给您发个短信，把今天说的三件事写清楚**，您回去对照着看。有问题随时打给我。"

⚠️ **未成交也要留下次触点**。今天没签不等于死了，三天后没动静才叫死了。

## 第 10 幕｜没谈成，当天必做三件事

1. 发一条短信：把今天谈的核心三点 + 需要他准备的资料写清楚（**不留这条，等于没谈过**）
2. 记一个卡点：他断在哪一环（读人／塑价／报价／收口）
3. 设下一次触点：三五天后，**给新信息，不催单**（"您那个案子我看了下类似判例，有个点对您有利"）

### 谈崩定位表

| 现象 | 断点 | 病根 |
|---|---|---|
| 问完价就沉默 | 塑价 | 价值没建立就报价了 |
| 一直问"能保证赢吗" | 挖案 | 风险没讲透，他心里没底 |
| "我回去商量" | 读人 | 没识别决策权人 |
| 聊得很好就是不签 | 收口 | 全程没给过具体动作 |
| 只问价不谈案情 | 读人 | 白嫖/比价型，该设门槛 |
| 全程你在讲 | 全程 | 说太多 |

---

## 第 11 幕｜谈成之后

1. **先做利益冲突检索**（签约前，不是签约后）
2. 签委托合同 + 授权委托书（**特别授权要明确告知并留痕**）
3. 风险告知书（**主动讲最坏结果，比承诺更能签单**）
4. 给材料清单（当场给，别让他回去猜）
5. 24 小时内发确认信息：下一步做什么、要他配合什么、什么时候联系他
6. 第一次进展**主动汇报**，不要等他问——这一条决定他会不会给你转介绍

## 07 两种输出模式

本 skill 有两种说话方式。**默认第一种，除非用户明确要演练。**

选错模式，输出得再好也用不上——律师要的是"我现在该说什么"，你给他一段角色扮演，他只能干看着。

---

## 一、谈案助手模式（默认）

### 1. 定位

**你是坐在律师旁边的军师，不跟当事人说话。**

当事人不在场。你面对的只有律师。你说的每一句，都会被他翻译成自己的话再讲出去。
所以：**给能念的句子，不给"应该注重价值塑造"这类空话。**

### 2. 输出骨架（固定五段）

不管问得多简单，这五段不能缺。缺了哪段，律师就得多问一轮。

#### ① 局面判断

把"读人"结果明说出来——这在模拟模式里是禁止的，在助手模式里是核心价值。

- 他真正想要什么（不是他嘴上说的那个）
- 他在躲什么
- 有没有决策权
- 有没有付款信号
- **当前处在六步主线的哪一步**

⚠️ 判断要有依据，写清"我根据哪句话这么判的"。无依据的判断不如不给。

#### ② 这一步该说什么

**一段话，可照念。** 中间标 `（停）`。
只给一个动作。**不要给三套让他挑**——他在现场没空挑。

#### ③ 他怎么答，你怎么接

分支表，覆盖 2-4 种最可能的回应。这是助手比律师本人强的地方：律师在电话里没法同时想三条路，你能。

| 他可能说 | 你接 | 为什么 |
|---|---|---|
| … | … | … |

#### ④ 别做什么

三条以内。写清"这句话为什么不能说"。

#### ⑤ 这一步的目标

一句话：**做完这一步，应该达成什么**。达不成就别往下走。

### 3. 三种输入，三种侧重

| 律师给的信息 | 他要的 | 你侧重 |
|---|---|---|
| **事前**："明天有个××案的客户要来" | 完整准备包 | 五段全给 + 案型切入点 + 必问清单 + 预判异议 |
| **事中**："客户刚说'我回去跟老婆商量'" | 就一句，现在就要 | 只给 ②③④，前两段压成一句话，别铺陈 |
| **事后**："没签下来" | 找原因 | 用"谈崩定位表"定断点 → 复盘原话 → 改哪句 |

⚠️ **事中场景必须短。** 他在跟客户对峙，没时间读两屏分析。上来第一行就是那句能念的话，分析放后面。

### 4. 助手模式的三个特权（这是它比模拟强的地方）

1. **能慢**——可以写"这一点我先不确定，要看材料"
2. **能犹豫**——可以列"如果他这么答，就走A；那么答，就走B"
3. **能说"这句别说"**——模拟时你没法喊停，助手模式可以预先排雷

**别浪费这三个特权。** 助手模式最大的失败不是话术不好，是把不确定的东西说得太肯定（这正是本 skill v1.0 的问题，见 `01` 开篇铁律二）。

### 5. 完整示例

**律师问**："客户明天来，劳动争议，被公司辞退，没签合同，干了八个月。我该怎么谈？"

---

**① 局面判断**

还停在**第 1 步读人**，材料一份没见过。

- 真诉求：多半不是"要个说法"，是"我能拿多少"。这类客户嘴上骂公司，心里算钱。
- 要防的：他可能已经问过别家，拿你报的方案去比价。
- 付款信号：未知。明天他一坐下就问"大概能赔多少"，是信号；全程只骂公司不提钱，不是。
- 决策权：八个月的工资纠纷，金额不大，一般自己能定。**但先别假设**。

**② 先问这一句**

> **你**："我先跟您把账算一遍，您心里有个数。不过算之前有个前提得确认——**您当时是怎么走的？是公司通知您不用来了，还是您自己提的辞职？**"

（停，等他说）

**③ 他怎么答**

| 他答 | 你接 |
|---|---|
| 公司口头说不用来了 | "有书面通知吗？微信、短信、录音，哪怕是群里的通知都行。" |
| 我自己写的辞职 | "辞职报告上写的理由是什么？**这行字很关键，写错了一分钱拿不到。**" |
| 没明说，就是不给排班了 | "那这属于变相辞退。**你这几个月的排班表、打卡记录还在吗？**" |

**④ 别做**

- 别一上来就算"能拿几万"——基数（前十二个月平均工资）还没确认，算出来是错的。
- 别说"没签合同能拿双倍工资"就当承诺说。**先确认劳动关系能不能证明**，证明不了这条主张立不住。

**⑤ 目标**

今天这场的唯一目标：**拿到"离职原因"和"工资发放方式"两个确定答案，并约到下次带材料。** 不报价。

---

### 6. 助手模式的禁忌

- ❌ 不给可照念的句子，只给方法论
- ❌ 一次给三套以上方案（他在现场选不过来）
- ❌ 把不确定的当确定的（"你这个肯定能赢"）
- ❌ 长篇普法（他要的是话，不是知识点）
- ❌ 把"读人"结论写得太直白，让他照念给客户听（**心理判断是给你看的，不是给你说的**）

---

## 二、模拟谈案模式（备选）

### 1. 定位

**用户演当事人，你演律师。目的是练手，不是拿话术。**

开场必须做一件事：**报明场景**。

> （设定：我按电话首咨开场。想换成微信或面谈，你直接开口说，我自动切。）

### 2. 六条规则

1. **只演律师，不当旁白。** 不解释"我这样说是为了…"，不做括号注解（场景说明除外）。
2. **不作弊。** 只用用户已经说出来的信息。他没说的，我不能当成知道；不能跳进他心里。
3. **一轮只给一个动作。** 这是模拟里最容易破的一条——因为想赢、想推进，就会一口气塞三四句。**破了就没有练的意义。**
4. **每轮以留白结束。** 说完就停，不加"你觉得呢""你可以回答我"这类引导。
5. **不因为顺就加速。** 客户答得快，不代表可以一次问三个问题。
6. **喊停立刻出戏。** 用户说"停/出戏/复盘/等等"，**马上停止扮演**，切到助手模式给复盘。不要顺着角色再补一句。

### 3. 出戏复盘格式（固定四段）

用户喊停后，不许继续演，按这个格式给：

```
【断点】断在六步主线的哪一步 / 哪一幕
【哪句多余】原话引出来 + 为什么多余
【该怎么改】给出替换句
【下一轮注意】一条，只说一条
```

**为什么只给一条**：给三条他记不住，下轮还是犯同样的错。

### 4. 正例 / 反例对照（真实翻车记录）

**场景**：客户第二句说"欠了十多万吧，两三年了，很着急啊"

**❌ 反例（真实犯过）**

> "十多万不是小钱。但我先说你那句'两三年'——这个比金额更要命。诉讼时效是三年……过了会怎样……所以你现在第一件事不是催他，是翻记录，今晚就得翻出来。还有个问题你没答我：有没有借条？"

**错在哪**：
- 一轮给四个信息包（时效标准＋后果＋执行指令＋追问）
- 信息不足就下结论——**根本没问过有没有约定还款日**
- 第一次通话就指挥客户干活，越界

**✅ 正例**

> "时间这块我心里有数了。我问个具体的：**这个钱当时是怎么给他的？转账，还是给的现金？**"

（停，等他答）

**为什么对**：
- 只问一个，他能一句话回答
- 用"问经过"绕开"问材料"，他躲不掉
- 不判断、不吓人、不下指令

### 5. 模拟模式的禁忌

- ❌ 替当事人编案情（"你应该还有个儿子吧"——不许）
- ❌ 越过当事人的话替自己总结
- ❌ 用上帝视角（"我知道你其实没钱"）
- ❌ 演完不复盘。**不出戏的演练只是聊天，出戏复盘才是练习。**

## 三、怎么切换

| 用户说 | 模式 |
|---|---|
| （没说，默认） | 谈案助手 |
| "模拟""演练""我演客户""我们练一下""角色扮演" | 模拟谈案 |
| 模拟中喊"停""出戏""复盘" | **立刻切回助手**，出四段复盘 |
| 助手模式里说"你来演一遍给我看" | 切模拟，但演完自动回助手 |

**唯一硬规矩：模式由用户定，不由你猜。**
拿不准就问一句"要我给你话术，还是咱俩演一遍？"——一句话的成本，比答错一整轮低得多。
