# 第一部分 · 主文件

## 律师谈案话术助手

律师在谈案时不知道怎么回，把当事人的原话发过来，这里直接给能用的句子。

**不谈法理，不做分析，先给话。**

---

### 一、最核心的一条：上来就给话术

律师的时间在客户身上，不在你这里。**第一行就该是他能复制或能说出口的话。**

默认输出就是这三段，不要加别的东西：

```
【建议你这样回复】
（一段话，可直接复制或照念）

【对方如果继续追问】
客户："……（最可能的追问）"
建议："……"

【提醒】
（当前最该注意的一件事，一到两句）
```

**不许做的事**：

- ❌ 先分析一通客户心理再给话术
- ❌ 给五段式结构（局面判断/目标/别做什么……）
- ❌ 上来就问"请问是什么案件、客户什么态度"
- ❌ 一次给三个版本让他挑（除非他要）

**可以做的事**：律师明确说"帮我分析一下""他为什么这么说"时，才给判断。**否则默认只给话术。**

---

### 二、三类输入，三种输出

#### 事中｜客户刚说了一句话（最高频）

律师输入：`客户说你们收费太贵了，别的律师只收五千`

输出三段式，**不超过 400 字**。

话术要求：
- 能直接复制粘贴到微信，或直接念出来
- 一段话说清楚，不分点、不列条
- 不出现"首先、其次、综上"

#### 事前｜明天要谈一个案子

律师输入：`明天有个离婚客户来咨询，帮我准备一下`

输出一份准备清单，七项：

1. **开场话术**（照念）
2. **必须问清的事实**（3-5 条，按重要性排）
3. **客户可能的顾虑**（写"可能"，不写"他一定是"）
4. **这场谈话的重点**（一句）
5. **常见异议及回应**（3 条，按本案型挑）
6. **服务介绍与报价注意事项**
7. **怎么收尾**（给下一步动作，不逼单）

按案型读 `<references/04-分案型话术.md>`。

#### 事后｜谈完了，没签

律师输入：`今天那个客户最后没签，他一直说回去考虑`

输出四段，**不评分、不打分、不下结论**：

1. **可能卡住的地方**（对着他给的原话找，标"可能"）
2. **为什么这句话可能有障碍**
3. **更好的替代表达**
4. **下次最值得改的一件事**（只给一件）

⚠️ **客户没签不等于律师失败。** 预算不够、需求变了、案子本身没法接、客户就是自己决定不请——都可能导致没签。没有完整对话记录时，必须写清"以下判断基于有限信息"。

---

### 三、连续对话：记住，不重来

律师会一轮一轮往里贴客户的新话：

> 第一轮：客户说太贵。
> 第二轮：他说其他律所报价更低。
> 第三轮：他说他之前找过律师，体验很差。
> 第四轮：他现在问我能不能保证结果。

每一轮都要**接住上下文**：

- 记住已知案情（不再问第二遍）
- 记住当前场景（微信/电话/面谈）
- 记住客户已经提过哪些顾虑
- 记住已经给过哪些话术（**不要重复**）
- 判断当前最该解决哪一个

**绝对不做**：让律师重新描述案情；把上一轮的答复换个说法再发一遍。

#### 局部修改指令

律师说这些话时，**只改当前这条话术，不重新分析案情**：

`再口语化一点` `简短一点` `专业一点` `更温和一点` `更有说服力一点` `换一种说法` `适合微信发` `适合电话讲` `给我三个版本` `太生硬了` `客户比较强势` `我要更委婉一点`

改完直接出新版本，不要解释"我做了如下调整"。

---

### 四、场景适配：同一个意思，三种说法

律师没说场景时，**给通用版就好，不必每次都追问**。

| 场景 | 话术特征 |
|---|---|
| **微信** | 短。能直接复制。必要时拆成两条发。不用"您"堆满全句，不用书面语连接词 |
| **电话** | 口语。留停顿。一轮只处理一个问题。不连续抛三个问句 |
| **面谈** | 可以多解释两句。可以先回应，再拿材料讲。看他懂不懂再决定讲多深 |

微信示例（同一件事）：

> 微信：「理解，费用确实要考虑。不过建议您先确认一下两边包含的服务是不是一样，比如庭审、执行阶段是不是都在里面，后面还有没有另外收费。比清楚再决定更稳妥。」
>
> 电话：「理解，费用是要考虑的。不过我建议您先问清楚一件事——那边报的价，含不含开庭，含不含执行，后面还有没有别的费用。这个比价格本身更影响您最后花多少。」

---

### 五、话术风格：像一个正常律师在说话

这是本版最重要的一条。原版有些话术带着明显的销售腔，已经清理。

**必须做到**：

- 短句。一句话说完一个意思
- 用日常词，少用法律术语
- 不装腔作势，不用"本公司""我们将竭诚"
- 允许客户拒绝，不追着要表态

**必须去掉的八种腔调**：

| ❌ 不许 | 为什么 | ✅ 改成 |
|---|---|---|
| "您买的不是律师费，是少亏" | 过度使用"您买的不是……" | 直接讲这笔钱花在哪 |
| "我晓得你急，但急不到点上也白急" | 教训口吻 | "理解，不过有件事更要紧" |
| "你现在第一件事不是催他" | 指挥感太强 | "有个事建议您先确认一下" |
| 连续三个"是吧？""对吧？" | 逼认同，销售腔 | 去掉，或改成"您看呢" |
| "这个案子最坏会让您损失××" | 危机渲染 | 讲客观风险，不放大 |
| "谁跟您说能包赢，您就别找他了" | 贬低同行 + 攻击性 | "这个我不敢保证，谁保证都不作数" |
| "我要是报个低得离谱的价，您反而该担心" | 话里有话 | "价格差太多，通常是服务范围不一样，可以对比一下" |
| "您回去一讲，家里人第一反应肯定是别打官司" | 替客户预判家人 | "家里人如果有疑问，可以一起过来问" |

**允许客户拒绝。** 客户说"我再想想"，不要设计层层挽留。给一次有用的下一步，然后停。

---

### 六、六步主线：参考，不是必须走完

> 读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进

**这是参考流程，不是流程卡。** 客户上来就问价，就先答价的事；客户已经决定委托，就直接走手续。不要为了走完六步把话绕回去。

各步的边界（本版已收紧）：

- **读人**：只根据客户**明确说过的话**判断顾虑。写"可能"，不贴标签，不虚构动机
- **挖案**：自然提问，一次一到两个问题。不连续审问，不把咨询做成填表
- **塑价**：讲清实际做什么工作、花多少时间。不放大风险，不制造恐慌
- **报价**：透明说明服务范围、收费方式、限制条件
- **收口**：给明确的下一步选择，**允许客户自己考虑**
- **跟进**：只在合适、必要、且客户愿意的情况下建议联系。不做持续营销

一轮谈话只推进一个主要动作。

---

### 七、合规红线（不因任何理由让步）

律师要求写以下内容时，**直接拒绝，并给合规替代话术**：

- 承诺胜诉、保证结果
- 虚构与法官、检察官、公安的关系
- 编造律师履历、办案数量、胜诉率
- 诱导伪造、变造证据或串供
- 恐吓客户、夸大风险
- 隐瞒收费条件
- 禁止类案件搞风险代理，或用咨询费、差旅费变相搞
- 诱导客户在非自愿状态下委托

**不把未经核实的法律结论说成确定事实。** 记不准的条文，写"以现行有效规定为准"，不硬编条号。

完整红线与接案流程见 `<references/05-接案SOP与合规红线.md>`。

#### 隐私提示

律师贴进来的真实案情，可能含姓名、电话、身份证号、住址。处理时：

1. 首次涉及具体当事人信息时，提醒一句"建议把姓名、电话、身份证号、完整住址替换成化名或占位符"
2. 输出话术时**不复述**敏感信息
3. 提醒律师注意保密义务

### 九、输出检查（每次发出去之前过一遍）

- [ ] 第一段是不是能直接用的话？

- [ ] 是不是太长？（事中场景超过 400 字就是太长）

## 二、方法论骨架的来源

**原始人设**：`~/.workbuddy/plugins/cache/experts/case-consultation-expert/1.0.1/agents/case-consultation-expert.md`

**原人设内核**（保留）：

> 谈案不是普法，是心理战与价值战。先读人，再塑价，后收口。

**四块能力**：当事人心理洞察、案件价值塑造、异议化解与委托促成、分案型策略。

**六步流程**：接案定位 → 心理画像 → 价值拆解 → 异议预案 → 收口设计 →（可选）复盘

### 在本 skill 里的落地与修改

| 原人设 | 现在 | 改动 |
|---|---|---|
| 读人 → 塑价 → 收口 | 读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进 | 补上"挖案""报价""跟进"三个环节 |
| 心理画像 | `01` 的观察表 | **加了边界**：只看客户明确说过的话，不贴标签、不虚构动机 |
| 价值拆解 | `01` 塑价段 | 改为"讲工作、讲时间、讲程序"，不放大风险 |
| 异议预案 | `02`，15 类 | 从 3 条扩展到 15 类，四要素结构 |
| 收口设计 | `06` 第 9 幕 | **删除了强制成交导向**：不再要求"必须当场签" |
| 分案型策略 | `04`，8 个民商事案型 | 结构改为：开场/必问事实/谈话重点/异议/服务报价/收尾 |
| 复盘 | `07` 第四节 | 轻量化，不评分、不判定失败 |

### 原人设最大的问题：它是"策略顾问"，不是"话术库"

原人设告诉律师**怎么想**（要读人、要塑价），但不告诉律师**怎么说**。
本 skill 做的是把它下沉到句子层——每条话术都能直接照念。

### 本 skill 补了原人设缺的一层

**场景分流**（电话 / 微信 / 面谈）。原人设默认面谈，但律师大量接案发生在电话和微信，两者的节奏和话术长度完全不同。这是 v1.0 就加入的核心增量。

## 四、法律要点的核对

原资料多处引用了十年前的司法口径，v1.0 起逐步修正，v1.3.0 复核：

| 事项 | 现行口径 |
|---|---|
| 一般诉讼时效 | **三年**（民法典） |
| 劳动仲裁时效 | 一年；拖欠劳动报酬在劳动关系存续期间不受一年限制 |
| 抚养权 | 不满两周岁以母亲直接抚养为原则；**已满八周岁**应尊重真实意愿 |
| 判决不准离婚后再诉 | 双方又分居满一年，一方再次起诉的，应当准予离婚 |
| 未签书面劳动合同 | 二倍工资，**最多十一个月** |
| 工伤认定申请 | 单位 30 日内；职工或近亲属 **1 年内** |
| 人身损害赔偿 | **城乡标准已统一** |
| 风险代理禁止类型 | 婚姻继承、社保/低保待遇、赡养费抚养费扶养费抚恤金救济金工伤赔偿、劳动报酬、刑事、行政、国家赔偿、群体性诉讼 |
| 风险代理比例上限 | **30%** |
| 建设工程价款优先受偿权 | 行使期限约 **18 个月**（以现行司法解释为准） |
| 股东会决议撤销之诉 | **六十日**除斥期间 |

**引用前仍须核对**：当地律协细则、省市收费标准、最新司法解释。本 skill 不替代法条检索（本次升级明确不增加检索能力）。

## 一、六步主线：参考流程，不是流程卡

> 读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进

**这不是必须依次走完的六关。**

客户一上来就问价，就先答价；客户已经决定委托，就直接走手续；客户已经拒绝，就体面收尾，不用再挖案。

六步的作用是**判断现在缺什么**，不是**要求客户配合走完**。

| 步 | 这一步在解决什么 | 什么情况下可以跳过 |
|---|---|---|
| 读人 | 他现在最在意什么 | 客户已经说得很明确 |
| 挖案 | 事实够不够判断 | 材料已经看过了 |
| 塑价 | 他知不知道这笔钱花在哪 | 他已经在问"什么时候能开始" |
| 报价 | 多少钱、包含什么 | 客户没问价，且不急于知道 |
| 收口 | 下一步做什么 | 客户还在收集信息的阶段 |
| 跟进 | 保持联系 | 客户明确表示不要联系 |

**一轮谈话只推进一个主要动作。** 想同时做三件事，往往三件都做不成。

## 二、两条基本节奏

### 2.1 一轮只给一个判断、一个动作

电话里人一次只能接住一个东西。

反面例子（真实出现过）：

> 客户："欠了十多万吧，两三年了，很着急啊。"
> 律师："十多万不是小钱。但我先说你那句'两三年'——这个比金额更要命。诉讼时效是三年……过了会怎样……所以你现在第一件事不是催他，是翻记录，今晚就得翻出来。还有个问题你没答我：有没有借条？"

一句话里塞了：时效标准、过期后果、执行指令、追问。客户接不住，只会觉得"这人在催我"。

正确做法：

> "时间这块我心里有数了。有个事想先确认一下——**这个钱当时是怎么给他的？转账，还是给的现金？**"

**自检**：这句话说完，他能不能用一个短句回答？不能，就是给多了。

### 2.2 不确定就不下判断

缺口径的判断，比不给判断更麻烦。三个后果：说错被客户回头堵、专业形象一次性崩掉、万一误导了客户是要担责的。

**下判断前的四问**：

- [ ] 时间点问准了吗？（不是"两三年"，是具体哪年哪月）
- [ ] 起算依据问清了吗？（约定日期 / 未约定 / 最后一次催告 / 部分还款）
- [ ] 手上有什么材料，问清了吗？
- [ ] 对方的抗辩点，能预判吗？

缺任何一项，标准说法：

> 「这个得看材料才能定，我现在给您个数，是不负责任的。」
> 「这一点我先记下，回头核了再回您。」

⚠️ 该讲的风险还是要讲。区别在于——**讲风险不说成结论**。可以说"这个时间点很关键，得算准"，不能说"您已经过了"。

## 三、三场景节奏

### 3.1 电话

**电话的任务：** 让他对这件事有个方向，并且愿意的话，下一步继续。

电话的优势是能听出语气，劣势是看不见材料、也看不见表情。

#### 开场（20 秒）

> 「您好，××律师事务所，我姓×。您说。」

不要问"有什么可以帮您"，那是客服腔。让他直接讲，你做三件事：不打断、记关键词、嗯一声。

#### 听 + 复述

听完必须复述一遍，用"一二三"：

> 「我先把您说的理一遍，您看我理解得对不对——第一……；第二……；第三，您现在最想解决的是……。是这样吧？」

**复述的作用不是确认事实**，是把他散乱的话整理成"问题"。能被说清楚的问题，才有得谈。

#### 一次问一到两个

> 「我问几个问题，您别嫌烦，这些直接影响后面怎么弄。」

问完**回一个判断**，别只问不给：

> 「什么时候的事？」
> （答）
> 「嗯，这个时间点很关键，**诉讼时效是三年，从您知道权利被侵害那天算**。您这个还有多久，我得把日期问准才能算。」

#### 要不要在电话里报价

**可以报，但要说明依据。** 详见 `03-报价与收费话术.md`。

不报的唯一理由应该是"信息不够，报出来会错"，不是"销售上不该报"。

#### 收口

电话结束前，给一个具体的下一步。可以约见面，也可以不约：

> 「这样，您把××和××找出来，发我看一下，我看完给您一个方向。要是方便，也可以过来一趟，当面讲清楚一些。」

**不要每次都把"来所里"当唯一出路。** 有些客户线上就能谈成，有些客户来了也不会签，逼着见面反而消耗信任。

#### 三个细节（用得上就用，不必强求）

- 约时间用"今天下午还是明天上午"，比"您什么时候方便"更容易得到答复
- 约好之后发一条短明确认，把口头约定变成书面
- 记得称呼他的名字，或者"×律师"自称时要自然，不用刻意拉近

### 3.2 微信

**微信的任务：** 建立基本信任，把长问题转到能说清的地方。

微信的坑：**你打的每个字都可能被转发、被截图、拿去比价。**

#### 回复长度

- 每条约 60-100 字
- 超过 150 字就拆成两条
- 不要一条里塞三个问题

#### 不写完整法律分析

> 「您这个事，核心是三个点：①……②……③……。这三块每一个都有讲究，打字容易说偏。您方便的话通个电话，五分钟比打两百字清楚。」

**为什么**：写全了他不需要你，写一半他觉得你不专业，而且文字会被拿去问别人。

#### 首次咨询不说太多

> 「您好，我是××律所的×律师。您先说说情况，我看到就回。」

#### 设边界

> 「简单问一句我随时答。要是涉及看材料、出方案，这部分我们是收费咨询，××元一次，后面委托了从律师费里扣。」

收费咨询的意义不是赚那点钱，是**筛人**。愿意付的通常是真的要办；不愿意的，本来也不会签。

#### 收口

> 「您这个情况，我建议当面或通个电话讲一下，二十分钟差不多。您看是明天下午还是后天上午？」

### 3.3 面谈

**面谈的任务：** 让他做完决定之后，心里是清楚的——不管这个决定是委托还是不委托。

#### 前五分钟不谈案

给水、问路上、看一眼他带的材料。

> 「您这材料整理得挺仔细，一般人过来都是一团。」

夸具体的东西，不夸人。

#### 读人：只看他说过的话

边听边在心里记这几项，**但不要下结论**：

| 观察 | 看什么 |
|---|---|
| 他最在意什么 | 反复提到的是哪件事 |
| 他在担心什么 | 说到哪里开始重复、开始抱怨 |
| 他能不能自己决定 | 有没有出现"要问我老公""要问合伙人" |
| 他是不是在准备委托 | 有没有问流程、问时间、问要准备什么 |

**记在心里，不要说出口。** "您其实是怕花钱"这种话，说出来就是冒犯。

#### 挖案：自然提问

一次一到两个问题，问完给个判断。**不要把咨询做成填表。**

#### 塑价：讲工作，不讲形容词

- 讲"这一步要跑哪几个地方、大概几天"，不讲"我们非常专业"
- 讲"这一步做晚了会怎样"，不讲"不请律师您就完了"

#### 报价：透明

见 `03`。核心是三件事：多少钱、包含什么、不包含什么。

#### 收尾

给明确的下一步，**也给他不选你的空间**：

> 「情况我大致清楚了。剩下几个点得看材料才能定。您把××和××准备一下，我这边出个书面方案给您。您看完觉得合适我们再走手续，觉得不合适也没关系。」

**"觉得不合适也没关系"这句话要敢说。** 说了反而更容易签，因为客户感到没有被逼。

## 四、谈完之后：轻量复盘

### 4.1 客户没签，先别急着定性

**没签的原因可能是**：预算不够、需求变了（对方还钱了、家里和解了）、案子本身没法接、家里不同意、客户想再比比、客户就是自己决定不请。

**这些都不是律师谈得不好。**

没有完整对话记录时，必须明说：

> 「以下判断基于您提供的有限信息，可能有偏差。」

### 4.2 复盘四问

1. **哪句话可能造成了障碍？**（对着原话找）
2. **为什么这句话可能不合适？**
3. **更好的说法是什么？**
4. **下次最值得改的一件事是什么？**（只给一件，给多了记不住）

### 4.3 常见障碍对照

| 现象 | 可能的原因 | 下次怎么办 |
|---|---|---|
| 问完价就沉默 | 价格前没讲清做什么 | 报价前先讲一段"这个案子要做什么" |
| 一直问"能保证赢吗" | 风险没讲透，他心里没底 | 主动把最坏情况说清 |
| 说"回去商量" | 可能是真的要走流程，也可能是委婉拒绝 | 问一句"主要担心哪块" |
| 聊得很好但不签 | 结束时没给具体下一步 | 收尾给一件事、一个时间 |
| 只问价不聊案情 | 可能在比价，也可能只是先了解行情 | 给参考区间，别投入过多时间 |
| 全程你在讲 | 说太多 | 每讲两分钟，问他一个问题 |
| 客户明显不耐烦 | 讲太深了 | 看他的反应调深浅，不看他该懂多少 |

⚠️ 这张表是**可能性**，不是诊断书。同一个现象可能有完全不同的原因。

## 02 异议应答库

15 类常见异议。每类四个部分：**客户可能这么说 → 判断依据 → 推荐回应 → 不建议的表达**。

### 使用前提醒

- **判断依据只是可能性，不是结论。** 客户没说，就不能当成事实。跟客户对话时，**永远不要把这里的推断原样说出去**。
- 推荐回应是模板，不是台词。按你自己的说话习惯改，改得越像你自己越管用。
- **允许客户拒绝。** 这个库不是设计来把人留住，是设计来让每次对话都不尴尬、不亏待。

## 一、嫌律师费贵

### 客户可能这样说

> "太贵了。"
> "这个价我承受不了。"
> "能不能少一点？"
> "就这么点事，要这么多钱？"

### 判断依据

三种情况，处理方式完全不同：

| 可能的情况 | 依据 |
|---|---|
| **真的没预算** | 他会主动提自己的经济状况、问能不能分期、问能不能少做几项 |
| **觉得不值** | 他说"就这点事"，或者反复问"你具体做什么" |
| **在试价** | 他没有具体抱怨，只是一直说贵，看你让不让 |

**区分方法**：问一句"您是总预算这块有压力，还是觉得这个价对不上要做的事？"——他自己会说。

### 推荐回应

**（觉得不值时）**
> 「我理解。那我把这个钱花在哪跟您说一下：这个案子要跑保全、立案、开庭，中间可能还有一次调解，文书、证据、跟对方沟通都算在里面。您要是觉得哪一块不需要，我们可以砍掉，价格跟着降。」

**（真的预算紧时）**
> 「那咱们换个做法：先做最要紧的一段——保全加立案。这一段做完，对方大概率会来找您谈，谈成了后面就省了。这一段是××。」

**（在试价时）**
> 「这个价我按这个案子的工作量报的，没往上留空间。您要是想比一比，可以多问两家，把服务范围对一下再判断。」

### 不建议这样说

- ❌ 「您买的不是律师费，是少亏」——这句话律师自己说得出口，客户听着像话术
- ❌ 「一分钱一分货」——太熟，等于没说
- ❌ 「我要是报低得离谱，您反而该担心」——话里有话，容易激反感
- ❌ 直接降价，什么都不问——他下次还会砍

## 二、拿别的律所比较

### 客户可能这样说

> "我问了另一家，人家只收五千。"
> "某某律师说他这个价就能做。"
> "网上报价比你这低多了。"

### 判断依据

- **可能他真的拿到过低价**：那就比服务范围，不比价格
- **可能他在虚张声势**：只说数字，说不出对方包含什么
- **可能别人报的是低配版**：只做一段、不含执行、不含差旅

**不要假设他在骗你，也不要假设他在说实话。** 就事论事问范围。

### 推荐回应

> 「报价差这么多是常事。您方便的话问一下那边：这个价包含到哪一步，是只到开庭，还是含执行？中间有没有另外收的鉴定费、差旅费、公告费？这几项不一样，最后总价可能差得比现在这个差额还多。」

**他追问"那你到底比他好在哪"**：
> 「我可以具体说：这个案子我打算怎么弄、包含哪些活、有哪些地方需要您配合。您听完再判断值不值这个价。」

### 不建议这样说

- ❌ 「他们不专业」「那种价格肯定做不好」——贬低同行，且你并不知道对方怎么做
- ❌ 「我们是大所」——规模跟你的服务质量没直接关系
- ❌ 「那您去找他们吧」——赌气，客户真的会走

---

## 三、要求优惠

### 客户可能这样说

> "打个折吧。"
> "便宜两千我就签。"
> "朋友介绍的，给个面子。"

### 判断依据

- 他已经在谈具体条件 → 意向较高，只是想把价格压到心理线
- 他只是顺口一说 → 试探，让不让都未必影响决定
- 他明确给出条件（"便宜××我今天就签"）→ 这是可谈的信号

### 推荐回应

**（第一次提，不急着让）**
> 「这个价我报的时候是按工作量算的，没留多少空间。您要是确实有困难，我可以帮您想想别的办法——比如分两段付，先做立案这一段，压力会小一些。」

**（他给出明确条件时）**
> 「您说的这个数我得跟所里报一下，能不能批我不敢保证。要是批下来了，您这边大概什么时候能定？」

**（确实让了价，要说明交换）**
> 「这个价我争取下来了，但服务范围是按刚才说的那些，不再加项。这个我得先跟您说清楚。」

### 不建议这样说

- ❌ 「那给您打个八折」——第一次还价就答应，他会觉得还有空间
- ❌ 「我去请示领导」，然后回来说"领导同意了"——如果本来就能降，这话是在演
- ❌ 「今天签才能享受这个价」——制造时间压力，容易让人不舒服

---

## 四、只想免费咨询

### 客户可能这样说

> "先简单问一下，不收费吧？"
> "你就告诉我该怎么办，我自己去弄。"
> "微信上聊两句就行。"

### 判断依据

- **他把问题问得很具体**（有明确事实、有材料）→ 大概率是认真在办这件事，只是不想先付钱
- **他问得很泛**（"我这个能赢吗"）→ 可能只是想听个安慰
- **他反复问、不给材料** → 大概率是在免费攒方案

### 推荐回应

**（先答，再设边界）**
> 「您问的这个问题我可以直接答。（答完）
> 再往下就涉及看材料、出方案了，那部分我们是收费咨询，××元一次，委托了从律师费里扣。您看要不要走这一步。」

**（他反复问、不给材料）**
> 「您这几个问题我都答了。再细的说下去，就得看您手上的东西了。要不我们约个时间，您把材料带上，我一次给您讲清楚？」

### 不建议这样说

- ❌ 「我们是专业机构，咨询是要收费的」——太硬，第一句话就把人推走
- ❌ 「简单的问题不收费，复杂的收费」——什么算复杂，最后一定扯皮
- ❌ 一声不吭地一直答下去——答到最后他就不来了

---

## 五、质疑律师专业能力

### 客户可能这样说

> "你看起来挺年轻的。"
> "你办过这种案子吗？"
> "你是专门做这行的吗？"

### 判断依据

这类问题背后通常是**不确定你能不能办成**，不是真的在意年龄。

- 他问具体的办案思路 → 在考察专业度，正常
- 他只质疑身份不给具体问题 → 可能在找理由压价或有别的顾虑

### 推荐回应

> 「办过同类的，一模一样的没有——天底下没有两个完全一样的案子。您这个案子我看下来，最容易出问题的地方在××，这个地方处理不好后面要返工。您听我说这一段，自己判断我够不够。」

⚠️ 如果确实没办过这类案子：
> 「这一类我做得不多。您这个案子我建议您找专做这块的律师，我可以帮您问问同行有没有合适的。」

**说这句话不会丢单，硬撑才会。**

### 不建议这样说

- ❌ 「我虽然年轻但是很专业」——空话
- ❌ 「我们团队办过几百件」——数字要能对上，编了就是雷
- ❌ 「你不信我就算了」——赌气

---

## 六、认为案件很简单

### 客户可能这样说

> "这事很简单，就是欠钱不还。"
> "我自己去法院立个案就行了。"
> "用得着请律师吗？"

### 判断依据

- 他说"简单"，多半是**没看到难点在哪**
- 他问"用得着吗"→ 在算投入产出，不是在质疑你

### 推荐回应

> 「程序上确实不复杂，立案现在也方便。不过这类案子容易出问题的不是立案，是两件事：一是财产保全得赶在对方转移之前做，这个有时间窗；二是对方提抗辩的时候怎么接。这两样您自己办，容易踩空。」

**如果他坚持自己办**：
> 「也行。那我提醒您三件事：时效别过、起诉前先查一下对方有没有财产、判决下来两年内记得申请执行。这三样错一样，前面都白做。」

### 不建议这样说

- ❌ 「你以为简单？开庭你就知道了」——居高临下
- ❌ 「每个案子都复杂」——等于没说，且不真诚
- ❌ 为了签单硬把简单案子说复杂

---

## 七、要求保证胜诉

### 客户可能这样说

> "你能不能保证赢？"
> "有多大把握？"
> "别人都说能赢，你怎么不敢说？"

### 判断依据

- **他不是在要结果，是在要安全感。** 这类问题背后通常是"我花了钱万一没结果怎么办"
- 他拿别人作比较 → 说明已经有人在给他"承诺"

### 推荐回应

> 「这个我不保证，也没人该保证。案子怎么判，取决于证据、对方怎么应诉、法院怎么认定，不是律师能定的。我能做的是把您这边的证据理清楚、该走的程序走到位，把能争取的空间争到。」

**他追问"那别的律师说能赢"**：
> 「您可以让他把'能赢'说具体点——凭什么赢、靠哪几份证据。说得出来，您可以多听听；说不出来，那句话对您没什么用。」

**他要求给个百分比**：
> 「给百分比没意义。同样是八成把握，一个是靠证据撑起来的八成，一个是随口说的八成，差别很大。我更愿意告诉您：我们这边强在哪、弱在哪、对方可能怎么打。」

### 不建议这样说

- ❌ 「基本没问题」「八九成」「放心交给我」——都算不当承诺
- ❌ 「谁跟你说能赢，你就别找他了」——攻击同行
- ❌ 「包在我身上」——绝对红线

---

## 八、担心花钱没结果

### 客户可能这样说

> "万一钱花了，事情没办成呢？"
> "打赢了也拿不到钱怎么办？"
> "对方没钱，起诉有什么用？"

### 判断依据

这是**风险顾虑**，不是价格顾虑。降价解决不了，讲清风险结构才解决。

### 推荐回应

**（怕白花钱）**
> 「这个担心是实在的。所以我把最坏的情况先跟您说：证据不足可能败诉，赢了也可能执行不到钱。这两件事我现在都没法排除。我能做的是把胜算做到最大，做不到的是保证结果。」

**（怕执行不到钱）**
> 「您没查过，就不知道他到底有没有钱。起诉以后法院能查房产、车辆、股权、账户，这些您自己查不到。就算真查不到，判决书把债权固定下来，一辈子有效；不起诉，过了时效就没了。」

### 不建议这样说

- ❌ 「肯定能拿回来」——承诺
- ❌ 「他肯定有钱」——你并不知道
- ❌ 「不起诉你一分钱都拿不到」——吓唬

---

## 九、不愿意提供材料

### 客户可能这样说

> "材料我慢慢找，先聊。"
> "这些东西重要吗？"
> "我不太想把合同给别人看。"

### 判断依据

- **怕泄露隐私或商业信息** → 常见，尤其公司客户
- **材料本身有问题**（比如合同不利） → 他不好意思拿出来
- **嫌麻烦** → 只是懒

### 推荐回应

**（担心隐私）**
> 「理解。您可以把关键页拍照发我，姓名、账号这些涂掉。我看的是条款结构和时间点，不需要您的身份证号。」

**（他拖着不给）**
> 「材料这块我不催您。但有件事得说清楚：现在讲的都是大概，看了材料以后判断可能会变。所以您先听个方向，别当成定论。」

### 不建议这样说

- ❌ 「不给材料我没法帮你」——直接把人推走
- ❌ 「你放心，我们都是保密的」——口头保证不如给具体做法（涂掉敏感信息）
- ❌ 反复催要材料

---

## 十、要求先办事后付款

### 客户可能这样说

> "打赢了再给你钱行不行？"
> "先做，拿到钱再付。"
> "你们能不能风险代理？"

### 判断依据

先看案件类型：

- **禁止风险代理的案件**（婚姻继承、社保待遇、赡养费抚养费扶养费抚恤金救济金、**工伤赔偿**、**劳动报酬**、刑事、行政、国家赔偿、群体性诉讼）→ 不能做，要说清
- **可以做的案件** → 谈具体比例和支付节点

### 推荐回应

**（禁止类的）**
> 「您这个案子按规定不能做风险代理——不是我保守，是这类案件不允许，做了合同可能被认定无效，对您我都没保障。我们能谈的是分段付：先做立案这一段，做完您再决定要不要往下走。」

**（可以做的）**
> 「可以谈。一般是前期收一部分基础费用，后期按实际到账的金额提成。具体比例得看标的和难度，而且有上限规定。我把两种方案都给您算一下，您对比。」

### 不建议这样说

- ❌ 「拿不到钱一分不收」——禁止类案件这么说就是违规
- ❌ 用「咨询费」「调查费」的名义变相做全风险
- ❌ 「我们不做风险代理，全城没有一家做」——与事实不符

---

## 十一、需要和家人商量

### 客户可能这样说

> "我回去跟我爱人说说。"
> "得跟我爸妈商量一下。"
> "我跟合伙人通个气。"

### 判断依据

- **真的要走流程**：他会主动问"我该怎么跟他说"，或者问"能不能带他一起来"
- **委婉拒绝**：他说完这句就不再问细节了
- **他自己做不了主**：这种情况很常见，尤其是家事案件和公司案件

### 推荐回应

> 「应该的，这个事确实不该一个人定。您商量的时候有个东西能帮上忙——我把今天说的几个点，还有要准备的材料，发一份给您，您拿给他看比自己复述清楚。」

**想约决策人时**：
> 「要是家里人有疑问，可以一起过来，我当面讲一遍，有问题当场问。您回去解释还得替我说一遍，麻烦。」

### 不建议这样说

- ❌ 「您回去一讲，家里人肯定说别打官司」——替客户预判家人，容易引起反感
- ❌ 「这种事还要商量？」——贬低他的处境
- ❌ 直接放弃，不再联系

---

## 十二、暂时不想委托

### 客户可能这样说

> "我再想想。"
> "过段时间再说吧。"
> "最近比较忙。"

### 判断依据

- **有个具体顾虑没说**：通常说"再想想"的时候，前面一定有个他没认同的点
- **时机不对**：真的忙，或者事情还没到必须处理的时候
- **在等其他方案**：比如在等对方还钱、在等别的律师报价

**不要断定是哪一种。** 问一句具体的就知道。

### 推荐回应

> 「行，这个事该想清楚。您考虑的时候主要是费用这块，还是有别的地方没底？」

**（他说忙）**
> 「忙是正常的。那这样，您先不用管，我把要准备的材料列一份给您，您有空的时候对着找，找齐了再说下一步。」

**（有明确时间点的，比如时效）**
> 「有件事我得提醒您一下：您这个事有个时间点，××之前如果不动，后面会比较被动。您不用现在决定，但心里有个数。」

### 不建议这样说

- ❌ 「您还在犹豫什么？」——逼问
- ❌ 「那我明天再给您打电话」——变成催单
- ❌ 「过了这个村没这个店」——制造压力

---

## 十三、明确拒绝委托

### 客户可能这样说

> "我决定不请律师了。"
> "我找别人了。"
> "暂时不考虑。"

### 判断依据

**这就是拒绝。不需要分析，也不需要挽回。**

客户不委托的原因可能很多：预算、信任、家里意见、案子本身、找到更合适的、或者就是不想请。**这些都不需要你追问。**

### 推荐回应

> 「行，理解。有需要随时找我。」
>
> （如果他愿意多说一句）
> 「方便的话，您是因为费用这块，还是觉得案子本身不用请？我下次也好改进。」

**收尾时可以多说一句（只说一句）**：
> 「有几个时间点您留意一下：××之前要主张，过了就麻烦。这个不收费，就是提醒您一句。」

### 不建议这样说

- ❌ 「您再考虑考虑，我给您留个优惠」——死缠
- ❌ 「是不是有人跟您说了什么」——质问
- ❌ 追问不委托的真实原因超过一次

**体面收尾的人，才会被推荐。** 这个行业里，转介绍比当场签单值钱。

---

## 十四、情绪激动

### 客户可能这样说

> （长时间抱怨、骂对方、哭）
> "我这辈子没受过这种气！"
> "法律到底管不管？"

### 判断依据

情绪激动的客户通常**不是要方案，是要有人听**。这个时候给方案，他听不进去。

### 推荐回应

**第一步，让他说完。** 不打断，不"我理解您的心情"（这句太套路，说了也没用）。

**第二步，用一句话证明你听懂了**：
> 「您说的这个事，最难受的地方是他明明做错了，还理直气壮。」

**第三步，把情绪转成问题**：
> 「那我们现在能做的是两件事：一件是把该固定的证据先固定，另一件是看看能不能让他付出代价。您想先从哪件开始？」

### 不建议这样说

- ❌ 「您先冷静一下」——这句话只会让人更激动
- ❌ 「我完全理解您的心情」——万能台词，等于没听
- ❌ 在他还在说的时候讲法律条文

---

## 十五、不信任律师

### 客户可能这样说

> "律师都是收钱不办事的。"
> "我之前被律师坑过。"
> "你们这行我信不过。"

### 判断依据

- **有过不好的经历**：他会讲具体的事（收了钱不理人、中途加价、案子办砸）
- **听别人说的**：讲不出细节
- **行业偏见**：泛泛而谈

**区别对待**：有具体经历的，要针对他说的那一环回应；泛泛而谈的，给验证路径就行。

### 推荐回应

**（有具体经历）**
> 「上次是哪一环让您觉得不对——是收了钱不怎么联系，还是中途又加了费用？您说说，我至少能讲清楚这几件事在我这边是怎么处理的。」

**（泛泛不信任）**
> 「这话我不敢反驳，这行确实有不像话的。我不跟您保证什么，给您两个办法：一是我的执业证号，您可以去司法局网站查；二是这类案子我办过哪些，可以挑两三个讲给您听，您自己去核。」

**（他要看承诺）**
> 「每个阶段做什么、什么时候做，可以写进委托合同。您按合同对，做不到您找我。」

### 不建议这样说

- ❌ 「我们跟他们不一样」——所有人都会这么说
- ❌ 「您要相信法律」——答非所问
- ❌ 急着证明自己，越证越可疑

---

## 附：判断客户顾虑的三条规矩

1. **只根据他说过的话判断。** 他没说的，不猜。
2. **判断结果留在自己心里。** 不要把"您其实是想白嫖"这种话说出口。
3. **拿不准就问一句具体的。** "您主要担心哪一块"比任何推断都准。

## 03 报价与收费话术

> 本文件的收费规则以现行有效规定为准。签约前请核对当地律协细则与律所备案标准。
> **任何具体金额都要由律师按自己的授权和律所规则确定，本文件不给数字。**

---

## 一、报价前先判断三件事（不是三道门槛）

| 判断 | 够格就报 | 不够就说清楚 |
|---|---|---|
| **案情了解到什么程度** | 知道案由、标的、大致程序 | "现在讲的还是大概，报价会偏" |
| **证据状况** | 知道手上有什么、缺什么 | "看不见材料，我给不准" |
| **服务范围** | 你清楚要做哪几段 | "先定做哪几段，才能定价" |

**三条都够 → 直接给价。**
**有一条不够 → 给范围或给结构，同时说明为什么不准。**

⚠️ 旧版要求"必须面谈才能报价"，本版已取消。**电话和微信里可以报价**，只要你说清依据、并把不确定性讲明白。这不是销售技巧问题，是职业诚实问题：客户有知情权，你也省得后面扯皮。

---

## 二、客户一开口就问价

### 2.1 他还没说案情

> 「价格跟案子本身关系很大——同样是要钱，有欠条的和什么都没有的，工作量差好几倍。您先跟我说说是什么事、手上有什么，我说出来的数才有意义。」

**不要**："见面再谈"——如果他只是想知道个大概，这句话会让他直接挂断。

### 2.2 他说了基本情况，但没给材料

> 「按您刚说的这个情况，大概在××到××之间。这个范围是按××算的，如果材料看完发现有××，会往上走；如果比想的简单，也可能往下。」

**给范围，不给死数。** 范围要说明什么条件下变。

### 2.3 他问的是一件很小的事（写个函、看个合同）

直接给价，不要绕：

> 「这个××元，包含看一遍、改一遍，后面对方有反馈需要再改的话，按次算。」

小事绕圈子，客户会觉得你不实在。

### 2.4 电话里被追问"你就说个数字"

> 「那我给您一个参考：这类案子一般是××到××。但这个是参考，不是报价——报价要看完材料才能定，不然到时候对不上，您我都不好办。」

**可以给参考区间。** 完全不给，反而显得要么不懂行，要么在拿捏。

---

## 三、信息不足时怎么说

三种正确说法：

**① 说清缺什么**
> 「现在缺的是××。这个不一样，价格差得比较多。」

**② 给区间并说明变量**
> 「如果××，是××；如果××，要到××。您先确认一下是哪种。」

**③ 分步报价**
> 「前面这一段（看材料、出方案）是××。后面打不打、怎么打，等这一段做完再说，那时候价才准。」

**三种错误说法**：
- ❌ 「不好说」（等于拒绝回答）
- ❌ 硬报一个数，事后再加价
- ❌ 绕回"见面谈"（他问三遍你都不答，他就走了）

---

## 四、报价明细

### 该给的时候

客户问"具体怎么算"、公司客户要走采购流程、案件分段明显——**直接给明细，这是专业表现。**

### 怎么给

按**阶段**列，不按"动作"列：

> 「分三段：
> 第一段，保全加立案，××；
> 第二段，一审，××；
> 第三段，执行，××。
> 每一段做完再付下一段。要是不做执行，第三段就不收。」

### 不按动作列的原因

按"起草文书××、开庭××、阅卷××"这种列法，客户会一项项砍："这个我不需要""那个能不能不做"。

**按阶段列，客户看的是"办到哪一步花多少钱"，这才是他真正关心的。**

### 明细必须写清的三项

1. **包含什么**（阶段、服务内容）
2. **不包含什么**（诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费、异地办案费）
3. **什么情况下会加钱**（追加被告、发回重审、二审另计等）

⚠️ 第 2 项最容易起纠纷。客户以为"全包"，结算时多出鉴定费就翻脸。事先写清反而是加分。

---

## 五、客户要求降价

### 5.1 先分清他想降多少、为什么

> 「您是总预算这块有压力，还是觉得这个价对不上要做的事？」

- **预算有压力** → 调结构（分段付、减范围），不是降价
- **觉得不值** → 补价值说明（讲清做什么）
- **只是试价** → 说明为什么这个价，不必让

### 5.2 可以调结构的三种做法

**① 分段付**
> 「分两段：立案保全这一段先付××，做完您看到东西了，再决定要不要走第二段。」

**② 减范围**
> 「执行这一段您要是想自己做，可以砍掉，价跟着降。但我得提醒您，执行这一步最容易卡住。」

**③ 换收费方式**
> 「这个案子也可以按小时算，您做多少算多少。缺点是总额不封顶，您心里没底。」

### 5.3 真要让价时

**让价要换东西，且要说清。**

> 「这个数我帮您报上去看看，能不能批我不敢保证。要是批下来了，服务范围还是按刚才说的那些，不再加项。」

**不要演的戏**：
- ❌ 明明自己能定，说"我去请示领导"
- ❌ "今天签才能享受"（制造时间压力）
- ❌ 让了价不说，客户以后还会砍

### 5.4 客户反复砍价

> 「这个价我这边到这儿了。再往下要么减范围，要么换收费方式，您选一个，我们按那个来。」

**给他选择，不给无底线的让步。**

---

## 六、客户拿别的律所比较

> 「报价差得多是正常的。您方便问一下那边三件事：含不含开庭、含不含执行、中间有没有另外收的费。这三样不一样，最后总价可能差得比现在这个差额还大。」

**他追问"那你怎么比别人贵"**：
> 「我这个价是按这个案子实际的工作量报的。您要是能拿到对方的服务清单，我们对一下，差在哪我能跟您讲清楚。」

**绝不能做**：
- ❌ 说对方不专业、不靠谱
- ❌ 说"低价肯定有问题"
- ❌ 编自己的办案量来压对方

---

## 七、按阶段收费怎么谈

客户问"能不能分段"——这是好事，说明他在认真考虑。

> 「可以。一般分三段：保全立案、一审、执行。每段做完再付下一段，您能看见进展，我也不至于干到一半没着落。」

**要说清的两个点**：

1. **每一段的边界**——比如"一审不含二审，如果需要上诉，另算"
2. **中止怎么算**——比如"您中途和解撤诉，剩下的段不再收，但已经做的部分不退"

第 2 点不写清，将来必扯皮。

---

## 八、风险代理：法定边界（必须记准）

### 8.1 禁止风险代理的案件

**依《律师服务收费管理办法》**（以现行有效版本为准）：

1. 婚姻、继承案件
2. 请求给予社会保险待遇或最低生活保障待遇的
3. 请求给付赡养费、抚养费、扶养费、抚恤金、救济金、**工伤赔偿**的
4. 请求支付**劳动报酬**的
5. 刑事诉讼、行政诉讼、国家赔偿案件
6. 群体性诉讼案件

### 8.2 比例上限

实行风险代理收费的，**最高收费金额不得高于收费合同约定标的额的 30%**。

### 8.3 禁止变相风险代理

不得通过以下方式规避上述限制：

- 以"咨询费""调查费""差旅费""材料费"等名义收取实质上的风险对价
- 约定"按结果补收"但不在合同中写明
- 把禁止类案件包装成"法律顾问""专项服务"来做风险收费
- 与当事人约定由第三方代收、事后分成

**这类安排一旦发生争议，合同可能被认定无效，且面临行业处分。**

### 8.4 客户要求全风险时怎么说

> 「您这个案子按规定不能做风险代理——不是我保守，是这类案件不允许。做了以后万一有争议，那份合同可能被认定无效，到时候您我都麻烦。我们能谈的是分段付：前期收一部分，后面按阶段走，您压力小，我也不至于白干。」

**可以做的案件**：
> 「可以谈。一般是前期收基础费用，后期按实际到账金额提一定比例，比例有上限规定。我把两种方案的账都给您算一下，您对比。」

### 8.5 三条绝对不做

- ❌ 承诺"拿不到钱一分不收"（禁止类案件）
- ❌ 用别的名目变相做全风险
- ❌ 跟客户说"全城没有一家做风险代理"（与事实不符）

---

## 九、说明收费价值（不说销售话术）

客户问"为什么值这个钱"，讲这三样，不讲形容词：

**① 具体做什么**
> 「这个案子我要做的是：查对方财产、做保全、立案、开庭、可能要跑两次调解、写文书、跟对方律师谈。这些活加起来是××个工作日左右。」

**② 你能做而他做不了的**
> 「查财产、保全这两样，您自己去办不了。时效一旦过了，谁都救不回来。这些是有时间窗的。」

**③ 不收这笔钱会发生什么**
> 「不是说不请律师就一定输。是很多事情有时间点，错过就补不回来。」

**不要说的**：
- ❌ 「您买的不是律师费，是少亏」（话术感太重）
- ❌ 「一分钱一分货」（太熟）
- ❌ 「专业的事交给专业的人」（空）

---

## 十、报价单必须写的六项

口头报完，**当天发一份书面的**。既是专业形象，也是纠纷时的证据。

1. **服务范围**：具体做哪些阶段和事
2. **不包含事项**：诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费
3. **金额与支付节点**
4. **主办律师**：谁办，能不能换
5. **每阶段交付什么、多久汇报一次**
6. **报价有效期**（7-15 天较常见）

---

## 十一、报价自检

- [ ] 有没有编具体金额、服务项目、折扣权限？（编了就是雷）
- [ ] 有没有承诺"拿不到钱不收"？
- [ ] 案件是否属于禁止风险代理类型？是 → 改成分段
- [ ] 有没有用别的名目变相做风险代理？
- [ ] 有没有说"我是最低价""别人都不行"？
- [ ] 不包含的费用写清了吗？
- [ ] 给的是范围还是死数？死数有没有说明前提？
- [ ] 有没有为了签单硬压价，压到自己做不下去？

## 04 分案型话术

八大民商事案型。每个案型六块：**开场 → 必问事实 → 谈话重点 → 常见异议 → 服务与报价 → 收尾**。

> 本文件法律要点为速查提示，**不是结论**。正式出具意见前请核对现行有效法律法规与当地裁判口径。

---

## 一、婚姻家事

### 开场

> 「先听您说。您把情况从头讲一遍，中间我可能会打断问几句，您别介意。」

### 必问事实（按重要性）

1. **孩子在不在、多大、现在跟谁生活**（不满两周岁以母亲直接抚养为原则；已满八周岁应尊重本人真实意愿；中间段看双方条件）
2. **财产有什么、登记在谁名下、婚前还是婚后**（房、车、存款、股权、公积金）
3. **对方什么态度**——同不同意离、争不争孩子、有没有提过条件
4. **有没有家暴、出轨、转移财产的迹象**——报警记录、就诊记录、聊天记录
5. 登记时间地点、双方现在居住地（管辖）

### 谈话重点

**不是"感情有没有破裂"，是"孩子和钱怎么安排"。**

客户哭着讲的时候要听，但把话头引到"怎么办"的那一刻，他才开始把你当律师，而不是树洞。

> 「您说的我都听明白了。我们现在把话头转一下——**您最想保住的是哪一样？孩子，还是财产，还是就想赶紧把这事了了？** 这三个打法不一样，得先有个顺序。」

### 常见异议

**「我自己出轨，对方要我净身出户」**
> 「法律上没有'净身出户'这一说。出轨是过错，过错的法律后果可能是承担损害赔偿，也可能影响财产分割的比例。对方这么说，多半是拿您不懂法在压您。」

**「他不肯离」**
> 「他不肯，不影响您离。协议不成就是起诉。**根据民法典，法院判决不准离婚后，双方又分居满一年，一方再次起诉的，应当准予离婚。** 所以第一关过不了，不等于没有路，关键看证据和分居事实能不能证明。」

**「他说离婚就弄死我」**
> 「这种话要当真处理。三件事可以同时做：报警留记录、申请人身安全保护令、把威胁的聊天记录和录音固定下来。这些既是保护，在争抚养权、谈财产的时候也用得上。」

**「我要告他重婚，让他坐牢」**
> 「可以告，但我得先说实话：**重婚的证据要求很高**，光有开房记录、光有孩子，都不一定够。这是自诉案件，证据要您这边举证。所以现在的关键是先取证，不是先立案。取不到证，立了也白立。」

### 服务与报价

**分段明显**：调解谈判 / 一审 / 二审 / 执行。可以分段报。

明确不含：评估费、公证费、鉴定费、差旅。

⚠️ **婚姻继承案件禁止风险代理**（《律师服务收费管理办法》），不能做"不离婚不收钱"。

### 收尾

> 「您先把结婚证、财产凭证、还有孩子相关的材料找出来。我这边看完给您一个方案，包括起诉还是先谈、大概多久、要准备什么。您看完再决定要不要走。」

---

## 二、民间借贷与债务

### 开场

> 「您说说是怎么回事，多少钱，什么时候的事。」

### 必问事实（按重要性）

1. **钱是怎么给的**——转账、现金、还是代付？（**这一问最关键**，决定证据基础）
2. **有没有借条/欠条/协议**——谁写的、签没签、有没有约定还款期
3. **有没有约定还款日**——直接决定时效从哪天算
4. **最后一次催是什么时候、有没有证据**（微信、短信、录音）
5. 中间有没有还过一部分
6. 对方的财产状况、有没有其他债权人已经起诉

### 谈话重点

**不是"能不能赢"，是"什么时候能拿到钱"。**

> 「这类案子赢不赢通常不是最大问题，能不能执行到钱才是。所以我先问一句：**他现在名下有什么，您清楚吗？**」

### 常见异议

**「他没钱，起诉有什么用」**
> 「您查过吗？没查过就不好说。
> 就算真没钱，起诉也不是白起：判决把债权固定下来，长期有效；法院能查房产、车辆、股权、账户，这些您自己查不到；起诉本身也能把他逼到谈判桌上。」
>
> ⚠️ 不要承诺"肯定能执行到钱"。

**「借钱给他是现金，没有转账记录」**
> 「不是不能打。要看三样：借条上有没有写明是现金交付、您能不能说清现金来源、对方有没有明确否认借款这件事。**对方只是拖着不还、没有否认，这对我们有利。** 剩下的证据可以补。」

**「我这个都两三年了」**
> 「得把日期问准才能说。**诉讼时效是三年**，从还款期限届满或者您最后一次主张权利那天算。有没有约定还款日、中间催过几次、有没有还过一部分，这几件事不一样，结论差很多。您把借条和催款的聊天记录找出来，我给您算。」

### 服务与报价

分段：发函催告 / 保全 + 立案 / 一审 / 执行。

**保全这一步要单独讲清**——保全费、保全担保费通常是另算的，不含在律师费里。

### 收尾

> 「您把借条、转账记录、催款的聊天记录都截出来，我这边看一遍，能给您一个大概的判断：现在还能不能主张、走哪条路、要不要先保全。」

---

## 三、合同纠纷

### 开场

> 「这类案子我得先看到合同。不是不信您转述，是**合同里每一条都跟别的条连着**，单抽一条出来讲，容易讲成对我们不利的样子。」

### 必问事实（按重要性）

1. **您想要的是什么**——继续履行、解除合同并赔偿、还是只要违约金？（**方向定不下来，后面全是空转**）
2. 合同签的哪一方、有没有原件、有没有补充协议
3. 谁先违约、违约在哪一步
4. 有没有约定违约金、定金、解除条件
5. 履行到哪一步了（付款、交货、验收记录）
6. 有没有欺诈、重大误解、显失公平的情形

### 谈话重点

**不是"谁有理"，是"哪条路对您更值"。**

> 「房价涨了，要房子比要赔偿合适；房价跌了，反过来。**同样一份合同，主张继续履行和主张解除赔偿，是两条完全不同的路，选错方向后面都白做。** 您先告诉我，您真正想要的是哪个结果。」

### 常见异议

**「合同是霸王条款，是不是就没戏了」**
> 「霸王条款不是自动无效。要看它是不是属于**格式条款里不合理地免除对方责任、加重您责任、排除您主要权利**的情形。这类条款可以主张无效，但要具体到哪一条，得看全文。」

**「这么简单，我自己起诉就行」**
> 「程序您可以学，但有三件事比较难自己办：一是判断该主张哪一条请求权——同样的钱，按违约要、按不当得要、按侵权要，举证责任和赔偿范围都不一样；二是财产保全，去晚了对方钱就没了；三是损失怎么举证、违约金能不能调。」

**「对方一直拖着，我能不能要求赔偿」**
> 「能主张，但要有依据。先看合同里有没有约定违约金，再看您实际发生的损失有没有证据。**只说'我损失几十万'，法院不会认，得有票据、有账目、有其他能对应的东西。**」

### 服务与报价

按阶段：发函 / 立案保全 / 一审 / 执行。

**合同审查、起草、见证是单独的服务**，不要混进诉讼报价里。

### 收尾

> 「您把合同原件、补充协议、还有往来的聊天记录、付款凭证都带上。我看完把有利的和不利的都列给您，您再判断值不值得打。」

## 四、劳动争议

### 开场

> 「先算账。您把入职时间、工资多少、怎么离开的跟我说一下，我大概能算出来能主张哪几项。」

### 必问事实（按重要性）

1. **怎么离开的**——公司通知不让来了、自己写的辞职、还是不给排班（**这一条决定整个方向**）
2. 入职时间、有没有签书面合同
3. 工资多少、怎么发的（打卡/现金/谁的名义）
4. 有没有书面解除通知，理由写的是什么
5. 社保交没交、按什么基数
6. 手上有什么能证明劳动关系（工牌、工资流水、工作群、考勤）

### 谈话重点

**不是"公司违法"，是"算下来能拿多少"。**

> 「这类案子能主张的通常是几项加起来：违法解除的赔偿金、未签合同的双倍工资、未休年假、加班费、拖欠的工资。**每一项能不能主张、怎么算，条件不一样。** 我一项项给您说。」

**法律要点**：
- 未签书面劳动合同，可主张二倍工资，**最多十一个月**（劳动合同法）
- 违法解除的赔偿金，按经济补偿标准的二倍
- **劳动仲裁时效一年**，从知道或应当知道权利被侵害之日起算；拖欠劳动报酬在劳动关系存续期间不受一年限制

### 常见异议

**「才几千块，值得打吗」**
> 「值不值看怎么算。您算的是这一笔，我算的是**连着能主张的几笔加起来**。而且这类案子很多不用打到开庭，仲裁申请书递过去，公司就愿意谈了。」

**「我还想在这个行业干，怕被拉黑」**
> 「这个顾虑很实际。那可以先走协商和发函，不急着立案。**但协商也要有底牌，底牌就是证据和时效。** 手上什么都没有去谈，就是求人。」

**「是我自己写的辞职报告」**
> 「那要看辞职报告上写的理由。写的是'个人原因'，主张违法解除就很难；写的是公司拖欠工资、不缴社保，可以往被迫解除的方向走。**那份东西您还在吗？**」

### 服务与报价

仲裁阶段多数地区不收费，但律师费照常。可以按阶段报：仲裁 / 一审 / 执行。

⚠️ **请求支付劳动报酬的案件禁止风险代理**，不能说"要回来再给钱"。

### 收尾

> 「您把劳动合同、工资流水、社保记录、还有离职时的通知或聊天记录找出来。我先看这些，能不能主张、主张几项，看完给您一个清单。」

## 五、工伤

### 开场

> 「工伤这条路我给您捋一遍：**确认劳动关系 → 工伤认定 → 劳动能力鉴定 → 申请仲裁赔偿。** 四步，一步不能省。」

### 必问事实（按重要性）

1. **什么时候受的伤**（**最要紧**——涉及 1 年的申请期限）
2. 给谁干活、有没有签劳动合同
3. 伤在哪、住院多久、有没有诊断证明和病历
4. 医药费谁出的、现在还欠多少
5. 单位认不认工伤、什么态度
6. 有没有买工伤保险

### 谈话重点

**不是"是不是工伤"，是"时间还来不来得及"。**

> 「工伤认定有时间限制：**单位应当在事故发生之日起 30 日内申请；单位不申请的，职工或者近亲属可以在 1 年内直接申请。** 这一年是硬期限。您先告诉我具体是哪一天出的事。」

⚠️ 讲清"1 年"是对的，但**不要替客户断言"您已经过了"**——要看有没有中断、有没有特殊情况，必须核对具体情况。

### 常见异议

**「没签合同，是不是没办法了」**
> 「没签合同反而是常事。**没签也能认定，靠的是其他证据**：工牌、工资转账、微信工作群、同事证言、工地出入记录。这些证据怎么取、什么时候取很关键——等老板警觉了，就取不到了。」

**「包工头跑了 / 公司说是包工头的事」**
> 「这是他们内部的事。您可以向有资质的用工单位或施工单位主张——人能跑，公司和项目跑不了。至于他们之间怎么追偿，是他们自己打官司。」

**「评不上伤残是不是就没什么可赔的」**
> 「不一定。就算评不上伤残，医疗费、停工留薪期工资、护理费这些还是可以主张的。能不能评、评几级，要做鉴定才知道。」

### 服务与报价

工伤案件通常分：劳动关系确认 / 工伤认定 / 鉴定 / 仲裁 / 诉讼。**周期长，分段报更合理。**

⚠️ **请求工伤赔偿的案件禁止风险代理。**

### 收尾

> 「您把病历、诊断证明、还有能证明您在那儿干活的东西（工牌、工资记录、同事联系方式）找出来。我先看能不能直接申请认定，还是要先确认劳动关系。」

## 六、建设工程

### 开场

> 「工程款这类案子，主要看两样：**有没有能算清的结算依据**，和**有没有在期限内主张优先受偿权**。第二样很多人不知道，过期就没了。」

### 必问事实（按重要性）

1. 合同、补充协议、签证单、结算单在不在？**有没有对方签字盖章**
2. 工程验收没有、有没有交付
3. 欠多少、怎么算出来的、有没有对账
4. 有没有实际施工人、转包、分包关系
5. **工程竣工或者约定竣工日期是什么时候**（涉及优先受偿权期限）
6. 发包方有没有其他债权人、项目有没有被查封

### 谈话重点

**不是"他该不该给"，是"有没有能算清的账"。**

> 「有没有一张对方签了字的对账单，比十份合同都管用。没有结算依据，就得做造价鉴定，周期长、费用高，而且结果不一定合您预期。」

### 法律要点

- 建设工程价款优先受偿权优先于抵押权和其他债权
- **行使期限：自发包人应当给付建设工程价款之日起十八个月内**（以现行司法解释为准）
- 这个期限是硬期限，过期视为放弃

### 常见异议

**「工程都没验收，能要钱吗」**
> 「要看合同怎么约定，以及没验收的原因在哪方。如果是因为发包方原因导致没验收，可以主张。这个得看具体条款和履行过程。」

**「甲方说质量有问题所以不给钱」**
> 「这是常见抗辩。要有依据：有没有书面通知、有没有鉴定、问题是不是在保修范围。**如果对方只是口头说，这对他不利。** 但要有准备，可能要走鉴定。」

### 服务与报价

分：发函 / 诉前保全 / 一审 / 二审 / 执行。

造价鉴定费通常另计，金额可能不小，**必须提前说清这笔钱不含在律师费里**。

### 收尾

> 「您把合同、签证单、结算单、验收资料都找出来，我看看有没有能直接算出金额的东西。有对账单最好。」

## 七、公司股权

### 开场

> 「股权的事先问一句：**您是想把钱拿回来就走，还是想继续留在公司？** 这两条路方向相反。」

### 必问事实（按重要性）

1. **要钱还是要权**（决定走哪条路）
2. 公司章程怎么约定、有没有股东协议、有没有代持
3. 出资实缴了没有、有没有抽逃
4. 股权比例、表决权安排、有没有一票否决
5. 有没有分红、账能不能看、有没有被排除在经营之外
6. 争议是跟大股东，还是跟公司

### 谈话重点

**不是"谁对谁错"，是"您是股东还是债权人"。**

> 「股东要退出的路径有三条：股权转让、公司回购、公司解散。**这三条的难度差很多**，而且要看章程怎么约定。您先把章程找出来。」

### 常见异议

**「公司不给我看账，我怎么知道有没有被掏空」**
> 「可以提股东知情权诉讼。**这类诉讼成本低、周期相对短**，而且拿到账册以后才知道下一步怎么走。很多人卡在'不知道公司有多少钱'上，这一步可以先破。」

**「我想退股，但没人接」**
> 「退股本身在法律上没有这个动作，实际上要走股权转让或者回购。转让要看有没有人愿意买、其他股东行不行使优先购买权。**这些章程里通常都写了。**」

### 法律要点

- 股东会决议撤销之诉：**自决议作出之日起六十日内**（除斥期间，过期消灭）
- 股东知情权诉讼不以出资比例为限（一般股东均可主张查阅）

### 服务与报价

公司类案件谈判成分重，可以按小时或者按阶段。

### 收尾

> 「您把公司章程、股东协议、历次股东会决议、还有出资凭证都带上。这些看完，路怎么走基本就清楚了。」

## 八、交通事故与人身损害

### 开场

> 「我先给您把能赔的项目过一遍：医疗费、误工费、护理费、营养费、住院伙食补助、交通费、残疾赔偿金、精神损害抚慰金。哪些能主张、大概什么标准，我一个个跟您说。」

### 必问事实（按重要性）

1. 什么时候、在哪、谁开的车、有没有报警
2. **责任认定书下来没有、怎么划的责、有没有过复核期**
3. 伤在哪、住院多久、有没有做伤残鉴定
4. 对方有没有保险、交强险和商业三者险额度
5. 受害人年龄、户籍、工作、收入、有没有被扶养人
6. 对方和保险公司什么态度、垫付了没有

### 谈话重点

**不是"他多坏"，是"能赔多少、怎么拿到"。**

> 「赔偿标准现在城乡已经统一，按统一标准算。**真正影响数额的是伤残等级、误工损失和被扶养人情况**，这几项才是要争的。」

### ⚠️ 必须纠正的旧说法

**"农村户口赔得少一半，有办法按城镇标准操作"——这是过时且违规的说法。**

人身损害赔偿的城乡二元标准已经统一。现在再讲城乡差异，是拿旧知识误导客户，而且"操作"两个字本身就涉嫌造假。

正确说法：
> 「赔偿标准现在城乡统一了。影响数额的是伤残等级、误工时间、收入情况，这些才是重点。」

### 常见异议

**「交警定我主责，很冤」**
> 「认定书出来后有个复核期限，**过了就不能再提**。您先告诉我定责依据是什么、现场有没有监控、有没有证人。复核是一回事，诉讼里法院也可以不采信认定书，但那需要有相反的证据。」

**「对方一分钱不垫，太欺负人」**
> 「垫付不是法定义务，法律没强制他先给钱。所以我们要做的是**通过程序推**：起诉、保全、把保险公司列为被告。保险公司多数只认判决。」

**「我要做鉴定吗，什么时候做」**
> 「要做，而且时点很重要。一般是治疗终结后做，做早了可能评不上，做晚了有些证据不好补。**具体什么时候做，得看您的伤情和医嘱。**」

### 服务与报价

交通事故案件常按标的比例或阶段收。**注意：人身损害案件可以做风险代理，但比例受 30% 上限限制。**

### 收尾

> 「您把事故认定书、病历、医疗费票据、误工证明、还有对方的保险信息都找出来。这些齐了，我大概能算出一个范围。」

---

## 通用：八个案型的共同原则

1. **开场只做一件事——让他讲。** 不打断、不预设。
2. **必问事实按重要性排。** 先问决定方向的那一条，别从最细的问起。
3. **每问一到两个，给一个判断。** 只问不给，客户会觉得在填表。
4. **法律要点讲"通常""一般"，不讲"一定""肯定"。** 尤其别替客户断言"您这个已经过了时效"。
5. **收尾只给一个下一步 + 一件要准备的事。** 给多了他记不住。

## 05 接案 SOP 与合规红线

## 一、接案六步

### 第 1 步 利益冲突检索（签约前，不是签约后）

签约前必须查：

- 对方当事人是否已是本所客户或在办案件当事人
- 本案关联方是否与在办案件冲突
- 是否同一法律关系的对立双方
- 客户是多方主体时（公司 + 股东 + 法定代表人）需分别确认

**跟客户怎么说**

> 「签合同之前我得先做个利益冲突检索，这是规定动作，不是拖您。万一对方正好是我们所的客户，我代理您就违规了。半天出结果。」

⚠️ 不做会怎样：代理被撤销、退费、行业处分。这是最容易被忽略的一步。

---

### 第 2 步 风险告知（书面 + 口头）

书面告知并留痕：

- 本案可能的不利结果
- 证据不足的风险
- 诉讼或程序周期
- 执行不能的风险
- 费用不包含的项目

**主动讲风险比承诺结果更能签单。** 客户已经听过太多"包在我身上"，你说真话反而稀缺。

> 「这份是风险告知书，我把最坏的情况都写在上面了。您看完签字，不是走形式，是为了将来不管什么结果，咱们都清楚当初说过什么。」

---

### 第 3 步 收费约定

《委托代理合同》写清：

- 服务范围（哪几个阶段、哪些事）
- 收费金额、支付节点
- **不包含的费用**（诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费）
- 主办律师
- 每阶段交付什么

**费用必须进律所账户、必须开票。** 不得私自收取。

涉及风险代理的，先核对是否属于禁止类型、比例是否超限。

---

### 第 4 步 委托手续

- 《委托代理合同》——一般两份，客户留一份
- 《授权委托书》——**授权范围写清楚**（一般授权 / 特别授权）。特别授权含和解、放弃、变更诉请，**必须明确告知客户并留痕**
- 风险告知书 / 谈话笔录（客户签字）
- 身份证复印件、营业执照副本、法定代表人身份证明

---

### 第 5 步 材料清单

当场给，别让他回去猜。

**通用**

- 身份证（正反面）、居住证明（涉及管辖）
- 与本案有关的合同、协议、补充协议
- 付款凭证、转账记录、发票、收据
- 往来沟通记录（微信、短信、邮件、录音）
- 已有裁判文书（如有在先诉讼）

**分案型增补**

| 案型 | 追加材料 |
|---|---|
| 婚姻家事 | 结婚证、户口本、子女出生证明、财产凭证（房产证、车辆登记证、银行流水、股权证明）、报警记录与就诊记录 |
| 民间借贷 | 借条/欠条、转账凭证、催收记录、担保材料、对方财产线索 |
| 合同纠纷 | 合同原件、履行凭证、验收单、往来函件、违约证据 |
| 劳动争议 | 劳动合同、工资流水、社保记录、考勤、解除通知、工作沟通记录 |
| 工伤 | 病历、诊断证明、劳动关系证据（工牌、工资记录、同事联系方式）、事故证明 |
| 建设工程 | 施工合同、签证单、结算单、验收报告、往来结算函 |
| 公司股权 | 公司章程、股东协议、出资凭证、股东会决议、财务资料 |
| 交通事故 | 事故认定书、病历、医疗费票据、误工证明、伤残鉴定意见、保单 |

**跟客户怎么说**

> 「这张单子您拿回去对着找，有就给原件，没有也别自己编——缺什么我们想办法补。材料齐不齐，直接决定这案子打得多顺。」

---

### 第 6 步 建档与留痕

- 建客户档案（纸质 + 电子）
- 记录：接案时间、来源、案由、标的、收费、主办人、关键节点
- **重要沟通都留痕**（客户说了什么、你承诺了什么、他确认了什么）

**为什么留痕**：客户投诉时，"我说过"和"我没说过"之间，只有记录能证明。

| 类型 | 怎么处理 |
|---|---|
| 姓名 | 张某某、A 某、当事人甲 |
| 手机号 | 138****0000 或直接删掉 |
| 身份证号 | 完全删掉（用不到） |
| 住址 | 只留到区一级 |
| 银行卡/账号 | 删掉，或只留后四位 |
| 车牌号 | 部分遮挡 |
| 公司全称 | 用"某科技公司"替代（除非案情必须） |
| 案号 | 可保留（一般已公开） |

### 2.2 不要整份粘贴卷宗

- 需要 AI 帮你想话术时，**只给这句话的上下文**，不需要整份材料
- 需要分析案情时，只给关键事实，不给原始证据全文
- 涉及未成年人、性侵、医疗隐私等敏感案件，**进一步降低细节颗粒度**

### 2.3 跟客户怎么说

> 「您发给我的这些东西，我会按执业规定保管，不会外传。另外您发的时候，身份证号、银行卡号这些不用发，我用不到。」

### 2.4 保密义务的法律依据

律师对执业活动中知悉的委托人信息负有保密义务，这是法定要求，不因委托关系结束而终止。

**用 AI 处理信息时，保密义务不因此免除。** 脱敏的责任在律师，不在工具。

## 三、合规红线

### 3.1 绝对不能说的六类话

| 违规表述 | 性质 |
|---|---|
| "这个案子包赢 / 我保证能拿回来" | 对办案结果作不当承诺 |
| "我跟×法院/公安很熟，能打招呼" | 暗示影响办案，涉嫌违法 |
| "别的律师都不行 / 他就是骗子" | 诋毁同行 |
| "我们去年这类案子办了几百件"（不实） | 虚假宣传 |
| "病历/结算单/证据我帮你弄一下" | 教唆伪造证据 |
| "拿不到钱一分不收"（禁止类案件） | 违规风险代理 |

### 3.2 三件绝对不做

1. **不做结果承诺。** 客户逼、单子要飞，都不承诺。这是唯一不能妥协的一条。
2. **不碰证据造假。** 不改材料、不暗示客户去"找人开证明"、不建议证人改口。
3. **不私下收费。** 所有费用进律所账户、开票。没有例外。

### 3.3 关于"判断客户心理"的边界

本 skill 会帮你分析客户可能的顾虑，**那是给你判断用的，不是给你说给客户听的**。

- ✅ 可以：判断他担心什么，从而知道该先解释哪一块
- ✅ 可以：识别他是不是真的准备委托，从而合理安排时间
- ❌ 不可以：把"您其实是想白嫖"这类话说出口
- ❌ 不可以：利用客户的急迫、恐惧，催他当场决定
- ❌ 不可以：明知案子没把握，为了费用硬接

## 四、旧话术警示表

市面上流传的谈案话术资料里，有一批内容**已经不适用或不能用了**。遇到类似说法，对照这张表：

| 旧说法 | 问题 | 现在怎么说 |
|---|---|---|
| "农村户口赔偿少一半，我们有办法按城镇标准操作" | 城乡标准已统一；"操作"涉嫌造假 | 按统一标准算，重点争伤残等级与误工损失 |
| "全成都的交警队没有不认识的" | 违规宣传 | 只谈证据和程序，不谈关系 |
| "出院证明和护理费我们可以操作" | 教唆伪造证据 | 依法举证，缺证据就补证据 |
| "报价明细搞复杂点，设置价格诱饵" | 价格欺诈 | 按阶段列清，总额说清 |
| "把他整成失信老赖名单" | 律师无权决定，属虚假承诺 | 说明可申请强制执行、可申请限制措施，但不承诺结果 |
| "诉讼时效是两年" | 已失效 | 一般诉讼时效**三年** |
| "抚养权 10 岁以上听孩子意愿" | 与现行法不符 | 已满**八周岁**应尊重真实意愿 |
| "我们所不做风险代理，全城没有一家做" | 与事实不符 | 按法定范围说明能做与不能做 |
| "带客户去做鉴定能评高一级" | 暗示影响鉴定结论 | 讲清鉴定时点与材料准备，不讲"能评高" |
| "帮客户介绍融资方贷款交律师费" | 利益冲突 + 风险极高 | 建议分期或分段收费，不介入借贷 |
| 纯"挑矛盾"式煽动话术 | 伦理风险，可能损害客户利益 | 保留"揭示真实风险"的功能，去掉"制造情绪"的部分 |

**统一原则**：凡是靠"我知道你不知道的内幕"取信客户的话术，一律不用。

## 五、输出自检（每次给话术之前过一遍）

- [ ] 第一段是不是能直接用的话？
- [ ] 有没有先讲一通分析？
- [ ] 是不是太长？（事中超过 400 字就太长）
- [ ] 有没有替客户断定心理？
- [ ] 有没有承诺结果、夸关系、贬低同行？
- [ ] 有没有编造案例、办案量、胜诉率？
- [ ] 引用的法条是不是现行有效？时效、年龄、赔偿标准核对了吗？
- [ ] 涉及金额的，有没有编数字？（金额必须由律师自己定）
- [ ] 有没有利用客户情绪施加压力？
- [ ] 涉密信息复述进去了吗？

## 六、接案之后

1. **24 小时内发一条确认信息**：下一步做什么、要他配合什么、什么时候联系他
2. **第一次进展主动汇报，不要等他问**——这一条决定他会不会给你转介绍
3. **结案后要一次反馈**：问他对服务有什么意见

案源的本质不是话术，是**上一个客户愿不愿意替你说话**。

## 06 全流程谈案台本

**这本是提词器，不是教材。** 放在桌上，电话响了扫一眼就能念。

三个符号：
- `（停）` = 闭嘴，等他说完。**这是全本最要紧的符号**
- `【分支】` = 他这么说，你这么接
- `⚠️` = 这一步最容易出问题

---

## 第 0 幕｜接通前 10 秒

**唯一任务：把心态调到"我是来搞清楚情况的"。**

三条总则：

1. **一轮只给一个判断、一个动作**
2. **每问完一句就停**
3. **不确定就说不确定**

⚠️ 全场的比例：**你说的话不超过一半。**

---

## 第 1 幕｜开场

### 1-1 电话

> 「喂，您好，××律师事务所，我姓×。您说。」

（停，让他讲）

不问"有什么可以帮您"，那是客服腔。你只做三件事：不打断、记关键词、嗯一声。

### 1-2 微信

> 「您好，我是××律所的×律师。您先说说情况，我看到就回。」

**中间回复只给框架，不给完整分析：**

> 「您这个事，核心是三个点：①……②……③……。这三块每一个都有讲究，打字容易说偏。方便的话通个电话，五分钟讲得清。」

### 1-3 面谈

前五分钟不谈案。给水、问路上、看一眼他带的材料。

> 「您这材料整理得挺仔细，一般人过来都是一团。」

夸具体的东西，不夸人。

---

## 第 2 幕｜听 + 复述

**唯一任务：让他从"讲情绪"进入"讲问题"。**

### 2-1 他一直在讲

不打断，但要有节奏地回应：

> 「嗯。」
> 「然后呢？」
> 「这块您再细说说。」

### 2-2 复述确认（全场最关键的一步）

> 「我先把您说的理一遍，您看我理解得对不对——第一……；第二……；第三，您现在最想解决的是……。是这样吧？」

**为什么必须做**：一是证明你在听；二是把他散乱的话整理成"问题"，能被说清的问题才谈得下去；三是从他嘴里拿到第一个"是"。

### 2-3 把"讲道理"拉到"要结果"

> 「所以您现在要的不是'这事到底谁有理'，是**怎么把钱拿回来 / 怎么把婚离掉 / 怎么把赔偿要到位**。」

⚠️ 这一句决定后面能不能谈钱。他还在"讲道理"的频道里，你说什么价他都觉得贵。

---

## 第 3 幕｜发问

**唯一任务：挖事实，同时了解他的实际处境。**

### 3-1 通用节奏

> 「我问几个问题，您别嫌烦，这些直接影响后面怎么弄。」

然后：**问一到两个 → 回一个判断 → 再问下一个。**

示范：

> 「这事什么时候发生的？」
> （答）
> 「嗯，这个时间点很关键，**诉讼时效是三年，从您知道权利被侵害那天算**。您这个还剩多久，我得把日期问准才能算。」
> 「那手上有没有合同、转账记录这些？」
> （答）
> 「有就好办。没有也不是不能打，要靠别的证据补。」

⚠️ **问了要给判断。** 只问不给，他会觉得自己在填表。

### 3-2 他躲问题怎么办

**同一个问题问第二遍，他会躲得更坚决。** 换问法——问经过，不问材料。

| 你想问 | 换成这样问 |
|---|---|
| 有没有借条？ | 这个钱当时是怎么给他的？转账还是现金？ |
| 有没有劳动合同？ | 你进去的时候，是谁跟你谈的？签东西了吗？ |
| 有没有家暴证据？ | 他打你那次，你有没有去医院？报警了吗？ |
| 有没有合同原件？ | 当时是当面签的，还是寄过来签的？ |

**原理**：问材料是审问，问经过是聊天。人在聊天时防御低，答案一样能定性。

### 3-3 他说"记不清了"

别追问，改成让他往外掏：

> 「那你手上跟这个事有关的，现在都有什么？截图、聊天、录音、转账记录，什么都行，你先翻一翻。」

### 3-4 信息不够时

**标准句式**：

> 「这个得看材料才能定，我现在给您个数，是不负责任的。」
> 「这一点我先记下，回头核了再回您。」

⚠️ 最容易犯的错：时间点还没问准，就说"时效快过了"。**说错的代价不是丢单，是客户回头拿你的话堵你。**

### 3-5 八个案型的必问索引

| 案型 | 先问这三件 | 详见 |
|---|---|---|
| 婚姻家事 | 孩子多大跟谁／财产登记在谁名下／对方什么态度 | `04` 一 |
| 债务借贷 | **钱怎么给的**／有没有约定还款日／最近一次催是什么时候 | `04` 二 |
| 合同纠纷 | 要履行还是要赔偿／谁先违约在哪步／有没有约定违约金 | `04` 三 |
| 劳动争议 | 怎么离开公司的／签没签合同／工资怎么发 | `04` 四 |
| 工伤 | **哪天出的事**／给谁干活、签没签合同／伤在哪、费用谁出 | `04` 五 |
| 建设工程 | 有没有签字盖章的结算单／验收没有／**竣工日期** | `04` 六 |
| 公司股权 | 要钱还是要权／章程怎么约定／实缴了没有 | `04` 七 |
| 交通事故 | 认定书下来没有、怎么划责／伤在哪、鉴定做了没有／保险额度 | `04` 八 |

---

## 第 4 幕｜说明法律路径

**唯一任务：让他自己看明白有哪几条路。**

### 4-1 排比法

> 「这事无非两条路。一条是您自己去谈——您已经谈过了，什么结果您比我清楚。
> 另一条是走程序。走程序的好处不是'法院帮您出气'，是**把主动权换到您手上**：该保全的保全，该立案的立案。他拖，程序不让他拖。」

### 4-2 他说"法律没用，我都试过了"

> 「您走到这一步确实累。但您试过的这些，**都是在'没有人强制他'的前提下试的**。
> 程序真正有用的地方就一个：**它能让对方不得不坐下来。** 判决、保全、执行，这些不是讲道理，是硬约束。」

### 4-3 他只想出气

> 「这个气我理解。但咱们先把目标定清楚：是要他难受，还是要钱回来？
> 这两件事有时候一致，有时候相反。为了让他难受而多花钱、多耗时间，最后钱没拿回来，气也没出成。」

---

## 第 5 幕｜讲清能做什么

**唯一任务：让他知道你会做哪些具体的事。**

### 5-1 讲工作，不讲形容词

> 「这个案子我要做的是：查对方财产、做保全、立案、开庭，中间可能还有一次调解，文书、证据、跟对方沟通都算在里面。」

**不讲**："我们非常专业""我们经验丰富"——这类话客户听过一万遍。

### 5-2 他逼你给结果

> 「正因为做得多了，才知道同一个案情换个证据、换个法院，结果就不一样。谁张嘴就给您一个准数，您反而要当心。」

### 5-3 讲经验（不吹、不编）

> 「这类案子我做过，最容易出问题的地方在××。很多人不知道这一层，办到一半才发现要返工。」

⚠️ **不编案例、不编数量。** 真实讲一个就够，编十个就废。

---

## 第 6 幕｜约下一步

**唯一任务：给一个具体、可执行的下一步。可以是见面，也可以不是。**

### 6-1 约见面

> 「这样，电话里我只能给您个方向。合同/欠条/病历这些，每一份都影响判断。
> 您把材料带上，过来坐半小时，我当面给您把路径捋清楚——**您听完觉得我行，我们再谈委托；觉得不行，您拿着这个思路自己走也可以。**」

### 6-2 不约见面也可以

**有些客户线上就能谈，有些来了也不会签。**

> 「您先把材料拍给我，我看完给您写个书面意见，包括能主张什么、大概多久、要准备什么。您看完再决定下一步。」

### 6-3 二选一锁时间

> 「那您看是今天下午方便，还是明天上午？」
> （选了明天上午）
> 「行，明天上午十点，我给您留出时间。地址我发您手机上。」

### 6-4 饭桌上被问价

> 「×总，今天谢谢您。案子的事我听明白了，方向心里有数了。**价格这事饭桌上说不合适**——有旁人在，说岔了回头朋友难做。您明天抽空过来一趟，我给您出个具体方案。」

⚠️ 饭桌不报价。酒桌上的数字第二天就变味。

---

## 第 7 幕｜报价

**唯一任务：说清多少钱、包含什么、不包含什么。**

详细规则见 `03-报价与收费话术.md`。这里是台本版。

### 7-1 可以直接报价了（本版不再要求必须先见面）

> 「按您说的情况，大概在××到××之间。这个范围是按××算的——如果材料看完发现有××，会往上走；比想的简单也可能往下。」

### 7-2 按阶段报

> 「分三段：保全加立案，××；一审，××；执行，××。每段做完再付下一段。不做执行，第三段就不收。」

### 7-3 他要明细

> 「可以。我按阶段给您列，每个阶段做什么、大概多少时间，都写清楚。**不包含的费用也标出来**——诉讼费、保全费、鉴定费这些是另算的。」

### 7-4 他砍价

**第一轮：说明，不急着让**
> 「这个价是按这个案子实际的工作量报的，没往上留空间。」

**他还是要让**
> 「那咱们换个方式：分两段付，先做保全加立案这一段，做完您看到东西了再决定要不要往下走。这样您压力小一些，我也不至于干到一半没着落。」

**确实要让，要说清交换**
> 「这个数我去报一下看看，能不能批我不敢保证。要是批了，服务范围还是刚才说的那些，不再加项。」

⚠️ **不演戏**：明明自己能定不要说"我去请示领导"；不要说"今天签才有这个价"。

### 7-5 他要比价

> 「报价差得多是正常的。您方便问一下那边三件事：含不含开庭、含不含执行、中间有没有另外收的费。这三样不一样，最后总价可能差得比现在这个差额还大。」

⚠️ 不说同行不专业。**不接"他们不靠谱"这个话头。**

---

## 第 8 幕｜异议速查

**异议不是拒绝，是他在给继续谈的机会。**

| 他说 | 你接 |
|---|---|
| 怎么收费？ | 「价格跟案子关系很大。您先说说是什么事、手上有什么，我说出来的数才有意义。」 |
| 太贵了 | 「理解。那我把这个钱花在哪跟您说一下：这个案子要跑保全、立案、开庭，中间可能还有调解……」 |
| 别人只收五千 | 「差这么多是常事。您方便问一下那边含不含开庭、含不含执行、后面还有没有别的收费。」 |
| 能保证赢吗 | 「这个我不保证，也没人该保证。我能做的是把证据理清楚、程序走到位。」 |
| 我再想想 | 「行，这个事该想清楚。您考虑的时候主要是费用这块，还是有别的地方没底？」 |
| 跟家人商量 | 「应该的。您商量的时候我把今天说的几个点整理一份给您，您拿给他看比自己复述清楚。」 |
| 我最近忙 | 「忙是正常的。那我先把要准备的材料列一份给您，您有空对着找，找齐了再说下一步。」 |
| 赢了也执行不到 | 「您没查过就不知道他有没有钱。起诉以后法院能查房、车、股权、账户，这些您自己查不到。」 |
| 你有关系吗 | 「这个我不敢说，也不该说。现在办案全程留痕。真正管用的是证据和程序。」 |
| 我朋友也是律师 | 「那挺好。不过朋友要么不收钱（不会真投入时间），要么收钱（不如找专做这类的）。」 |
| 你这么年轻 | 「经验不在年纪，在这类案子办过多少。您这案子我看下来，最容易出问题的地方在××，您听这一段自己判断。」 |
| 律所靠谱吗 | 「这话该问。我不保证什么，给您两个办法：执业证号可以去司法局网站查；办过的案子我讲两三个，您自己去核。」 |
| 我自己也能弄 | 「程序您能学。但查财产、保全、判断该主张哪条请求权，这三样比较难自己办。」 |
| 先办事后付款 | 「要看案件类型。您这个（如是禁止类）按规定不能做风险代理。能谈的是分段付。」 |
| 我决定不请了 | 「行，理解。有需要随时找我。」（可补一句时间点提醒，只一句） |

**完整 15 类、含"不建议这样说"的版本见 `02-异议应答库.md`。**

---

## 第 9 幕｜收尾

**唯一任务：给一个具体的下一步，并且允许他不选你。**

### 9-1 标准收尾

> 「那我们定一下下一步：**明天上午十点，您把××和××带过来**，我给您出个书面方案。」

### 9-2 他还在犹豫

> 「不着急定。我把今天说的整理一份给您，您带回去看，有问题随时问我。」

⚠️ **不必每次都要求当场决定。** 逼出来的委托，后面麻烦更多。

### 9-3 他今天就走了

> 「行，我给您发个短信，把今天说的三件事写清楚，您回去对照着看。」

---

## 第 10 幕｜没签之后

**当天做三件事**：

1. 发一条短信：核心三点 + 需要他准备的资料
2. 记一个卡点：他停在哪个环节
3. 设一次触点：三五天后给一条**有用的新信息**，不催单

> 「您那个案子我看了下类似的判例，有个点对您有利，发给您看看。」

⚠️ **不打电话催，不发"考虑得怎么样了"。** 一次有用的信息，胜过十次问候。

**复盘见 `07-谈案助手输出规范.md` 第四节。**

---

## 第 11 幕｜谈成之后

1. 利益冲突检索（签约前）
2. 委托合同 + 授权委托书（**特别授权必须明确告知并留痕**）
3. 风险告知书
4. 材料清单（当场给）
5. 24 小时内发确认信息：下一步做什么、要他配合什么、什么时候联系他
6. 第一次进展**主动汇报**，不等他问

详见 `05-接案SOP与合规红线.md`。

## 附录 A｜微信 vs 电话：同一句话两种说法

这是本版新增的重点。同一个意思，微信要短，电话要活。

### A-1 报价前需要看材料

> **微信**：「收费跟材料关系很大，同样的事，证据全不全差很多。您把合同和转账记录拍给我，我看完给您一个准数。」
>
> **电话**：「收费这个……得看您手上有什么。您要是合同、转账记录都在，那好办；要是什么都没有，那活就完全不一样了。您先跟我说说手上有什么？」

### A-2 客户嫌贵

> **微信**：「理解，费用确实要算一下。不过我建议您先确认一下两边包含的服务是不是一样——比如开庭、执行在不在里面，后面还有没有别的收费。比清楚再决定更稳妥。」
>
> **电话**：「理解，费用是要考虑的。不过我建议您先问清楚一件事——那边报的价，含不含开庭，含不含执行，后面还有没有别的费用。这个比价格本身更影响您最后花多少。」

### A-3 不能保证结果

> **微信**：「这个我没法保证。案子怎么判取决于证据、对方怎么应诉、法院怎么认定。我能做的是把证据理清楚、程序走到位。」
>
> **电话**：「这个我不保证，也没人该保证。我能保证的是过程——证据怎么补、程序怎么走、每一步我提前跟您说。」

### A-4 约下一步

> **微信**：「那您看明天下午还是后天上午方便？我给您留出时间。」
>
> **电话**：「那您看是明天下午方便，还是后天上午？……行，明天下午三点，我给您留着。」

### A-5 拆成两条发（微信专用）

长句拆开，第二条不要重复第一条的意思：

> 第一条：「理解，费用确实要算一下。」
> 第二条：「不过我建议您先问清楚一件事——那边报的价含不含开庭、含不含执行，后面还有没有别的收费。这个比价格影响更大。」

## 附录 B｜可直接用的句子

**开场 / 控场**
1. 「您说，我听着。」
2. 「我先把您说的理一遍，您看对不对。」
3. 「我问几个问题，您别嫌烦，这些直接影响后面怎么弄。」
4. 「这一点我先记下，回头核了再回您。」

**给判断 / 不承诺**
5. 「这个我不敢跟您保证，谁跟您保证都不作数。」
6. 「我现在给您一个数，是不负责任的。」
7. 「能不能成，得看手上有什么、材料能证明什么。」
8. 「这类案子最容易出问题的地方在××。」

**推进**
9. 「电话里我只能给您个方向，看材料才能定。」
10. 「您听完觉得行，我们再谈委托；觉得不行，您拿着这个思路自己走也可以。」
11. 「您看是今天下午还是明天上午？」
12. 「地址我发您手机上。」

**报价**
13. 「这个价是按这个案子实际的工作量报的。」
14. 「分三段，每段做完再付下一段。」
15. 「不包含的费用我也标出来——诉讼费、保全费、鉴定费这些是另算的。」

**异议**
16. 「您这个顾虑很正常。」
17. 「您现在最拿不准的是哪一块？」
18. 「这个数我去报一下看看，能不能批我不敢保证。」
19. 「行，那我不留您，我给您发个短信把今天说的写清楚。」
20. 「这事不用您自己扛，交给我。」

## 07 谈案助手输出规范

本文件定义这个 skill 唯一的输出形态。**没有第二种模式，不做角色扮演，不演客户。**

---

## 一、三条总原则

1. **先给话，后给理由。** 第一段必须能直接用。
2. **短。** 事中场景超过 400 字就是失败。律师在看手机的间隙里读你。
3. **不确定就写"可能"。** 客户没说过的心理，不许编成事实。

---

## 二、事中输出：三段式（最高频）

客户刚说了一句话，律师在等一句能回的话。

### 2.1 格式

```
【建议你这样回复】
（一段话，可直接复制到微信，或直接念出来）

【对方如果继续追问】
客户："……"
建议："……"

【提醒】
（当前最该注意的一件事，一到两句）
```

**追问分支给几个？** 1-2 个。给多了律师挑不过来，也不符合真实对话只有一条路的事实。

**什么时候省略"追问"段？** 客户还没表达出明确异议、只是陈述事实时，可以只给两段。

### 2.2 示例一｜嫌贵 + 比价

**律师输入**：
> 客户说你们收费太贵了，别的律师只收五千。

**输出**：

> **【建议你这样回复】**
>
> 您比较几家是正常的，律师费确实得考虑。不过我建议您先确认一下，两边包含的服务内容是不是一样——比如开不开庭、包不包含执行阶段、后面还有没有另外收的钱。这几项比价格本身更影响您最后总共花多少。
>
> **【对方如果继续追问】**
>
> 客户："那你到底比他好在哪？"
> 建议："我可以具体跟您说，我这个案子打算怎么弄、包含哪些活、有哪些地方是需要您配合的。您听完再判断值不值这个价。"
>
> **【提醒】**
>
> 不要贬低其他律师，也不要编自己的办案数量。说清你做什么，比说别人不行有用。

### 2.3 示例二｜要求保证结果

**律师输入**：
> 他现在问我能不能保证赢。

**输出**：

> **【建议你这样回复】**
>
> 这个我没法保证，也不该有人跟您保证。诉讼结果取决于证据、对方怎么应诉、法官怎么认定，不是律师能定的。我能做的是把您这边的证据理清楚、把该走的程序走到位，把能争取的空间尽量争到。您如果想听"包赢"这两个字，我给不了；但案子怎么打，我可以跟您讲清楚。
>
> **【对方如果继续追问】**
>
> 客户："那别的律师说能赢，是不是你没把握？"
> 建议："您可以让那位律师把'能赢'的依据说具体一点——凭什么赢、靠哪几份证据赢。说得出来，您可以多听听；说不出来，那句话对您没什么用。"
>
> **【提醒】**
>
> 不要顺口说"大概八九成""问题不大"，这类话在实践中都算不当承诺。

### 2.4 示例三｜说要考虑

**律师输入**：
> 客户说回去考虑一下。

**输出**：

> **【建议你这样回复】**
>
> 行，这个事确实该想清楚。您考虑的时候有个东西可以帮您判断——我把您这个案子接下来大概要走的几步，还有每步需要您配合什么，发一份给您，您对着看会比空想清楚些。
>
> **【对方如果继续追问】**
>
> 客户："那你觉得我这官司值得打吗？"
> 建议："值不值，得看您最想要的是什么——是要这笔钱，还是要个说法，还是想尽快了结。这三个目标打法不一样，成本也不一样。您先定这个，我再告诉你哪条路划算。"
>
> **【提醒】**
>
> 不要追问"您还在犹豫什么"，也不要约"我明天再给您打电话"。给一份有用的东西，然后等。

### 2.5 长度控制

| 场景 | 上限 |
|---|---|
| 三段式全部 | 400 字以内 |
| 「建议你这样回复」那一段 | 微信 100 字以内；电话 150 字以内；面谈可以到 250 字 |
| 「提醒」 | 两句话，超过两句就是在讲课 |

---

## 三、事前输出：谈案准备清单

律师说"明天有个××案子要谈"，输出七项。**顺序固定，不要增减。**

```
1. 开场话术（照念）
2. 必须问清的事实（3-5 条，按重要性排序）
3. 客户可能的顾虑（写"可能"）
4. 这场谈话的重点（一句）
5. 常见异议及回应（3 条，按本案型挑）
6. 服务介绍与报价注意事项
7. 怎么收尾
```

### 示例｜明天有个劳动争议客户来咨询

> **1. 开场**
>
> 「先听您说，您把情况从头讲一遍，中间我可能会打断问几个问题，您别介意。」
>
> **2. 必须问清**
>
> - 怎么离开公司的——公司通知不让来了，还是自己写的辞职？（**这条最重要，观点完全不同**）
> - 入职时间、有没有签书面合同
> - 工资多少、怎么发的（打卡/现金/谁的名义）
> - 拿过什么书面东西（解除通知、工资条、考勤）
>
> **3. 他可能担心的**
>
> - 材料不全能不能打
> - 打了会不会影响下一份工作
> - 公司拖着不给钱
> - 律师费会不会比能拿到的还高
> - 时间要多久
>
> **4. 这场谈话的重点**
>
> 让他明白：能不能拿到钱，取决于能证明什么，不取决于公司做错了什么。
>
> **5. 常见异议**
>
> | 他说 | 你回 |
> |---|---|
> | 才几千块，值不值得打 | 「先把能主张的几项加一起算算，您再判断。有时候不是一笔，是几笔。」 |
> | 我还想在这个行业干 | 「可以先协商发函，不急着立案。但协商也要有底牌，底牌就是证据和时效。」 |
> | 公司说是我自己走的 | 「所以辞职报告上写了什么很关键。您手上有那份东西吗？」 |
>
> **6. 服务与报价**
>
> 讲清做哪几个阶段、每阶段交什么、哪些费用不含（仲裁不收费，但可能有鉴定、差旅）。**不在没看材料时报总价。**
>
> **7. 收尾**
>
> 「您把劳动合同、工资流水、解除通知这些找出来，明天下午或者后天上午拿过来，我看完给您一个具体方案。到时候再谈费用。」

⚠️ 第 6 项不许编金额，不许编律所收费规则。律师自己的报价权限他不知道，不能替他定。

---

## 四、事后输出：复盘四段

```
1. 可能卡住的地方
2. 为什么这句话可能有障碍
3. 更好的替代表达
4. 下次最值得改的一件事（只给一件）
```

### 硬规矩

**客户没签，不等于律师失败。**

没签的原因可能是：预算不够、需求变了（比如对方主动还钱了）、案子本身没法接、家里不同意、客户就是想再比比、客户自己决定不请律师。

**没有完整对话记录时，必须加一句**：

> 「以下判断基于您提供的有限信息，可能有偏差。」

**不许做的**：
- 打分数、评级（A/B/C、及格不及格）
- 说"这次谈案失败了"
- 说"客户明显是在比价"（他没说，你就不能断定）

### 示例

**律师输入**：
> 今天那个客户最后没签，他说回去考虑，后来微信也没回。

**输出**：

> **1. 可能卡住的地方**
>
> 从您描述的这一步看，最可能在费用那一段没谈透——他说"考虑"，通常不是真的在想，而是有个具体顾虑没解决但不想当面讲。
>
> **2. 为什么可能有障碍**
>
> "回去考虑"是个很安全的话，谁都能说，不用承担拒绝你的尴尬。如果前面没有出现过他主动问细节（比如"多久能打完""要准备什么"），说明他还没走到"准备委托"这一步。
>
> **3. 更好的表达**
>
> 那时候可以问一句具体的：「您考虑的时候，主要是费用这块，还是有别的担心？」——问具体的，比问"您还在犹豫什么"好接。
>
> **4. 下次最值得改的一件事**
>
> 收尾不要停在"您考虑好了联系我"。给一个具体的下一步：一份材料清单，或者一个明确的时间点。
>
> （以上判断基于您提供的有限信息，可能有偏差。）

---

## 五、场景改写：同一句话的三种说法

### 对照表

| | 微信 | 电话 | 面谈 |
|---|---|---|---|
| 长度 | 100 字内，必要时拆两条 | 150 字内 | 250 字内 |
| 语气 | 简洁，不用"您"堆满 | 口语，允许"嗯""对" | 可以多解释 |
| 连接词 | 少用"不过""因此" | "那""就是说" | 随意 |
| 提问 | 一次一个问题 | 一问一停 | 可以边看材料边问 |

### 同一个意思，三种写法

**要表达的意思**：报价之前我需要看材料。

> **微信**
> 「收费跟材料关系很大，同样的事，证据全不全差很多。您把合同和转账记录拍给我，我看完给您一个准数。」

> **电话**
> 「收费这个东西……得看您手上有什么。您要是合同、转账记录都在，那好办；要是什么都没有，那活就完全不一样了。您先跟我说说手上有什么？」

> **面谈**
> 「我先把话说在前头，收费我不拍脑袋报。您这些材料我看一遍，大概要花多少工夫我心里就有数了，那时候报的价才是准的。现在给您个数，对您不负责任。」

### 拆成两条发（微信专用）

长句拆成两条，第二条开头不要重复第一条的意思：

> 第一条：「理解，费用确实要算一下。」
> 第二条：「不过我建议您先问清楚一件事——那边报的价含不含开庭、含不含执行，后面还有没有别的收费。这个比价格本身影响更大。」

## 六、局部修改指令

律师说下面这些话时，**只改当前这条话术，不重新分析案情，不解释改了什么**。

| 他说 | 你改什么 |
|---|---|
| 再口语化一点 | 去掉书面词，缩短句子，加"那""就是说" |
| 简短一点 | 砍到一半，只留核心一句 |
| 专业一点 | 补上程序或术语，但不能堆 |
| 更温和一点 | 去掉判断句，改成提问或建议 |
| 更有说服力一点 | 补一个具体的、可验证的事实或程序细节 |
| 换一种说法 | 换切入角度，不换意思 |
| 适合微信发 | 缩到 100 字内，去书面连接词 |
| 适合电话讲 | 加停顿，改成口语短句 |
| 给我三个版本 | 给三个不同角度（讲道理／讲程序／讲成本），标一句各自适合什么情况 |
| 太生硬了 | 去掉命令句和反问句，改成陈述 |
| 客户比较强势 | 不硬碰，先承认他的立场，再给事实 |
| 我要更委婉一点 | 结论后置，先说客观情况 |

### 示例｜同一句话的六种改法

**原句**：
> 「这个价我是按您这个案子该花的功夫报的，没往上虚。」

| 改法 | 结果 |
|---|---|
| 口语化 | 「这个价是按您这案子实际要花的工夫算的，没多报。」 |
| 简短 | 「按工夫算的，没多报。」 |
| 温和 | 「我报的时候是按这个案子实际的工作量来的。」 |
| 专业 | 「我按这个案子的工作量、阶段和可能的程序节点核的，没有预留议价空间。」 |
| 微信 | 「按实际工作量算的，没往上加。」 |
| 三个版本 | ①讲道理版：按工作量算的，没多报 ②讲程序版：这案子要跑保全、立案、开庭，工序在这 ③讲成本版：这个钱摊到每个环节其实不多 |

## 七、连续对话：四轮不重样

律师会一轮轮贴客户的新话。必须接住上下文，且**不重复上一轮**。

### 每轮要记住的六件事

1. 已知案情（不再问第二遍）
2. 当前场景（微信／电话／面谈）
3. 客户提过哪些顾虑
4. 已经给过哪些话术
5. 律师已经做了什么
6. 现在最该解决哪一个

### 完整示例｜四轮

**第一轮**
> 律师：客户说太贵了。

> **【建议你这样回复】**
> 费用我理解，确实要算一下。不过我想先确认一件事——您现在最担心的是总共要花多少，还是担心花了钱事情办不成？这两个我能给您的答案不一样。
>
> **【对方如果继续追问】**
> 客户："都担心。"
> 建议："那我这么跟您说：总共花多少我现在能给您一个范围，但准数得看材料；能不能办成，谁都不能保证，我只能告诉您有哪些把握、有哪些风险。"
>
> **【提醒】**
> 先分清他怕的是"贵"还是"亏"，这两句话术完全不同。

**第二轮**
> 律师：他说其他律所报价更低。

> **【建议你这样回复】**
> 报价有差别很正常。您方便的话，可以问一下那边报的价包含到哪一步——是只到开庭，还是含执行；中间有没有另外收的鉴定费、差旅费。这几项不一样，最后总价可能差得比现在这个差额还多。
>
> **【对方如果继续追问】**
> 客户："那就是说他们不靠谱？"
> 建议："我没这么说。我是建议您把两边的服务范围对一下，对完您自己就清楚了。"
>
> **【提醒】**
> 不要接"他们不靠谱"这个话头，一接就变成贬低同行。

**第三轮**
> 律师：他说他之前找过律师，体验很差。

> **【建议你这样回复】**
> 这个我理解，遇到过不顺利的情况，换谁都会有顾虑。您方便说说当时是哪一环让您不放心吗——是沟通少、进展慢，还是费用上后面又加了？我至少能跟您讲清楚，这几件事在我这边是怎么处理的。
>
> **【对方如果继续追问】**
> 客户："上次那个律师收了钱就不怎么理人。"
> 建议："这个我可以给您一个具体的做法：每个阶段该做什么、什么时候做，我提前跟您说；有结果我主动告诉您，不用您来问。您要是发现我没做到，直接跟我说。"
>
> **【提醒】**
> 别急着说"我跟他们不一样"。先问清他上一次具体卡在哪，你的回答才有落点。

**第四轮**
> 律师：他现在问我能不能保证结果。

> **【建议你这样回复】**
> 这个我不保证，也没人该保证。案子怎么判，取决于证据、对方怎么应诉、法院怎么认定。我能保证的是过程——证据怎么补、程序怎么走、每一步我会提前跟您说。您要是需要一句"肯定赢"才敢委托，那我可能不是最合适的人。
>
> **【对方如果继续追问】**
> 客户："那我怎么知道你会不会尽力？"
> 建议："这个没法靠嘴证明。我们可以把每个阶段要做的事写进委托合同，做完一项对一项。您按这个验我。"
>
> **【提醒】**
> 最后那句"我可能不是最合适的人"要敢说。愿意说这句话的律师，反而更容易被信。

⚠️ **四轮里没有一句重复。** 每一轮都在处理新信息，且都建立在前面已经建立的共识上（第一轮定下了"贵还是亏"，后面就不再问）。

## 八、禁止清单

**结构上不许**：
- 五段式（局面判断/该说什么/分支/别做/目标）
- 先分析再给话
- 每轮都问"请描述一下案情"
- 重复上一轮内容
- 动辄给三个版本

**内容上不许**：
- 承诺结果
- 编办案数量、胜诉率、履历
- 提司法关系
- 贬低同行
- 替客户断定心理（"他其实是想白嫖"）
- 用"您买的不是××，是××"这类句式
- 连续三个反问求认同
- 制造时间压力逼单
