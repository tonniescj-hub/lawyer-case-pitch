# 二、方法论骨架的来源

**原始人设**：`~/.workbuddy/plugins/cache/experts/case-consultation-expert/1.0.1/agents/case-consultation-expert.md`

**原人设内核**（保留）：

> 谈案不是普法，是心理战与价值战。先读人，再塑价，后收口。

**四块能力**：当事人心理洞察、案件价值塑造、异议化解与委托促成、分案型策略。

**六步流程**：接案定位 → 心理画像 → 价值拆解 → 异议预案 → 收口设计 →（可选）复盘

## 在本 skill 里的落地与修改

| 原人设 | 现在 | 改动 |
|---|---|---|
| 读人 → 塑价 → 收口 | 读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进 | 补上"挖案""报价""跟进"三个环节 |
| 心理画像 | `01` 的观察表 | **加了边界**：只看客户明确说过的话，不贴标签、不虚构动机 |
| 价值拆解 | `01` 塑价段 | 改为"讲工作、讲时间、讲程序"，不放大风险 |
| 异议预案 | `02`，15 类 | 从 3 条扩展到 15 类，四要素结构 |
| 收口设计 | `06` 第 9 幕 | **删除了强制成交导向**：不再要求"必须当场签" |
| 分案型策略 | `04`，8 个民商事案型 | 结构改为：开场/必问事实/谈话重点/异议/服务报价/收尾 |
| 复盘 | `07` 第四节 | 轻量化，不评分、不判定失败 |

## 原人设最大的问题：它是"策略顾问"，不是"话术库"

原人设告诉律师**怎么想**（要读人、要塑价），但不告诉律师**怎么说**。
本 skill 做的是把它下沉到句子层——每条话术都能直接照念。

## 本 skill 补了原人设缺的一层

**场景分流**（电话 / 微信 / 面谈）。原人设默认面谈，但律师大量接案发生在电话和微信，两者的节奏和话术长度完全不同。这是 v1.0 就加入的核心增量。

# 三、话术素材的来源与授权状况（⚠️ 未完全解决）

## 3.1 原始素材清单

构建 v1.0 时使用的四份资料（均为公开流传版本，约 2016 年前后口径）：

1. 《律师对客户经典话术汇总》（约 51 条）
2. 《资深律师的成交话术模板》（7 套电话拒报价话术）
3. 《律师谈案收费的话术模板》一/二/三（13 个模板）
4. 《新人指引话术（律师篇）》（57 页，五大案型电话咨询全流程）

## 3.2 授权状况：无法确认

**这四份资料的原始作者、版权归属、首次发布渠道均无法核实。** 流传过程中的文件为 `.doc` / `.pdf`，无署名、无版权页、无授权声明。

**结论：不能确认有再分发依据。**

## 3.3 已采取的处理

v1.3.0 采取"能不依赖就不依赖"的原则：

| 处理 | 范围 |
|---|---|
| **完全原创重写** | `02` 异议应答库全部 15 类；`07` 输出规范全部；`03` 报价规则全部 |
| **结构性改写** | `04` 八个案型全部改为六块结构，法律要点重新核对，话术重写；`06` 台本全部重排并新增微信/电话对照 |
| **保留的部分** | 少量行业通识性表述，如"价值不到不报价""报价要说明包含范围""分段收费降低客户压力"——这类属于行业通用方法，难谓独创 |
| **已删除** | 所有可识别为原文照搬的长段落、销售技巧话术（"请示领导逼单""今天签才有这个价""永远不接第一次还价"）、以及全部违规与过时内容 |

## 3.4 仍未解决的问题（如实记录）

1. **无法追溯原始作者**，因此无法取得授权，也无法确定是否构成侵权。
2. **部分表述可能仍与原文相似**——法律谈案的基础表达方式有限（"这个价是按工作量算的"这类句子，很难说谁原创）。
3. **如需商业分发**（售卖、付费课程、企业内训），建议进一步改写或咨询专业意见。
4. 本项目的立场是：**方法论公开，话术重写，问题如实记录。**

**不建议对外宣称"完全原创"或"不存在版权风险"。**

# 四、法律要点的核对

原资料多处引用了十年前的司法口径，v1.0 起逐步修正，v1.3.0 复核：

| 事项 | 现行口径 |
|---|---|
| 一般诉讼时效 | **三年**（民法典） |
| 劳动仲裁时效 | 一年；拖欠劳动报酬在劳动关系存续期间不受一年限制 |
| 抚养权 | 不满两周岁以母亲直接抚养为原则；**已满八周岁**应尊重真实意愿 |
| 判决不准离婚后再诉 | 双方又分居满一年，一方再次起诉的，应当准予离婚 |
| 未签书面劳动合同 | 二倍工资，**最多十一个月** |
| 工伤认定申请 | 单位 30 日内；职工或近亲属 **1 年内** |
| 人身损害赔偿 | **城乡标准已统一** |
| 风险代理禁止类型 | 刑事、行政、国家赔偿、群体性诉讼、婚姻继承，以及社保/低保待遇、赡养费抚养费扶养费抚恤金救济金、工伤赔偿、劳动报酬案件——**禁止实行或者变相实行**（司发通〔2021〕87 号） |
| 风险代理收费上限 | **分段累进**：不足 100 万部分 18%；100–500 万部分 15%；500–1000 万部分 12%；1000–5000 万部分 9%；5000 万以上部分 6%。按各环节合计计算（司发通〔2021〕87 号）。**不再是单一 30%** |
| 建设工程价款优先受偿权 | 行使期限约 **18 个月**（以现行司法解释为准） |
| 股东会决议撤销之诉 | **六十日**除斥期间 |

**引用前仍须核对**：当地律协细则、省市收费标准、最新司法解释。本 skill 不替代法条检索（本次升级明确不增加检索能力）。

## v1.3.0 — 2026-10-27 · 轻量增强

**目标**：让律师把客户原话发过来，直接拿到能用的回复。

### 核心改动

1. **默认输出格式从五段式改为三段式**
   - 新格式：`【建议你这样回复】` → `【对方如果继续追问】` → `【提醒】`
   - 理由：五段式在客户正等着回复时太长

2. **删除模拟谈案功能**
   - 移除模拟模式的定义、规则、示例、触发词、切换表
   - 原 07「两种输出模式」重构为「谈案助手输出规范」，只保留助手形态

3. **话术自然度全面清理**
   - 删除八种销售腔：过度使用"您买的不是……"、连续反问求认同、教训口吻、指挥感、危机渲染、贬低同行、话里有话、替客户预判家人
   - 新增"必须做到"与"必须去掉"对照表（见 `SKILL.md` 第五节）

4. **新增连续对话与局部修改规则**
   - 六项记忆清单
   - 12 条局部修改指令（口语化/简短/专业/温和/微信/三个版本……）
   - 四轮连续示例，每轮不重复

5. **报价规则纠正**
   - **取消**"必须先面谈才能报价"的硬性要求
   - **取消**默认三档报价
   - 允许给参考区间，但必须说明依据和不确定性
   - 强化风险代理禁令与"禁止变相风险代理"（不得用咨询费、调查费等名目规避）

6. **六步主线改为灵活参考**

   - 新增"明确拒绝委托"的正确处理（体面收尾，不纠缠）

9. **新增隐私与脱敏专节**（`05` 第二节）

   - 不整份粘贴卷宗

# 六、以后怎么迭代

1. **补真实案例**：把你实际谈成/谈没成的案子按 `07` 第四节填进去，比通用话术有用
2. **本地化**：报价区间、律所名、称呼习惯按实际替换（本 skill 一律用 `××` 占位，不填数字）
3. **调案型权重**：案源集中在哪几块，就把 `04` 那几节写厚，其他压缩
4. **别加承诺类话术**。这个 skill 的价值就在"敢说真话还能谈下去"，加了承诺就废了
5. **持续核对法律要点**。每半年过一遍第四节那张表
