# 05 接案 SOP 与合规红线

---

# 一、接案六步

## 第 1 步 利益冲突检索（签约前，不是签约后）

签约前必须查：

- 对方当事人是否已是本所客户或在办案件当事人
- 本案关联方是否与在办案件冲突
- 是否同一法律关系的对立双方
- 客户是多方主体时（公司 + 股东 + 法定代表人）需分别确认

**跟客户怎么说**

> 「签合同之前我得先做个利益冲突检索，这是规定动作，不是拖您。万一对方正好是我们所的客户，我代理您就违规了。半天出结果。」

⚠️ 不做会怎样：代理被撤销、退费、行业处分。这是最容易被忽略的一步。

---

## 第 2 步 风险告知（书面 + 口头）

书面告知并留痕：

- 本案可能的不利结果
- 证据不足的风险
- 诉讼或程序周期
- 执行不能的风险
- 费用不包含的项目

**主动讲风险比承诺结果更能签单。** 客户已经听过太多"包在我身上"，你说真话反而稀缺。

> 「这份是风险告知书，我把最坏的情况都写在上面了。您看完签字，不是走形式，是为了将来不管什么结果，咱们都清楚当初说过什么。」

---

## 第 3 步 收费约定

《委托代理合同》写清：

- 服务范围（哪几个阶段、哪些事）
- 收费金额、支付节点
- **不包含的费用**（诉讼费、保全费、保全担保费、鉴定费、公证费、差旅费）
- 主办律师
- 每阶段交付什么

**费用必须进律所账户、必须开票。** 不得私自收取。

涉及风险代理的，先核对是否属于禁止类型、比例是否超限。

---

## 第 4 步 委托手续

- 《委托代理合同》——一般两份，客户留一份
- 《授权委托书》——**授权范围写清楚**（一般授权 / 特别授权）。特别授权含和解、放弃、变更诉请，**必须明确告知客户并留痕**
- 风险告知书 / 谈话笔录（客户签字）
- 身份证复印件、营业执照副本、法定代表人身份证明

---

## 第 5 步 材料清单

当场给，别让他回去猜。

**通用**

- 身份证（正反面）、居住证明（涉及管辖）
- 与本案有关的合同、协议、补充协议
- 付款凭证、转账记录、发票、收据
- 往来沟通记录（微信、短信、邮件、录音）
- 已有裁判文书（如有在先诉讼）

**分案型增补**

| 案型 | 追加材料 |
|---|---|
| 婚姻家事 | 结婚证、户口本、子女出生证明、财产凭证（房产证、车辆登记证、银行流水、股权证明）、报警记录与就诊记录 |
| 民间借贷 | 借条/欠条、转账凭证、催收记录、担保材料、对方财产线索 |
| 合同纠纷 | 合同原件、履行凭证、验收单、往来函件、违约证据 |
| 劳动争议 | 劳动合同、工资流水、社保记录、考勤、解除通知、工作沟通记录 |
| 工伤 | 病历、诊断证明、劳动关系证据（工牌、工资记录、同事联系方式）、事故证明 |
| 建设工程 | 施工合同、签证单、结算单、验收报告、往来结算函 |
| 公司股权 | 公司章程、股东协议、出资凭证、股东会决议、财务资料 |
| 交通事故 | 事故认定书、病历、医疗费票据、误工证明、伤残鉴定意见、保单 |

**跟客户怎么说**

> 「这张单子您拿回去对着找，有就给原件，没有也别自己编——缺什么我们想办法补。材料齐不齐，直接决定这案子打得多顺。」

---

## 第 6 步 建档与留痕

- 建客户档案（纸质 + 电子）
- 记录：接案时间、来源、案由、标的、收费、主办人、关键节点
- **重要沟通都留痕**（客户说了什么、你承诺了什么、他确认了什么）

**为什么留痕**：客户投诉时，"我说过"和"我没说过"之间，只有记录能证明。

# 二、隐私与保密（使用本 skill 时必须遵守）

## 2.1 输入前先脱敏

把案情交给 AI 处理前，**替掉这些信息**：

| 类型 | 怎么处理 |
|---|---|
| 姓名 | 张某某、A 某、当事人甲 |
| 手机号 | 138****0000 或直接删掉 |
| 身份证号 | 完全删掉（用不到） |
| 住址 | 只留到区一级 |
| 银行卡/账号 | 删掉，或只留后四位 |
| 车牌号 | 部分遮挡 |
| 公司全称 | 用"某科技公司"替代（除非案情必须） |
| 案号 | 可保留（一般已公开） |

## 2.2 不要整份粘贴卷宗

- 需要 AI 帮你想话术时，**只给这句话的上下文**，不需要整份材料
- 需要分析案情时，只给关键事实，不给原始证据全文
- 涉及未成年人、性侵、医疗隐私等敏感案件，**进一步降低细节颗粒度**

## 2.3 跟客户怎么说

> 「您发给我的这些东西，我会按执业规定保管，不会外传。另外您发的时候，身份证号、银行卡号这些不用发，我用不到。」

## 2.4 保密义务的法律依据

律师对执业活动中知悉的委托人信息负有保密义务，这是法定要求，不因委托关系结束而终止。

**用 AI 处理信息时，保密义务不因此免除。** 脱敏的责任在律师，不在工具。

# 三、合规红线

## 3.1 绝对不能说的六类话

| 违规表述 | 性质 |
|---|---|
| "这个案子包赢 / 我保证能拿回来" | 对办案结果作不当承诺 |
| "我跟×法院/公安很熟，能打招呼" | 暗示影响办案，涉嫌违法 |
| "别的律师都不行 / 他就是骗子" | 诋毁同行 |
| "我们去年这类案子办了几百件"（不实） | 虚假宣传 |
| "病历/结算单/证据我帮你弄一下" | 教唆伪造证据 |
| "拿不到钱一分不收"（禁止类案件） | 违规风险代理 |

## 3.2 三件绝对不做

1. **不做结果承诺。** 客户逼、单子要飞，都不承诺。这是唯一不能妥协的一条。
2. **不碰证据造假。** 不改材料、不暗示客户去"找人开证明"、不建议证人改口。
3. **不私下收费。** 所有费用进律所账户、开票。没有例外。

## 3.3 关于"判断客户心理"的边界

本 skill 会帮你分析客户可能的顾虑，**那是给你判断用的，不是给你说给客户听的**。

- ✅ 可以：判断他担心什么，从而知道该先解释哪一块
- ✅ 可以：识别他是不是真的准备委托，从而合理安排时间
- ❌ 不可以：把"您其实是想白嫖"这类话说出口
- ❌ 不可以：利用客户的急迫、恐惧，催他当场决定
- ❌ 不可以：明知案子没把握，为了费用硬接

# 四、旧话术警示表

市面上流传的谈案话术资料里，有一批内容**已经不适用或不能用了**。遇到类似说法，对照这张表：

| 旧说法 | 问题 | 现在怎么说 |
|---|---|---|
| "农村户口赔偿少一半，我们有办法按城镇标准操作" | 城乡标准已统一；"操作"涉嫌造假 | 按统一标准算，重点争伤残等级与误工损失 |
| "全成都的交警队没有不认识的" | 违规宣传 | 只谈证据和程序，不谈关系 |
| "出院证明和护理费我们可以操作" | 教唆伪造证据 | 依法举证，缺证据就补证据 |
| "报价明细搞复杂点，设置价格诱饵" | 价格欺诈 | 按阶段列清，总额说清 |
| "把他整成失信老赖名单" | 律师无权决定，属虚假承诺 | 说明可申请强制执行、可申请限制措施，但不承诺结果 |
| "诉讼时效是两年" | 已失效 | 一般诉讼时效**三年** |
| "抚养权 10 岁以上听孩子意愿" | 与现行法不符 | 已满**八周岁**应尊重真实意愿 |
| "我们所不做风险代理，全城没有一家做" | 与事实不符 | 按法定范围说明能做与不能做 |
| "带客户去做鉴定能评高一级" | 暗示影响鉴定结论 | 讲清鉴定时点与材料准备，不讲"能评高" |
| "帮客户介绍融资方贷款交律师费" | 利益冲突 + 风险极高 | 建议分期或分段收费，不介入借贷 |
| 纯"挑矛盾"式煽动话术 | 伦理风险，可能损害客户利益 | 保留"揭示真实风险"的功能，去掉"制造情绪"的部分 |

**统一原则**：凡是靠"我知道你不知道的内幕"取信客户的话术，一律不用。

# 五、输出自检（每次给话术之前过一遍）

- [ ] 第一段是不是能直接用的话？
- [ ] 有没有先讲一通分析？
- [ ] 是不是太长？（事中超过 400 字就太长）
- [ ] 有没有替客户断定心理？
- [ ] 有没有承诺结果、夸关系、贬低同行？
- [ ] 有没有编造案例、办案量、胜诉率？
- [ ] 引用的法条是不是现行有效？时效、年龄、赔偿标准核对了吗？
- [ ] 涉及金额的，有没有编数字？（金额必须由律师自己定）
- [ ] 有没有利用客户情绪施加压力？
- [ ] 涉密信息复述进去了吗？

# 六、接案之后

1. **24 小时内发一条确认信息**：下一步做什么、要他配合什么、什么时候联系他
2. **第一次进展主动汇报，不要等他问**——这一条决定他会不会给你转介绍
3. **结案后要一次反馈**：问他对服务有什么意见

案源的本质不是话术，是**上一个客户愿不愿意替你说话**。
