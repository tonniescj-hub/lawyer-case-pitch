# 01 谈案主线与节奏

---

# 一、六步主线：参考流程，不是流程卡

> 读人 → 挖案 → 塑价 → 报价 → 收口 → 跟进

**这不是必须依次走完的六关。**

客户一上来就问价，就先答价；客户已经决定委托，就直接走手续；客户已经拒绝，就体面收尾，不用再挖案。

六步的作用是**判断现在缺什么**，不是**要求客户配合走完**。

| 步 | 这一步在解决什么 | 什么情况下可以跳过 |
|---|---|---|
| 读人 | 他现在最在意什么 | 客户已经说得很明确 |
| 挖案 | 事实够不够判断 | 材料已经看过了 |
| 塑价 | 他知不知道这笔钱花在哪 | 他已经在问"什么时候能开始" |
| 报价 | 多少钱、包含什么 | 客户没问价，且不急于知道 |
| 收口 | 下一步做什么 | 客户还在收集信息的阶段 |
| 跟进 | 保持联系 | 客户明确表示不要联系 |

**一轮谈话只推进一个主要动作。** 想同时做三件事，往往三件都做不成。

# 二、两条基本节奏

## 2.1 一轮只给一个判断、一个动作

电话里人一次只能接住一个东西。

反面例子（真实出现过）：

> 客户："欠了十多万吧，两三年了，很着急啊。"
> 律师："十多万不是小钱。但我先说你那句'两三年'——这个比金额更要命。诉讼时效是三年……过了会怎样……所以你现在第一件事不是催他，是翻记录，今晚就得翻出来。还有个问题你没答我：有没有借条？"

一句话里塞了：时效标准、过期后果、执行指令、追问。客户接不住，只会觉得"这人在催我"。

正确做法：

> "时间这块我心里有数了。有个事想先确认一下——**这个钱当时是怎么给他的？转账，还是给的现金？**"

**自检**：这句话说完，他能不能用一个短句回答？不能，就是给多了。

## 2.2 不确定就不下判断

缺口径的判断，比不给判断更麻烦。三个后果：说错被客户回头堵、专业形象一次性崩掉、万一误导了客户是要担责的。

**下判断前的四问**：

- [ ] 时间点问准了吗？（不是"两三年"，是具体哪年哪月）
- [ ] 起算依据问清了吗？（约定日期 / 未约定 / 最后一次催告 / 部分还款）
- [ ] 手上有什么材料，问清了吗？
- [ ] 对方的抗辩点，能预判吗？

缺任何一项，标准说法：

> 「这个得看材料才能定，我现在给您个数，是不负责任的。」
> 「这一点我先记下，回头核了再回您。」

⚠️ 该讲的风险还是要讲。区别在于——**讲风险不说成结论**。可以说"这个时间点很关键，得算准"，不能说"您已经过了"。

# 三、三场景节奏

## 3.1 电话

**电话的任务：** 让他对这件事有个方向，并且愿意的话，下一步继续。

电话的优势是能听出语气，劣势是看不见材料、也看不见表情。

### 开场（20 秒）

> 「您好，××律师事务所，我姓×。您说。」

不要问"有什么可以帮您"，那是客服腔。让他直接讲，你做三件事：不打断、记关键词、嗯一声。

### 听 + 复述

听完必须复述一遍，用"一二三"：

> 「我先把您说的理一遍，您看我理解得对不对——第一……；第二……；第三，您现在最想解决的是……。是这样吧？」

**复述的作用不是确认事实**，是把他散乱的话整理成"问题"。能被说清楚的问题，才有得谈。

### 一次问一到两个

> 「我问几个问题，您别嫌烦，这些直接影响后面怎么弄。」

问完**回一个判断**，别只问不给：

> 「什么时候的事？」
> （答）
> 「嗯，这个时间点很关键，**诉讼时效是三年，从您知道权利被侵害那天算**。您这个还有多久，我得把日期问准才能算。」

### 要不要在电话里报价

**可以报，但要说明依据。** 详见 `03-报价与收费话术.md`。

不报的唯一理由应该是"信息不够，报出来会错"，不是"销售上不该报"。

### 收口

电话结束前，给一个具体的下一步。可以约见面，也可以不约：

> 「这样，您把××和××找出来，发我看一下，我看完给您一个方向。要是方便，也可以过来一趟，当面讲清楚一些。」

**不要每次都把"来所里"当唯一出路。** 有些客户线上就能谈成，有些客户来了也不会签，逼着见面反而消耗信任。

### 三个细节（用得上就用，不必强求）

- 约时间用"今天下午还是明天上午"，比"您什么时候方便"更容易得到答复
- 约好之后发一条短明确认，把口头约定变成书面
- 记得称呼他的名字，或者"×律师"自称时要自然，不用刻意拉近

## 3.2 微信

**微信的任务：** 建立基本信任，把长问题转到能说清的地方。

微信的坑：**你打的每个字都可能被转发、被截图、拿去比价。**

### 回复长度

- 每条约 60-100 字
- 超过 150 字就拆成两条
- 不要一条里塞三个问题

### 不写完整法律分析

> 「您这个事，核心是三个点：①……②……③……。这三块每一个都有讲究，打字容易说偏。您方便的话通个电话，五分钟比打两百字清楚。」

**为什么**：写全了他不需要你，写一半他觉得你不专业，而且文字会被拿去问别人。

### 首次咨询不说太多

> 「您好，我是××律所的×律师。您先说说情况，我看到就回。」

### 设边界

> 「简单问一句我随时答。要是涉及看材料、出方案，这部分我们是收费咨询，××元一次，后面委托了从律师费里扣。」

收费咨询的意义不是赚那点钱，是**筛人**。愿意付的通常是真的要办；不愿意的，本来也不会签。

### 收口

> 「您这个情况，我建议当面或通个电话讲一下，二十分钟差不多。您看是明天下午还是后天上午？」

## 3.3 面谈

**面谈的任务：** 让他做完决定之后，心里是清楚的——不管这个决定是委托还是不委托。

### 前五分钟不谈案

给水、问路上、看一眼他带的材料。

> 「您这材料整理得挺仔细，一般人过来都是一团。」

夸具体的东西，不夸人。

### 读人：只看他说过的话

边听边在心里记这几项，**但不要下结论**：

| 观察 | 看什么 |
|---|---|
| 他最在意什么 | 反复提到的是哪件事 |
| 他在担心什么 | 说到哪里开始重复、开始抱怨 |
| 他能不能自己决定 | 有没有出现"要问我老公""要问合伙人" |
| 他是不是在准备委托 | 有没有问流程、问时间、问要准备什么 |

**记在心里，不要说出口。** "您其实是怕花钱"这种话，说出来就是冒犯。

### 挖案：自然提问

一次一到两个问题，问完给个判断。**不要把咨询做成填表。**

### 塑价：讲工作，不讲形容词

- 讲"这一步要跑哪几个地方、大概几天"，不讲"我们非常专业"
- 讲"这一步做晚了会怎样"，不讲"不请律师您就完了"

### 报价：透明

见 `03`。核心是三件事：多少钱、包含什么、不包含什么。

### 收尾

给明确的下一步，**也给他不选你的空间**：

> 「情况我大致清楚了。剩下几个点得看材料才能定。您把××和××准备一下，我这边出个书面方案给您。您看完觉得合适我们再走手续，觉得不合适也没关系。」

**"觉得不合适也没关系"这句话要敢说。** 说了反而更容易签，因为客户感到没有被逼。

# 四、谈完之后：轻量复盘

## 4.1 客户没签，先别急着定性

**没签的原因可能是**：预算不够、需求变了（对方还钱了、家里和解了）、案子本身没法接、家里不同意、客户想再比比、客户就是自己决定不请。

**这些都不是律师谈得不好。**

没有完整对话记录时，必须明说：

> 「以下判断基于您提供的有限信息，可能有偏差。」

## 4.2 复盘四问

1. **哪句话可能造成了障碍？**（对着原话找）
2. **为什么这句话可能不合适？**
3. **更好的说法是什么？**
4. **下次最值得改的一件事是什么？**（只给一件，给多了记不住）

## 4.3 常见障碍对照

| 现象 | 可能的原因 | 下次怎么办 |
|---|---|---|
| 问完价就沉默 | 价格前没讲清做什么 | 报价前先讲一段"这个案子要做什么" |
| 一直问"能保证赢吗" | 风险没讲透，他心里没底 | 主动把最坏情况说清 |
| 说"回去商量" | 可能是真的要走流程，也可能是委婉拒绝 | 问一句"主要担心哪块" |
| 聊得很好但不签 | 结束时没给具体下一步 | 收尾给一件事、一个时间 |
| 只问价不聊案情 | 可能在比价，也可能只是先了解行情 | 给参考区间，别投入过多时间 |
| 全程你在讲 | 说太多 | 每讲两分钟，问他一个问题 |
| 客户明显不耐烦 | 讲太深了 | 看他的反应调深浅，不看他该懂多少 |

⚠️ 这张表是**可能性**，不是诊断书。同一个现象可能有完全不同的原因。
